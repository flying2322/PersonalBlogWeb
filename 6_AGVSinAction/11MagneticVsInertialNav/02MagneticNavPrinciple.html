2 磁条导航原理

磁条导航，说白了就是让AGV沿着地面上贴好的磁条跑。听起来简单，但里面的门道不少。我最早接触磁条导航是在2015年，那时候刚入行，觉得这技术太“土”了，后来才发现——越简单的东西，往往越可靠。

2.1 磁条的物理特性

磁条不是普通的橡胶条。它里面掺了铁氧体粉末，经过定向充磁后形成永磁体。我常用的磁条规格是：

  • 宽度：30mm、50mm、80mm 三种
  • 厚度：1.0mm ~ 1.5mm
  • 剩磁：一般要求 ≥ 200mT
  • 矫顽力：≥ 150kA/m

这里有个坑——剩磁和矫顽力是两个关键指标。剩磁决定了传感器能感应到多强的信号，矫顽力决定了磁条会不会被外部磁场消磁。我曾经在某个项目里用过一批便宜磁条，剩磁只有150mT，结果AGV跑着跑着就丢信号了。后来换了正规厂家的产品，问题才解决。

注意：磁条怕高温。超过80°C，磁性会开始衰减。车间地面如果有加热管道，铺设时要避开。

2.2 磁导航传感器工作原理

磁导航传感器，本质上是一排霍尔元件。每个霍尔元件能检测垂直方向的磁场强度。当磁条从传感器下方经过时，不同位置的霍尔元件会输出不同的电压值。

我常用的传感器是16位或32位的。16位就是16个霍尔元件排成一排，间距10mm，覆盖160mm宽度。32位同理，覆盖更宽。

工作原理可以概括为三步：

  1. 磁场检测：霍尔元件感应磁条产生的垂直磁场分量
  2. 信号转换：磁场强度 → 电压信号 → ADC采样 → 数字量
  3. 位置解算：找出信号最强的几个点，计算磁条中心线位置

核心公式（简化版）：

偏差量 = (信号最强点索引 - 传感器中心索引) × 霍尔元件间距

这个偏差量就是AGV相对于磁条的横向偏移，直接送给PID控制器做纠偏。

2.3 磁条铺设规范

铺设磁条看起来简单，但细节决定成败。我总结了几条硬性规范：

项目 要求 说明
地面清洁度 无油污、无灰尘 用酒精擦拭后再贴
铺设温度 15°C ~ 35°C 温度太低胶粘不牢
转弯半径 ≥ 500mm 太急的弯AGV容易甩出去
磁条接头 对接间隙 ≤ 1mm 间隙大了传感器会跳变
交叉角度 ≥ 30° 避免磁干扰

嗯，这里要特别说一下转弯半径。我见过有人把磁条铺成90°直角弯，AGV根本过不去。你想想看，AGV有轴距，转弯需要内轮差。磁条转弯半径至少要大于AGV的最小转弯半径，一般取500mm以上才保险。

我的习惯：铺设前先用粉笔在地面画出路径，让AGV手动跑一遍确认没问题，再贴磁条。省得贴好了又撕，胶残留很难清理。

2.4 信号采集与处理流程

信号采集这块，我踩过不少坑。先看流程图：

流程看起来简单，但实际处理时有很多细节。我重点说几个：

2.4.1 采样频率

我一般设置采样频率为100Hz，也就是每10ms采集一次。为什么是这个值？AGV最高速度1.5m/s，磁条宽度30mm，传感器覆盖160mm。算下来10ms内AGV移动15mm，足够在丢失信号前做出反应。

2.4.2 滤波算法

原始信号噪声很大。地面有铁屑、电机有电磁干扰，都会影响霍尔元件的输出。我常用的滤波方式：

// 中值滤波示例（取5次采样的中间值）
uint8_t median_filter(uint8_t *data, uint8_t len) {
    uint8_t temp[5];
    memcpy(temp, data, 5);
    // 冒泡排序
    for(int i=0; i<4; i++) {
        for(int j=0; j<4-i; j++) {
            if(temp[j] > temp[j+1]) {
                uint8_t t = temp[j];
                temp[j] = temp[j+1];
                temp[j+1] = t;
            }
        }
    }
    return temp[2];  // 返回中间值
}

中值滤波对脉冲噪声特别有效。有一次现场有电焊机干扰，均值滤波完全扛不住，换成中值滤波就好了。

2.4.3 信号丢失处理

这是最头疼的问题。磁条被叉车压坏了、被油污覆盖了，传感器就会丢信号。我的处理策略是：

  • 短时丢失（< 200ms）：保持上一帧的偏差量，继续运行
  • 中时丢失（200ms ~ 1s）：减速到0.3m/s，尝试重新捕获
  • 长时丢失（> 1s）：急停，报错
我曾经踩过的坑：一开始我把丢失阈值设得太短，AGV过磁条接头时稍微抖一下就急停。后来改成200ms的容忍窗口，问题解决了。但也不能太长，否则AGV会跑偏撞到货架。

2.5 小结

磁条导航的原理不复杂，但工程实现上有很多细节。说白了，就是传感器读数据、软件做滤波、控制器算偏差、电机做纠偏。每一步都做好了，AGV才能稳稳地沿着磁条跑。我见过太多项目因为磁条铺设不规范或者滤波没做好，导致AGV像喝醉了酒一样左右摇摆。嗯，这些坑咱们后面还会细讲。

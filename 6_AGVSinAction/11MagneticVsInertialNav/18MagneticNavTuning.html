18 磁条导航调试与优化：传感器安装校准、磁条接头处理、路径平滑优化、速度曲线匹配

磁条导航看着简单，不就是车跟着磁条跑嘛。但真正调试过的人都知道，这里面坑不少。我做了这么多年AGV，光磁条导航就折腾过不下几十个项目。今天把这四个核心环节掰开揉碎了讲，全是实战经验。

核心要点：磁条导航的调试，本质上是让传感器、磁条、运动控制三者完美配合。任何一个环节出问题，车就跑不顺。

18.1 传感器安装校准：位置偏差1mm，跑偏10cm

传感器安装，我见过太多人栽跟头了。你以为随便拧几个螺丝就行？太天真了。

安装位置要求：

  • 高度控制：传感器底面离磁条表面，我建议控制在20-30mm。太近了容易刮蹭，太远了信号弱。我有个项目，现场工人把传感器抬高了5mm，结果直线段跑得歪歪扭扭，查了两天才发现。
  • 居中安装：传感器中心线必须与AGV车体中心线重合。偏差超过2mm，转弯时就会出问题。
  • 水平度：传感器必须与地面平行。倾斜超过3度，左右信号就不对称了。

我的习惯：安装完传感器后，我会用水平尺和游标卡尺做一次复核。别嫌麻烦，这一步省了，后面调试时间翻倍。

校准步骤：

  1. 把AGV推到一段平直磁条上
  2. 读取传感器左右通道的原始信号值
  3. 理想状态：左右信号差值在5%以内
  4. 如果偏差大，微调传感器位置，直到信号平衡
// 传感器信号校准示例（伪代码）
float left_signal = read_sensor_left();
float right_signal = read_sensor_right();
float diff = abs(left_signal - right_signal) / max(left_signal, right_signal);

if (diff > 0.05) {
    // 偏差超过5%，需要调整
    printf("传感器偏差：%.2f%%，请检查安装位置\n", diff * 100);
} else {
    printf("传感器校准通过\n");
}

18.2 磁条接头处理：最容易被忽视的细节

磁条接头，说白了就是两段磁条拼接的地方。我遇到过最离谱的情况：AGV每次经过某个接头就剧烈抖动，后来发现是接头处有1mm的缝隙。

接头处理要点：

  • 无缝拼接：两段磁条端面必须紧密贴合，缝隙控制在0.5mm以内。我习惯用美工刀把端面切平，再用酒精擦拭干净。
  • 高度一致：接头处不能有台阶。用指甲划过接头，感觉不到凹凸才算合格。
  • 方向一致：磁条有N/S极方向，拼接时极性必须一致。我曾经犯过这个错，结果车在接头处直接掉头跑。

避坑指南：我曾经在一个项目中，磁条接头处用了双面胶固定。结果夏天温度高，双面胶软化，接头翘起来了。后来全部改用专用磁条胶带，再也没出过问题。

接头处理流程：

  1. 切割端面：用直角尺保证切口垂直
  2. 清洁：酒精擦拭，去除油污和灰尘
  3. 涂胶：均匀涂抹专用胶水，不要太多
  4. 压合：用力按压30秒，确保贴合紧密
  5. 固化：静置24小时，不要急着跑车

18.3 路径平滑优化：让AGV走得更顺

磁条导航的路径，说白了就是一段段直线和圆弧拼接起来的。但AGV在转弯处经常出现抖动、过冲、甚至脱轨。为什么会这样？

问题根源：磁条导航是离散的传感器信号，AGV只能根据当前传感器读数判断位置。转弯时，传感器信号变化剧烈，控制算法跟不上。

优化方法：

  • 圆弧过渡：直角转弯处，用圆弧磁条代替直角。圆弧半径我一般取AGV最小转弯半径的1.2倍。
  • 预判控制：在进入弯道前，提前减速。我习惯在弯道前30cm开始减速，弯道中保持匀速，出弯后加速。
  • 滤波处理：对传感器信号做低通滤波，减少噪声干扰。我常用滑动平均滤波，窗口大小取5-7个采样点。
// 滑动平均滤波示例
#define FILTER_WINDOW 5
float filter_buffer[FILTER_WINDOW];
int filter_index = 0;

float low_pass_filter(float raw_signal) {
    filter_buffer[filter_index] = raw_signal;
    filter_index = (filter_index + 1) % FILTER_WINDOW;
    
    float sum = 0;
    for (int i = 0; i < FILTER_WINDOW; i++) {
        sum += filter_buffer[i];
    }
    return sum / FILTER_WINDOW;
}

个人经验：路径平滑不是越平滑越好。我见过有人把路径做成完美的S形曲线，结果AGV跑起来反而更慢。因为磁条导航的响应速度有限，太复杂的曲线反而让控制算法无所适从。

18.4 速度曲线匹配：快慢有度，稳字当头

速度曲线匹配，说白了就是让AGV在不同路段跑不同的速度。直线段可以快，弯道要慢，接头处要稳。

速度曲线设计原则：

  • 直线段：最高速度，但不超过AGV设计上限。我一般取0.8-1.2m/s。
  • 弯道：根据转弯半径调整。半径越小，速度越慢。经验公式：速度 = 0.3 + 0.5 * (半径/最小转弯半径)。
  • 接头处：减速通过，速度控制在0.3m/s以下。等传感器信号稳定后再加速。
  • 加减速：加速度不宜过大，否则AGV会点头或甩尾。我习惯用0.3-0.5m/s²。
路段类型 推荐速度(m/s) 加速度(m/s²) 备注
直线段 0.8 - 1.2 0.4 - 0.5 根据负载调整
大弯道(R>1m) 0.5 - 0.8 0.3 - 0.4 提前30cm减速
小弯道(R<0.5m) 0.2 - 0.4 0.2 - 0.3 注意脱轨风险
磁条接头处 0.2 - 0.3 0.2 信号稳定后再加速 
// 速度曲线匹配示例
float get_target_speed(float curvature, bool is_junction) {
    float speed;
    
    if (is_junction) {
        speed = 0.25;  // 接头处低速通过
    } else if (curvature < 0.1) {
        speed = 1.0;   // 直线段高速
    } else if (curvature < 0.5) {
        speed = 0.6;   // 大弯道中速
    } else {
        speed = 0.3;   // 小弯道低速
    }
    
    return speed;
}

重要提醒：速度曲线不是一成不变的。同一个项目，空载和满载的速度曲线就要不同。我一般会在调试阶段，分别测试空载、半载、满载三种工况，然后取一个折中值。如果负载变化大，建议做自适应速度调节。

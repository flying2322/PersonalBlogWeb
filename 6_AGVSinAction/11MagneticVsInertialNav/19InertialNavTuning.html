19 惯性导航调试与优化

惯性导航这东西，说白了就是靠“猜”。

IMU自己算自己走了多远，没有外部参照。时间一长，误差就累积起来了。我刚开始做AGV那会儿，觉得IMU挺高级，结果一跑起来，定位越偏越离谱。后来才明白——调试和优化才是真正的重头戏。

19.1 IMU温漂补偿

IMU最怕什么？温度变化。

你想想看，芯片内部温度从25℃升到60℃，零偏可能漂了0.5°/s。这0.5°/s看着不大，但积分10秒就是5°的航向误差。AGV在仓库里转个弯，直接就撞货架了。

温漂补偿，我一般分三步走：

  1. 标定阶段：把IMU放进温箱，从-10℃到60℃每5℃记录一次零偏。拟合出一条温度-零偏曲线。
  2. 运行时补偿：实时读取IMU内部温度传感器，查表或插值得到当前零偏值，直接减掉。
  3. 动态校准：如果AGV长时间静止，我习惯用这段时间重新估算零偏，更新补偿参数。

核心公式（简化版）：

ω_corrected = ω_raw - b(T)
b(T) = a0 + a1 * T + a2 * T²

其中b(T)是温度T下的零偏估计值，a0、a1、a2是标定得到的系数。

我的经验： 别只依赖出厂参数。每块IMU的温漂曲线都不一样。我曾在项目里吃过亏，用了厂家给的通用补偿参数，结果AGV在夏天和冬天的定位精度差了30%。后来老老实实自己标定，问题才解决。

19.2 零速修正策略

零速修正，简称ZRUPT。名字挺唬人，其实道理很简单——

AGV停着的时候，速度应该是0。但IMU积分出来的速度往往不是0。这时候，我们强制把速度置零，同时修正位置和姿态。

什么时候触发零速修正？

  • AGV停止超过1秒
  • 轮速编码器检测到速度为0
  • 电机电流低于某个阈值（防止AGV在斜坡上溜车）

零速修正的典型流程：

if (检测到零速状态) {
    // 1. 速度强制归零
    vx = 0; vy = 0; vz = 0;
    
    // 2. 利用静止时的加速度计读数修正姿态
    roll = atan2(ay, az);
    pitch = atan2(-ax, sqrt(ay² + az²));
    
    // 3. 重置IMU的零偏估计
    gyro_bias = (gyro_bias + current_gyro) / 2;
    
    // 4. 位置保持不变（不修正位置，防止跳变）
}

注意： 零速修正不能太频繁。我曾经试过每停一次就修正一次，结果AGV在连续启停时位置来回跳。后来改成“连续静止超过3秒才触发”，效果好了很多。

19.3 地图构建优化

惯性导航的地图，和激光SLAM的地图不太一样。它更多是“轨迹地图”——记录AGV走过的路径和关键特征点。

我常用的优化手段：

  1. 闭环检测：AGV回到之前经过的位置时，强制对齐轨迹。这能有效抑制长时间运行的累积误差。
  2. 关键帧筛选：不是每一帧数据都存。只有AGV转弯、启停、或经过特征明显区域时，才保存关键帧。地图大小能减少80%。
  3. 局部地图更新：AGV在某个区域反复运行时，用最新的观测数据替换旧数据。说白了就是“用新信息覆盖旧信息”。

地图构建的核心逻辑：

// 伪代码
if (isKeyFrame(current_pose)) {
    map.addKeyFrame(current_pose, imu_data);
    if (detectLoopClosure(current_pose)) {
        optimizeGraph();  // 图优化，调整所有关键帧的位姿
    }
}

我个人习惯在AGV运行的第一圈做“粗建图”，第二圈做“精优化”。这样既保证了建图速度，又保证了精度。

19.4 运动模型调参

IMU的数据怎么用，很大程度上取决于运动模型。模型不对，参数调得再好也没用。

常见的运动模型：

模型类型 适用场景 关键参数
恒速模型 AGV直线行驶、速度变化缓慢 速度噪声方差、加速度噪声方差
恒加速度模型 AGV启停、加减速频繁 加加速度噪声方差
轮式里程计+IMU融合 大多数AGV场景 轮径、编码器分辨率、IMU与轮轴的安装角度

调参的几个要点：

  • 先粗调后精调：先让AGV跑起来，参数差不多就行。然后录一段数据，离线调优。
  • 关注残差：卡尔曼滤波的残差序列如果出现明显趋势，说明模型有问题。我遇到过残差一直正偏，后来发现是轮径标定错了。
  • 不要过度调参：参数调得太“完美”，换个环境就崩。我一般留10%的裕量。

避坑指南： 我曾经在一个项目里，把IMU的噪声方差调得特别小，觉得这样定位更准。结果AGV在颠簸路面上疯狂震荡，定位直接发散。后来才明白——噪声方差是信任度的体现。你越信任IMU，它犯错时你摔得越惨。

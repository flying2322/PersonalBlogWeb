23 惯性导航选型：一场“性价比”的博弈

说实话，做AGV这么多年，我见过太多在惯导选型上翻车的案例。有人花大价钱买了工业级IMU，结果发现算法没跟上，精度还不如消费级芯片配个好算法。也有人图便宜买了低端货，结果车子跑着跑着就偏了，最后还得加装磁条补救。

所以今天这篇选型指南，我打算从四个维度拆开来讲：IMU性能等级、导航计算机、算法授权、系统集成难度。你想想看，这四个东西就像一辆车的四个轮子，哪个瘸了都跑不远。

核心观点：惯导选型不是选最贵的，也不是选最便宜的，而是选“你的算法能驾驭的”。

二、IMU性能等级：别被参数表骗了

IMU这东西，参数表上写得天花乱坠，实际用起来完全是另一回事。我个人习惯把IMU分成三个等级：消费级、工业级、战术级。别被名字唬住，关键看几个硬指标。

2.1 消费级IMU（几十到几百元）

典型代表：MPU6050、ICM-20948。这类芯片我最早在平衡车上用过，后来也试过装在AGV上做短距离导航。说实话，零偏稳定性通常在10°/h以上，温度一变化就飘得厉害。

我的经验：消费级IMU只适合做辅助修正，比如配合磁条或二维码做短时盲区补偿。千万别指望它单独撑起导航任务，否则你会被温漂折磨到怀疑人生。

2.2 工业级IMU（几千到几万元）

这是AGV惯导的主力军。零偏稳定性能做到1°/h ~ 10°/h，带温度补偿和出厂标定。我用过ADIS16470和BMI088，说实话，BMI088性价比不错，但ADIS的稳定性更好。

参数 消费级 工业级 战术级
零偏稳定性 >10°/h 1~10°/h <0.1°/h
温度范围 0~70°C -40~85°C -55~125°C
典型价格 50~500元 2000~20000元 5万~50万+
适用场景 辅助修正 主力导航 高精度/军工

注意：我曾经在一个项目中选了工业级IMU，但忽略了振动环境。AGV在粗糙地面跑了几小时后，IMU输出直接漂了3度。后来加了减震支架才解决。所以选型时一定要考虑实际工况。

三、导航计算机选型：算力与功耗的平衡

导航计算机是惯导系统的大脑。你IMU再好，算力跟不上也是白搭。反过来，算力过剩又浪费成本和功耗。

3.1 主流方案对比

  • MCU方案（STM32H7系列）：适合简单融合算法，成本低，功耗小。但跑不了复杂的卡尔曼滤波或粒子滤波。
  • ARM Cortex-A系列（树莓派、RK3588）：我目前的主力方案。能跑EKF、UKF，还能同时处理视觉辅助。功耗5~15W，够用。
  • x86方案（Intel NUC）：算力最强，但功耗也高（20W+）。适合需要实时SLAM或深度学习辅助的场景。
  • FPGA方案：延迟最低，但开发周期长。我见过有人用Zynq做惯导+激光雷达融合，效果确实好，但团队没两把刷子别碰。

3.2 我的选型建议

说白了，选计算机就是看你的算法复杂度。如果你只是做简单的互补滤波+航位推算，STM32F4都够用。但如果你要做15状态EKF，还得实时输出控制指令，那至少得上Cortex-A55级别的芯片。

一个实用公式：所需算力 ≈ (IMU输出频率 × 状态维度²) × 3倍余量。比如100Hz的IMU，15维状态，算力需求 ≈ 100 × 225 × 3 = 67.5 MFLOPS。STM32H7大概能跑300 MFLOPS，够用。

四、算法授权模式：开源还是付费？

这个问题我纠结过很久。市面上惯导算法授权主要有三种模式：

4.1 买断制

一次性付费，永久使用。适合产品定型、批量大的项目。价格从几万到几十万不等。我见过一家公司花15万买了某厂商的惯导算法库，后续自己维护，算下来比年费划算。

4.2 年费/订阅制

每年交钱，厂商提供更新和技术支持。适合研发阶段或小批量生产。缺点是长期成本高，但好处是算法持续优化。

4.3 按量计费

按出货量收费，每台AGV收几十到几百元。适合初创公司，前期投入低。但要注意合同条款，有些厂商会限制你的最大出货量。

我的建议：如果你团队有算法能力，优先考虑开源方案（如RTKLIB、OpenVINS）。自己调参虽然累，但核心能力掌握在自己手里。我早期就是靠开源方案起步的，后来才逐步自研。

五、系统集成难度：别让选型毁在最后一步

很多人选完IMU和计算机就以为完事了。其实集成才是真正的坑。我总结了几点常见问题：

5.1 标定难题

IMU出厂标定只是基础。你装到AGV上后，安装误差、杆臂效应、磁干扰都需要现场标定。我曾经花了两周时间才把一台AGV的IMU标定好，因为车体本身有磁性材料。

5.2 温漂处理

工业级IMU虽然带温度补偿，但实际效果因厂商而异。我习惯在算法里加一个温度补偿模型，用多项式拟合零偏随温度的变化。代码大概长这样：

// 温度补偿示例（伪代码）
float gyro_bias_temperature_compensation(float raw_bias, float temp) {
    // 多项式系数需通过实验标定
    float a0 = 0.05, a1 = 0.002, a2 = 0.0001;
    float delta_temp = temp - 25.0;  // 参考温度25°C
    return raw_bias - (a0 + a1*delta_temp + a2*delta_temp*delta_temp);
}

5.3 振动与EMC

AGV的电机和驱动器是巨大的干扰源。我见过一个案例，IMU直接装在电机旁边，结果角速度输出全是电机换向的噪声。后来加了减震支架和屏蔽罩才解决。

避坑指南：我曾经在集成阶段忽略了IMU的安装方向。AGV转弯时，IMU的Z轴和车体Z轴差了5度，导致航向角误差累积。后来在算法里加了安装矩阵才修正。所以，安装精度一定要控制在0.1度以内。

六、总结：选型不是终点，是起点

说了这么多，其实就一句话：惯导选型要结合你的算法能力、成本预算和实际工况。别被参数表迷惑，也别迷信大厂。我见过用消费级IMU配合强算法做出不错效果的，也见过花大价钱买战术级IMU却因为集成问题翻车的。

最后送大家一句话：选型只是开始，调试才是常态。做好心理准备，留足调试时间，这才是项目成功的关键。

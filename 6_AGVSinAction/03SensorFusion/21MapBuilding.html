21 地图构建：占据栅格地图、TSDF地图、语义地图

地图构建这件事，说白了就是让AGV知道「我在哪，周围有什么」。

我做了这么多年SLAM，发现很多新手一上来就追求高大上的地图表示，结果在真实产线上跑得稀里哗啦。其实，选对地图类型比调参更重要。今天咱们就聊聊三种最常用的地图：占据栅格地图、TSDF地图、语义地图。

21.1 占据栅格地图（Occupancy Grid Map）

这是最经典、最成熟的地图表示方式。我个人习惯叫它「格子图」。

原理很简单：把环境划分成一个个小格子，每个格子存一个概率值，表示这个格子被障碍物占据的可能性。

核心思想：每个格子独立估计占据概率，通过贝叶斯滤波不断更新。

我记得2018年做一个仓储AGV项目时，一开始用了高精度的TSDF地图，结果发现计算量太大，工控机扛不住。后来换成占据栅格地图，分辨率调到5cm，效果反而更好。

更新公式

每个格子的概率更新用对数几率（log-odds）形式：

// 伪代码：占据栅格更新
float inv_sensor_model(int x, int y, float z) {
    // 根据激光点距离判断格子状态
    if (z < grid_distance) return 0.7;   // 占据
    else if (z == grid_distance) return 0.5; // 未知
    else return 0.3;  // 空闲
}

void update_grid(Grid* grid, float log_odds) {
    grid->log_odds += log_odds;
    grid->probability = 1 - 1/(1 + exp(grid->log_odds));
}

避坑指南：我曾经在动态环境中吃过亏——移动的人或叉车会在栅格地图上留下「鬼影」。后来加了时间衰减因子，旧观测的权重逐渐降低，才解决了这个问题。

优缺点对比

特性 说明
优点 计算快、内存小、容易实现、适合2D导航
缺点 无法表示高度信息、对动态物体敏感、分辨率固定
典型应用 室内AGV、扫地机器人、2D激光SLAM

21.2 TSDF地图（Truncated Signed Distance Function）

TSDF地图，你想想看，它其实是在解决「占据栅格地图太平面化」的问题。

每个体素（3D格子）存一个截断符号距离值，正值表示体素在障碍物表面之外，负值表示在内部，零值附近就是表面。

核心优势：可以重建精细的3D表面，支持多传感器融合（RGB-D相机、激光雷达）。

我建议在做3D导航或机械臂避障时优先考虑TSDF。2020年有个项目需要AGV在货架间穿行，货架腿只有5cm粗，用2D栅格地图经常撞到。换成TSDF地图后，精度直接提升了一个量级。

TSDF更新流程

// 伪代码：TSDF体素更新
struct Voxel {
    float tsdf;      // 截断符号距离
    float weight;    // 权重
};

void integrate_tsdf(Voxel* voxel, float depth, float truncation) {
    float sdf = depth - voxel->distance_to_sensor;
    if (sdf > -truncation) {
        // 截断处理
        float tsdf = min(1.0, max(-1.0, sdf / truncation));
        // 加权融合
        float new_weight = voxel->weight + 1.0;
        voxel->tsdf = (voxel->tsdf * voxel->weight + tsdf) / new_weight;
        voxel->weight = new_weight;
    }
}

注意：TSDF地图的内存消耗很大。一个10m×10m×3m的空间，分辨率5cm，就需要约24万个体素。我建议根据实际场景动态调整分辨率，远处用粗分辨率，近处用细分辨率。

21.3 语义地图（Semantic Map）

语义地图，说白了就是给地图里的物体「贴标签」。

比如这个格子是「货架」，那个区域是「通道」，这个点是「充电桩」。它不只是告诉AGV「这里有障碍物」，还告诉它「这是什么障碍物」。

嗯，这里要注意：语义地图通常不是独立存在的，而是建立在占据栅格或TSDF地图之上的一层「语义层」。

构建流程

  1. 物体检测：用YOLO、Mask R-CNN等模型识别图像中的物体
  2. 投影到地图：将检测框或分割掩码投影到地图坐标系
  3. 语义融合：多帧观测的语义标签进行贝叶斯融合
  4. 拓扑提取：从语义地图中提取道路、区域等高层信息

个人经验：我曾经在工厂里做语义地图，发现一个坑——光照变化会导致检测模型频繁误报。后来我加了时间一致性检查：同一个位置连续5帧都检测到「货架」，才确认它是货架。误报率从30%降到了5%以下。

21.6 实际项目中的选择建议

我根据这些年踩过的坑，给你几个实用建议：

  • 纯2D导航场景（如仓库地面AGV）：用占据栅格地图就够了，别折腾3D
  • 需要避障高度信息（如货架间穿行）：用TSDF地图，但注意控制分辨率
  • 需要智能交互（如识别充电桩、货架类型）：在占据栅格或TSDF基础上叠加语义层
  • 计算资源有限：优先用占据栅格地图，语义检测可以降低帧率

最后说一句：地图构建没有银弹。我见过太多人纠结于「哪种地图最好」，其实最适合你场景的，就是最好的。

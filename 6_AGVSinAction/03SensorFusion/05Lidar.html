5 激光雷达(LiDAR)：单线与多线激光雷达原理、点云数据格式、测距原理

说到AGV导航，激光雷达绝对是个绕不开的传感器。我入行那会儿，AGV还主要靠磁条导航，现在你去看任何一个稍微智能点的移动机器人，头顶上基本都顶着一个或者几个激光雷达。这玩意儿说白了就是机器人的「眼睛」，而且是那种自带尺子的眼睛——它不光能看见，还能精确告诉你障碍物有多远。

今天咱们就聊聊激光雷达的核心原理。我会把单线和多线的区别、点云数据长什么样、以及它到底怎么测距的，掰开了讲清楚。

5.1 单线激光雷达：AGV的「安全护栏」

单线激光雷达，顾名思义，就是只发射一束激光，通过旋转扫描得到一个平面的距离信息。你想想看，它扫出来的就是一个二维的切片图，像一把尺子在水平面上转了一圈。

工作原理其实不复杂：

  • 激光器发射一束脉冲激光
  • 打到物体表面后反射回来
  • 接收器捕获回波信号
  • 根据飞行时间计算距离

我在项目里用过最多的单线雷达是Sick和Hokuyo的。说实话，单线雷达在AGV上最大的价值就是做安全避障和沿墙导航。它只能扫一个平面，所以安装高度很讲究——装高了扫不到低矮障碍物，装低了又容易误检地面起伏。

核心参数：

  • 扫描角度：通常270°或360°
  • 角分辨率：0.25°~1°
  • 测距范围：10m~50m不等
  • 扫描频率：10Hz~50Hz

我的经验：单线雷达做SLAM其实挺吃力的，因为信息量太少。我建议在纯平地面、环境结构清晰的场景下用单线雷达做定位，否则还是老老实实上多线或者加IMU辅助。

5.2 多线激光雷达：3D感知的「主力军」

多线雷达就不一样了。它内部有多个激光发射器，同时发射多束激光，覆盖不同的垂直角度。你想想看，它扫出来的就不是一条线了，而是一个面——准确说是一个三维点云。

常见的多线雷达有：

  • 16线：性价比高，适合室内AGV
  • 32线：精度和视野均衡，户外也能用
  • 64线/128线：高端自动驾驶级别，价格也感人

我记得第一次用Velodyne的16线雷达做室外AGV导航时，最大的感受就是——信息量太大了！单线雷达你只能看到障碍物的一个截面，多线雷达直接给你一个三维模型。地面、墙壁、行人、车辆，全都能区分出来。

注意：多线雷达的数据量是单线的几十倍甚至上百倍。我曾经遇到过工控机CPU直接跑满的情况。所以做多线雷达融合时，一定要考虑算力开销，该降采样就降采样，别硬扛。

5.3 点云数据格式：你看到的不是图像，是「一堆点」

激光雷达输出的数据，我们叫它点云。说白了就是一堆三维坐标点，每个点包含(x, y, z)信息，有些还带强度值(intensity)。

常见的点云格式：

格式 说明 典型应用
PCD Point Cloud Library原生格式 PCL处理、存储
LAS/LAZ 行业标准格式，支持压缩 测绘、地理信息
PLY 支持顶点和面片 3D建模、可视化
BIN 二进制裸数据 实时传输、嵌入式

在AGV项目里，我最常用的是PCD格式，因为PCL库直接支持，处理起来方便。但如果你做的是嵌入式系统，我建议用BIN格式，省去解析开销。

来看一个简单的点云数据示例（PCD格式）：

# .PCD v0.7 - Point Cloud Data file format
VERSION 0.7
FIELDS x y z intensity
SIZE 4 4 4 4
TYPE F F F F
COUNT 1 1 1 1
WIDTH 5
HEIGHT 1
VIEWPOINT 0 0 0 1 0 0 0
POINTS 5
DATA ascii
0.0 0.0 0.0 100
1.0 0.0 0.0 200
0.0 1.0 0.0 150
0.0 0.0 1.0 180
1.0 1.0 0.0 220

你看，每个点就是一行数据。x、y、z是三维坐标，intensity是反射强度。强度值很有用——比如地面和墙面反射率不同，靠强度就能区分。

5.4 测距原理：TOF vs 三角法

激光雷达测距，主流就两种方法：飞行时间法(TOF)和三角法。

5.4.1 飞行时间法(TOF)

这个原理最简单粗暴：发射激光，等它反射回来，算时间差。光速是已知的，距离 = 光速 × 时间 / 2。

TOF又分两种：

  • 脉冲式：发射一个短脉冲，直接测量飞行时间。精度高，但电路复杂。
  • 相位式：发射连续调制的激光，通过相位差计算距离。精度更高，但测量范围有限。

我在项目中用过的大部分工业级雷达都是TOF的。它的优点是测距远（几十米到上百米），不受环境光影响太大。缺点嘛，就是贵，而且对时间测量精度要求极高——1纳秒的误差对应15厘米的距离偏差。

5.4.2 三角法

三角法就便宜多了。它利用激光发射点和接收器之间的几何关系，通过三角相似形计算距离。说白了就是：激光照到物体上，在接收器上成像的位置会随着距离变化而移动，算一下这个偏移量就能得到距离。

三角法的特点：

  • 近距离精度极高（毫米级）
  • 成本低，适合消费级产品
  • 远距离精度下降严重

我的建议：AGV导航场景，如果工作距离在10米以内，三角法完全够用。但如果你要做室外AGV，或者需要探测20米以上的障碍物，老老实实上TOF。我曾经在一个项目里图便宜用了三角法雷达，结果在室外阳光下直接失效——环境光干扰太严重了。

6 视觉传感器——单目与双目相机、深度相机、视觉里程计初步

各位同学，大家好。今天我们聊聊视觉传感器。

说实话，在AGV导航里，视觉传感器是个让人又爱又恨的东西。爱的是它信息量大，能认路标、能避障、还能做定位；恨的是它数据量太大，处理起来费劲，而且光照一变就容易掉链子。我自己做项目时，没少被视觉折腾过。

好，咱们直接进入正题。

6.1 单目相机：最基础的“一只眼”

单目相机，说白了就是一个摄像头。它拍出来的图像是二维的，没有深度信息。

单目相机能做什么？

  • 特征点提取与匹配：比如ORB、SIFT、SURF这些算法，能从图像里找到角点、边缘，然后在不同帧之间匹配它们。
  • 视觉里程计（VO）：通过连续帧的特征点运动，估算相机的位姿变化。
  • 路标识别：比如识别二维码、AprilTag，或者特定的地面标记。
注意：单目相机无法直接测量深度。它只能通过运动恢复结构（SFM）来估计深度，而且存在尺度不确定性。什么意思呢？就是它不知道物体到底离你1米还是10米，只知道相对比例。

我在项目里遇到过一个问题：单目VO在纯旋转时容易漂移。因为纯旋转时，特征点没有视差，深度估计会失效。嗯，这个坑大家要记住。

6.2 双目相机：两只眼，看出深度

双目相机模仿人眼，用两个摄像头同时拍摄。通过左右图像的视差，可以直接计算出深度。

双目测距的原理：

  • 左眼和右眼看到同一个点，在图像上的位置不同。
  • 这个位置差叫“视差”。
  • 深度 = (基线长度 × 焦距) / 视差。

公式很简单，但实际做起来坑不少。

我的经验：双目相机的基线长度很关键。基线越长，测距精度越高，但视野重叠区域越小。我一般选基线在10-20cm之间，适合室内AGV。

双目相机的优缺点：

优点 缺点
直接获取深度，无需运动 计算量大（立体匹配很费资源）
不受光照影响（红外双目除外） 基线固定，远距离精度差
硬件成本适中 标定复杂，需要左右相机联合标定

我曾经在AGV上用过双目做避障。效果还行，但一到纹理稀疏的墙面，立体匹配就崩了。后来我加了结构光辅助，才算稳定下来。

6.3 深度相机：直接给你深度图

深度相机，比如Intel RealSense、Microsoft Kinect、Orbbec，它们能直接输出深度图像。每个像素的值就是距离。

主流技术方案：

  • 结构光：投射红外点阵，通过变形计算深度。适合室内，受环境光影响大。
  • ToF（飞行时间）：发射红外光，测量反射时间。速度快，但分辨率低。
  • 双目立体：前面讲的双目，但这里指集成化的深度相机。
我的建议：如果AGV在室内、光照可控，用结构光深度相机性价比最高。如果要在室外用，ToF更靠谱，但价格贵一些。

深度相机最大的问题是：容易受干扰。比如阳光里的红外成分，会让结构光失效。还有多台深度相机同时工作时，会互相干扰。我踩过这个坑，后来加了同步信号才解决。

6.4 视觉里程计初步：从图像到运动

视觉里程计（Visual Odometry，VO），就是通过图像序列估算相机运动。它是视觉SLAM的核心模块。

VO的基本流程：

  1. 图像获取：从相机拿到帧。
  2. 特征提取：找角点、边缘等。
  3. 特征匹配：找前后帧的对应点。
  4. 运动估计：用对极几何或PnP算位姿。
  5. 局部优化：用BA（光束法平差）减少误差。

下面是一个简单的单目VO代码示例（使用OpenCV）：

// 伪代码，实际项目要复杂得多
Mat prevImg, currImg;
vector<Point2f> prevPts, currPts;

// 1. 提取特征
goodFeaturesToTrack(prevImg, prevPts, 200, 0.01, 10);

// 2. 光流跟踪
calcOpticalFlowPyrLK(prevImg, currImg, prevPts, currPts, status, err);

// 3. 本质矩阵估计
Mat E = findEssentialMat(currPts, prevPts, focal, pp);

// 4. 恢复位姿
recoverPose(E, currPts, prevPts, R, t, focal, pp);
注意：单目VO恢复的平移向量t只有方向，没有尺度。你需要IMU或轮速计来提供尺度信息。这就是为什么纯视觉VO在AGV上很少单独用。

我个人习惯在VO里加一个关键帧筛选。不是每一帧都处理，而是只选那些运动足够大的帧。这样能减少计算量，还能避免退化。

6.5 三种视觉传感器的对比与选型

咱们做个总结，方便你选型时参考：

传感器类型 深度获取 计算量 适用场景 典型成本
单目相机 间接（需运动） 低 室内、有纹理、配合IMU 低
双目相机 直接（立体匹配） 中高 室内外、纹理丰富 中
深度相机 直接（结构光/ToF） 低 室内、近距离 中高

你想想看，如果AGV在仓库里跑，地面有二维码，用单目就够了。但如果要避障，最好加个深度相机。要是室外环境，双目更靠谱。

避坑指南：我曾经在AGV上只用单目VO，结果在长直走廊里跑偏了。因为走廊纹理重复，特征匹配容易出错。后来我加了IMU做融合，才稳住。所以，视觉传感器最好别单打独斗，融合才是王道。

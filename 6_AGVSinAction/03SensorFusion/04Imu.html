4 惯性测量单元(IMU)——加速度计与陀螺仪原理、标定与零偏补偿

各位同学，今天我们聊聊IMU。说实话，IMU在AGV导航里是个又爱又恨的角色。爱它，是因为它不依赖外部信号，能给你高频的角速度和加速度数据；恨它，是因为它漂移起来，能把你的位姿估计带到沟里去。我最早做AGV项目时，就被IMU的零偏坑过——车子明明停着，积分出来的速度却显示在“漂移”。从那以后，我养成了一个习惯：拿到IMU的第一件事，就是做标定和零偏补偿。

4.1 加速度计与陀螺仪的工作原理

先说说它们是怎么工作的。你想想看，加速度计本质上就是个“弹簧-质量块”系统。当AGV加速时，质量块会因惯性产生位移，这个位移被电容或压阻效应检测到，换算成加速度值。陀螺仪呢？它用的是科里奥利效应——一个振动的质量块在旋转时会产生垂直于振动方向的力，测出这个力就能算出角速度。

嗯，这里要注意：加速度计测的是“比力”，不是纯重力加速度。什么意思？就是它测的是物体受到的合力加速度，包括重力。所以当AGV静止时，加速度计读数是9.8 m/s²，而不是0。我见过不少新手直接拿这个值做积分，结果位置飞了。

核心公式： 
加速度计输出 = 真实加速度 + 重力加速度 + 零偏 + 噪声
陀螺仪输出 = 真实角速度 + 零偏 + 噪声

记住这个公式，后面所有补偿都围绕它展开。

4.2 IMU标定——为什么必须做？

IMU出厂时虽然做过标定，但运输、焊接、温度变化都会让参数偏移。我个人习惯，每块IMU板子到手后，先做一次六位置标定。说白了，就是让IMU的每个轴分别朝上、朝下、朝左、朝右、朝前、朝后，记录静止时的加速度计读数。

为什么要六个位置？因为每个位置下，重力在三个轴上的投影是已知的。比如Z轴朝上时，理论上加速度计输出应该是[0, 0, 9.8]。实际读数和理论值之间的差异，就是标定要补偿的——包括零偏、比例因子和轴间对准误差。

我的经验： 六位置标定最好用水平台面，确保每个方向都严格垂直。我曾经用了个不太平的桌面，结果标定出来的零偏误差大了0.5 mg，导致后续导航精度下降。后来我改用精密转台，问题就解决了。

4.3 零偏补偿——最关键的环节

零偏，就是IMU在静止时输出的非零值。加速度计零偏的单位是mg（毫g），陀螺仪零偏的单位是°/h（度每小时）或°/s。一个好的MEMS IMU，加速度计零偏在±10 mg以内，陀螺仪零偏在±1 °/s以内。但实际项目中，温度变化会让零偏漂移，所以需要实时补偿。

我常用的零偏补偿方法有两种：

  1. 静态初始对准： AGV启动后静止5-10秒，取这段时间IMU输出的平均值作为零偏。这是最简单的方法，但只适用于启动后温度稳定的场景。
  2. 温度补偿模型： 建立零偏与温度的拟合曲线。我一般用二次多项式：Bias(T) = a*T² + b*T + c。标定时让IMU从-20°C升温到80°C，记录每个温度点的零偏，然后拟合出a、b、c三个系数。
避坑指南： 我曾经在零偏补偿时犯过一个低级错误——直接用静态初始对准的值去补偿动态数据。结果AGV一启动，温度变化导致零偏漂移，补偿效果反而更差。后来我改用温度补偿模型，并在每次停车时更新零偏，才解决了这个问题。

4.4 实战：IMU标定与零偏补偿代码

下面是我在项目中用的一段Python代码，用于六位置标定和零偏计算。代码不长，但很实用。

import numpy as np

# 六位置标定数据（加速度计输出，单位：m/s²）
# 每个位置取100个样本的平均值
positions = {
    'z_up':   [0.02, 0.01, 9.82],
    'z_down': [0.01, -0.02, -9.78],
    'x_up':   [9.81, 0.01, 0.02],
    'x_down': [-9.79, -0.01, 0.01],
    'y_up':   [0.01, 9.80, 0.02],
    'y_down': [-0.01, -9.78, 0.01]
}

# 理论值（重力加速度取9.81 m/s²）
g = 9.81
theoretical = {
    'z_up':   [0, 0, g],
    'z_down': [0, 0, -g],
    'x_up':   [g, 0, 0],
    'x_down': [-g, 0, 0],
    'y_up':   [0, g, 0],
    'y_down': [0, -g, 0]
}

# 计算零偏（取所有位置的平均偏差）
bias = np.zeros(3)
count = 0
for key in positions:
    measured = np.array(positions[key])
    theory = np.array(theoretical[key])
    bias += measured - theory
    count += 1
bias /= count

print(f"加速度计零偏: {bias} m/s²")
# 输出示例: [0.01, -0.005, 0.02]

这段代码的核心思想很简单：每个位置下，实际输出减去理论值，得到的就是该位置的偏差。把所有位置的偏差平均，就得到了零偏。当然，这只是最基础的标定。实际项目中，还需要用最小二乘法同时求解零偏、比例因子和轴间误差。

4.6 总结与建议

IMU标定和零偏补偿，说白了就是“把误差找出来，然后减掉”。但实际做起来，细节很多。我最后给你三个建议：

  • 标定环境要稳定： 温度、振动、电磁干扰都会影响标定结果。最好在无风、恒温、无振动的环境下进行。
  • 零偏补偿要动态： 不要只做一次静态补偿。AGV运行过程中，温度变化会导致零偏漂移，所以需要实时更新补偿值。
  • 数据记录要完整： 标定过程中，记录每个位置的原始数据、温度、时间戳。这样后期分析问题时，有据可查。

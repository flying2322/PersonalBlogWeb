11 无迹卡尔曼滤波(UKF)：无迹变换、Sigma点选取、UKF与EKF对比

说到非线性滤波，很多工程师第一反应就是EKF。嗯，EKF确实经典，但说实话，我在实际项目中踩过它不少坑。尤其是当系统非线性特别强的时候，EKF那个一阶泰勒展开，说白了就是「硬凑线性」。你想想看，把一个弯曲的曲面硬掰成平面，误差能不大吗？

后来我开始用UKF，效果确实好不少。今天我就把UKF的核心思路、Sigma点怎么选、以及它和EKF到底差在哪，一次性讲清楚。

11.1 无迹变换：UKF的灵魂

UKF和EKF最大的区别，就在于处理非线性的方式。

EKF的做法是：把非线性函数做泰勒展开，只保留一阶项。说白了就是「近似函数」。

UKF的做法是：我不去近似函数，我去近似概率分布。怎么近似？用一组确定的采样点——也就是Sigma点——去逼近真实分布。

我个人觉得，UKF的思路更优雅。你想想看，既然非线性变换后分布很难算，那我干脆选几个有代表性的点，把它们传过去，再统计结果不就行了？

核心思想：对任意非线性函数 y = f(x)，用一组加权采样点（Sigma点）近似 x 的分布，将这些点通过 f 映射后，加权统计得到 y 的均值和协方差。

我在做AGV的航迹推算时，遇到过IMU的加速度计数据非线性特别强的情况。用EKF，状态估计经常发散。换成UKF后，同样的传感器，同样的运动模型，估计精度直接提升了一个量级。

11.2 Sigma点怎么选？

Sigma点的选取，是UKF里最需要手感的环节。我刚开始用的时候也犯过糊涂，后来总结出一套经验。

标准UKF选取 2n+1 个Sigma点（n是状态维度）：

// 假设状态维度 n = 3，状态向量 x，协方差矩阵 P
// 参数 λ = α²(n + κ) - n，α 控制点的散布范围

// 第0个点：均值点
χ₀ = x̄

// 第1到n个点：沿主成分方向的正向偏移
χᵢ = x̄ + √((n + λ)P)ᵢ    i = 1, ..., n

// 第n+1到2n个点：沿主成分方向的负向偏移
χᵢ = x̄ - √((n + λ)P)ᵢ₋ₙ    i = n+1, ..., 2n

这里有个关键参数 α，我一般取 0.001 到 1 之间。α 越小，Sigma点越靠近均值，对强非线性系统效果越好。但也不能太小，否则数值不稳定。

我的经验：对于AGV的位姿估计，状态维度通常是7维（位置3+姿态4），我习惯取 α=0.1，κ=0，β=2（高斯分布最优值）。这套参数在大多数场景下表现都不错。

每个Sigma点还有对应的权重：

// 均值权重
W₀ᵐ = λ / (n + λ)
Wᵢᵐ = 1 / (2(n + λ))    i = 1, ..., 2n

// 协方差权重
W₀ᶜ = λ / (n + λ) + (1 - α² + β)
Wᵢᶜ = 1 / (2(n + λ))    i = 1, ..., 2n

嗯，这里要注意，均值和协方差的第0个点权重不一样。我刚开始写代码时没注意这个细节，结果协方差矩阵总是不正定，折腾了两天才发现是权重搞混了。

11.4 UKF vs EKF：到底差在哪？

这个问题我经常被问到。直接上对比表：

对比维度 EKF UKF
非线性处理方式 泰勒展开，一阶线性化 无迹变换，采样点传播
精度 一阶精度，强非线性时误差大 二阶精度（高斯分布下），对强非线性更鲁棒
计算复杂度 O(n³)，需要计算雅可比矩阵 O(n³)，但不需要求导
实现难度 需要推导雅可比矩阵，容易出错 无需推导雅可比，直接使用原函数
数值稳定性 线性化误差可能导致发散 无线性化误差，稳定性更好
适用场景 弱非线性、实时性要求极高 强非线性、对精度要求高

避坑指南：我曾经在一个项目中，用EKF做AGV的航向估计。航向角变化剧烈时，EKF的雅可比矩阵计算误差累积，导致滤波器直接发散。换成UKF后，同样的数据，一次跑通。所以如果你的系统非线性强，别犹豫，直接上UKF。

不过话说回来，UKF也不是万能的。它的计算量比EKF大一些，主要是Sigma点传播那一步。如果你的系统状态维度很高（比如超过20维），UKF的计算负担会明显增加。这时候可以考虑用CKF（容积卡尔曼滤波）或者粒子滤波。

11.5 什么时候用UKF？

我个人的经验是：

  • 系统非线性强：比如包含三角函数、四元数旋转、指数函数等，果断用UKF
  • 状态维度适中：n < 20 时，UKF性价比最高
  • 不想推导雅可比：有些模型太复杂，求导不现实，UKF直接上原函数
  • 对精度要求高：比如AGV的厘米级定位，UKF比EKF靠谱

嗯，最后说一句。UKF的代码实现其实比EKF更简洁，因为你不用写那些烦人的雅可比矩阵推导。我建议你从简单的2D定位问题开始练手，跑通一次之后，你就会爱上这种「无脑传点」的感觉。

一句话总结：EKF是「近似函数」，UKF是「近似分布」。UKF用一组确定的点，换来了更高的精度和更好的稳定性。代价？多算几次函数而已，值！

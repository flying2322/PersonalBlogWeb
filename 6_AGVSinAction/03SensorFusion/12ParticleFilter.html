12 粒子滤波(PF)：蒙特卡洛方法、重要性采样、重采样、粒子滤波定位

粒子滤波，这个名字听起来挺唬人的。其实说白了，它就是一套「用一堆随机点去猜位置」的方法。

我刚开始接触SLAM的时候，对粒子滤波也是一头雾水。后来在AGV项目里调试定位，遇到一个特别头疼的问题——机器人从仓库出来，经过一段长长的金属货架走廊，激光雷达数据全是噪点，卡尔曼滤波直接崩了。嗯，那时候我才真正意识到，有些场景下，你非得用粒子滤波不可。

蒙特卡洛方法：用随机数解决确定性问题

蒙特卡洛方法的核心思想，我总结成一句话：如果算不出来，那就猜，多猜几次就准了。

举个例子。你想知道一个不规则形状的面积，用公式算很麻烦。怎么办？往这个形状里随机撒点，数一数落在里面的点占总点数的比例，再乘以整个包围盒的面积，就得到了近似值。撒的点越多，结果越准。

在定位问题里，我们面对的是同样的困境。机器人的真实位置是一个连续空间里的未知数，我们没法精确知道它在哪里。但我们可以撒一堆「粒子」——每个粒子代表一个可能的位置假设。然后让这些粒子在状态空间里传播、更新、筛选。

关键理解：粒子数量决定了估计精度，也决定了计算开销。我一般建议在AGV场景下用500-2000个粒子。太少容易发散，太多实时性扛不住。

重要性采样：给每个粒子打分

粒子撒下去了，问题来了——哪些粒子更可信？

这就是重要性采样登场的时候。每个粒子都有一个权重，权重越高，代表这个粒子与当前观测数据越吻合。

我记得有一次调试，发现机器人明明在走廊中间，但粒子全都聚集在墙边。排查了半天，发现是激光观测模型写错了——我把激光击中障碍物的概率算反了。嗯，这种坑踩过一次就记住了。

重要性采样的流程其实很简单：

  1. 预测阶段：根据运动模型，让每个粒子向前走一步（加一点噪声）
  2. 更新阶段：用当前传感器观测数据，计算每个粒子的似然概率
  3. 权重归一化：把所有粒子的权重加起来，每个权重除以总和

我的经验：权重计算这一步最容易出bug。建议先写一个简单的仿真环境，用已知轨迹验证权重计算是否正确。别问我怎么知道的——我debug了整整两天才发现是角度单位搞混了。

重采样：优胜劣汰

重要性采样之后，你会发现一个问题：大部分粒子的权重变得很小，只有少数几个粒子权重很大。这就是所谓的「粒子退化」现象。

怎么办？重采样。

重采样的本质就是「把权重高的粒子复制几份，把权重低的粒子扔掉」。这样，粒子总数不变，但分布更集中在高概率区域。

常用的重采样方法有几种：

方法名称 原理 我个人的评价
多项式重采样 按权重比例随机抽取 实现简单，但方差较大
残差重采样 先确定保留份数，再随机补全 效率高，我项目里常用这个
系统重采样 等间隔抽取，减少随机性 稳定性好，适合高精度场景

注意：重采样不是越多越好。频繁重采样会导致「粒子贫化」——所有粒子都挤在一起，失去了多样性。我一般建议在有效粒子数低于总粒子数的一半时才触发重采样。

粒子滤波定位：从理论到实践

好了，把上面三块拼起来，就是完整的粒子滤波定位流程。我画了一张图，帮你理清整个逻辑：

实际写代码的时候，我习惯把粒子滤波封装成一个类。核心接口就三个：predict()、update()、resample()。这样调试起来方便，哪个环节出问题了直接定位。

class ParticleFilter:
    def __init__(self, num_particles=1000):
        self.particles = np.random.rand(num_particles, 3)  # x, y, theta
        self.weights = np.ones(num_particles) / num_particles
    
    def predict(self, control, noise_std):
        # 运动模型：加噪声
        self.particles += control + np.random.randn(*self.particles.shape) * noise_std
    
    def update(self, observation, map_data):
        # 计算每个粒子的观测似然
        for i, p in enumerate(self.particles):
            expected = self.raycast(p, map_data)
            self.weights[i] = self.likelihood(observation, expected)
        self.weights /= np.sum(self.weights)  # 归一化
    
    def resample(self):
        # 系统重采样
        cumsum = np.cumsum(self.weights)
        step = cumsum[-1] / len(self.particles)
        positions = np.arange(0, cumsum[-1], step) + np.random.rand() * step
        indices = np.searchsorted(cumsum, positions)
        self.particles = self.particles[indices]
        self.weights = np.ones_like(self.weights) / len(self.weights)

避坑指南：我曾经在重采样后忘记重置权重，导致下一轮权重累加时出现NaN。另外，粒子数量建议设置成2的幂次方（比如1024），这样在某些硬件加速场景下有奇效。

粒子滤波最大的优势是什么？它能处理非高斯、多模态的分布。什么意思呢？就是机器人可能同时觉得「我在A点」和「我在B点」都有道理——比如在对称的走廊里。卡尔曼滤波遇到这种情况就傻了，但粒子滤波可以同时保留这两种假设，直到后续观测数据打破歧义。

当然，粒子滤波也有短板。计算量大、维度灾难（超过4维就很容易发散）、粒子退化问题。所以在实际AGV项目中，我通常的做法是：正常场景用卡尔曼滤波，遇到激光退化或者绑架问题时，切换到粒子滤波做全局重定位。两者互补，效果最好。

嗯，粒子滤波就讲到这里。这套方法虽然老，但在实际工程中依然能打。关键是要理解它的本质——用一群随机样本去逼近真实分布，而不是试图精确求解。

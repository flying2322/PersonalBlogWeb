5 路径规划模块设计

路径规划，说白了就是回答两个问题：「往哪走」和「怎么走」。全局规划告诉你大方向，局部规划处理眼前的障碍物。我做了这么多年AGV，见过太多「全局规划跑得挺好，一遇到动态障碍就撞墙」的案例。嗯，这里面的坑，咱们一个一个说。

核心观点：全局规划负责「可行性」，局部规划负责「安全性」。两者缺一不可。

5.1 全局路径规划

全局规划的前提是——你已经有一张静态地图。这张图可以是栅格地图、拓扑地图，或者几何地图。我个人习惯用栅格地图，因为它对A*和Dijkstra都很友好。

5.1.1 Dijkstra算法

Dijkstra是个「老实人」算法。它从起点开始，一层一层往外扩，直到找到终点。优点是一定能找到最短路径，缺点是慢——尤其是在大场景下。

我在项目中遇到过一个问题：一个200m×200m的仓库，栅格分辨率0.1m，Dijkstra跑一次要十几秒。你想想看，AGV都停在那等路径，这谁受得了？

// 伪代码：Dijkstra核心逻辑
function Dijkstra(graph, start, goal):
    open_set = {start}
    came_from = {}
    g_score[start] = 0
    
    while open_set is not empty:
        current = node in open_set with lowest g_score
        if current == goal:
            return reconstruct_path(came_from, current)
        
        open_set.remove(current)
        for neighbor in graph.neighbors(current):
            tentative_g = g_score[current] + dist(current, neighbor)
            if tentative_g < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                if neighbor not in open_set:
                    open_set.add(neighbor)
    return failure

避坑指南：我曾经在动态障碍物频繁的场景里用Dijkstra做实时重规划，结果CPU直接拉满。后来我改用分层策略——先Dijkstra算粗路径，再用局部规划细化。效果立竿见影。

5.1.2 A*算法

A*是Dijkstra的「升级版」。它加了一个启发函数h(n)，告诉算法「终点大概在这个方向」。说白了，就是给搜索过程加了个导航。

启发函数怎么选？我一般用欧几里得距离或曼哈顿距离。前者适合自由移动的场景，后者适合网格化移动（比如四轮AGV）。

// 伪代码：A*核心逻辑
function AStar(graph, start, goal):
    open_set = {start}
    came_from = {}
    g_score[start] = 0
    f_score[start] = h(start, goal)  // 启发函数
    
    while open_set is not empty:
        current = node in open_set with lowest f_score
        if current == goal:
            return reconstruct_path(came_from, current)
        
        open_set.remove(current)
        for neighbor in graph.neighbors(current):
            tentative_g = g_score[current] + dist(current, neighbor)
            if tentative_g < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score[neighbor] = g_score[neighbor] + h(neighbor, goal)
                if neighbor not in open_set:
                    open_set.add(neighbor)
    return failure

经验之谈：A*的启发函数h(n)如果设置成0，它就退化成Dijkstra。如果h(n)过大，它可能找不到最优解。我一般取h(n)为实际距离的1.0~1.2倍，既保证最优性，又加速搜索。

5.2 局部路径规划

全局路径规划完了，你以为就完事了？不，真正的挑战才刚刚开始。局部规划要处理的是：动态障碍物、传感器噪声、控制误差。说白了，就是「计划赶不上变化」时的应对策略。

5.2.1 DWA（动态窗口法）

DWA的思路很直接：在速度空间里采样，找一条能避开障碍、又能靠近目标的速度曲线。它只考虑当前时刻的速度和角速度，所以计算量很小。

我记得有一次，AGV在走廊里遇到一个突然窜出来的行人。全局路径根本来不及更新，但DWA在20ms内就给出了避障速度。嗯，这就是局部规划的价值。

// 伪代码：DWA核心逻辑
function DWA(state, goal, obstacles):
    // 1. 在速度空间采样
    for v in [v_min, v_max]:
        for w in [w_min, w_max]:
            // 2. 预测轨迹
            trajectory = predict_trajectory(state, v, w)
            // 3. 评估轨迹
            cost = evaluate(trajectory, goal, obstacles)
            // 4. 选择最优
            if cost < best_cost:
                best_cost = cost
                best_v = v
                best_w = w
    return (best_v, best_w)

注意：DWA有个致命弱点——它只考虑当前时刻，容易陷入局部最优。比如遇到U形障碍物，DWA可能会在里面打转。这时候就需要全局规划介入，重新算一条路径。

5.2.2 TEB（时间弹性带）

TEB比DWA「聪明」一点。它不光考虑当前时刻，还考虑未来一段时间的轨迹。说白了，就是优化一条「时间-空间」的弹性带子。

TEB的核心思想是：在满足运动学约束的前提下，让轨迹尽可能短、尽可能平滑、尽可能远离障碍物。它用图优化（g2o）来求解，所以精度很高。

我在项目中遇到过一个问题：TEB在狭窄通道里表现很好，但在开阔地带反而容易「抖动」。后来我加了速度平滑项，才解决了这个问题。

个人建议：如果你的AGV在室内运行，障碍物多且动态，优先选TEB。如果是在开阔的室外，DWA就够用了。别盲目追求「高级」算法，适合场景的才是最好的。

5.3 路径平滑与插值

不管是全局规划还是局部规划，算出来的路径都是「折线」。AGV直接沿着折线走，会出现两个问题：

  • 急转弯：AGV的转向机构受不了，容易磨损
  • 速度突变：乘客（如果有）会感到不适

所以，我们需要对路径做平滑处理。常用的方法有：

方法 原理 适用场景
贝塞尔曲线 用控制点生成平滑曲线 路径点较少，需要快速生成
样条插值 分段多项式拟合 路径点密集，需要高精度
梯度下降平滑 迭代优化路径曲率 需要实时调整的场景

我个人的习惯是：先用样条插值做一次平滑，再用梯度下降微调。这样既保证了平滑度，又不会偏离原始路径太远。

// 伪代码：样条插值平滑
function spline_smooth(path):
    // 输入：原始路径点列表
    // 输出：平滑后的路径点列表
    n = len(path)
    // 构建三对角矩阵
    A = build_tridiagonal_matrix(n)
    b = build_constraint_vector(path)
    // 求解线性方程组
    coefficients = solve(A, b)
    // 生成平滑路径
    smooth_path = []
    for i in range(n-1):
        for t in [0, 0.1, 0.2, ..., 1.0]:
            point = evaluate_spline(coefficients[i], t)
            smooth_path.append(point)
    return smooth_path

核心要点：路径平滑不是「越平滑越好」。过度平滑会让路径偏离原始路径，导致AGV撞到障碍物。我一般控制平滑后的路径与原始路径的最大偏差不超过5cm。

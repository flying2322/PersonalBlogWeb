26 AGV控制器生产流程概览

做AGV控制器这么多年，我最大的感触就是：设计得再好，生产环节掉链子也是白搭。今天咱们聊聊控制器从图纸变成实物的全过程——SMT贴片、ICT测试、FCT测试、老化测试，这四个环节一个都不能少。

说白了，这四步就是从「焊好」到「测通」再到「跑稳」的过程。我见过不少团队跳过ICT直接做FCT，结果出了问题排查半天，最后发现是虚焊——白白浪费了时间。

二、SMT贴片流程

2.1 贴片前的准备

SMT贴片，就是把元器件焊到PCB上。听起来简单，但细节决定成败。

我个人习惯在贴片前做三件事：

  • 钢网检查——钢网开口尺寸对不对？厚度是否合适？AGV控制器上有不少大电流MOS管，焊盘尺寸和普通信号焊盘不一样，钢网开错了就是批量事故。
  • 物料核对——电容耐压值、电阻精度、IC批次，一个都不能错。我曾经遇到过一批0402电容贴错，整板电源纹波超标，排查了三天。
  • 炉温曲线验证——无铅焊接的炉温曲线，峰值温度235-245℃，升温斜率1-3℃/秒。这个参数每家板厂略有差异，但必须实测验证。
✅ 贴片关键参数表
参数项 要求值 检测方法
锡膏厚度 0.12-0.15mm SPI检测
贴片精度 ±0.05mm AOI光学检测
回流焊峰值温度 235-245℃ 炉温测试仪
焊接空洞率 ≤25% X-Ray抽检

2.2 贴片流程详解

标准的SMT流程分这几步：

  1. 锡膏印刷——用钢网把锡膏印到PCB焊盘上。这里要注意，AGV控制器上的BGA芯片对锡膏量很敏感，多了会短路，少了会虚焊。
  2. 贴片机贴装——高速机贴小元件，泛用机贴大元件和异形件。我建议把MCU、DDR这些关键芯片放在最后贴，减少静电损伤风险。
  3. 回流焊接——经过预热、恒温、回流、冷却四个温区。嗯，这里要注意，冷却速率太快会导致焊点裂纹，尤其是陶瓷电容。
  4. AOI光学检测——自动检测焊点质量，比如少锡、连锡、立碑等缺陷。
💡 我的经验

AGV控制器上有个容易忽略的地方——连接器焊盘。像JST、Molex这类接插件，焊盘间距小，而且经常要承受插拔力。我建议在贴片后增加一道X-Ray抽检，重点关注BGA和连接器焊点。别问我为什么，吃过亏的人都知道。

三、ICT测试

3.1 什么是ICT

ICT，全称In-Circuit Test，在线测试。说白了，就是给板子通电之前，先测一遍每个元器件对不对。

ICT测试的核心原理是飞针测试或针床测试。通过探针接触PCB上的测试点，测量电阻、电容、电感、二极管、三极管等元件的参数，以及检查是否有短路、开路。

3.2 ICT测试项目

我个人习惯把ICT测试分成三类：

  • 开路/短路测试——检查网络之间有没有不该连的地方，或者该连的地方没连上。这是最基本的，也是最重要的。
  • 元件值测试——电阻阻值、电容容值、电感感值，是否在规格范围内。比如AGV控制器上的电源滤波电容，容值偏差超过20%就可能引起纹波超标。
  • 二极管/三极管方向测试——极性元件装反了，上电就炸。ICT可以测出PN结的正向压降，判断方向是否正确。
⚠️ 避坑指南

我曾经遇到过一个案例：ICT测试全部通过，但整机一上电就烧保险丝。查了半天，发现是PCB上有个过孔设计得太靠近螺丝孔，安装时螺丝压到了过孔，造成短路。ICT测不到这个，因为测试时没装螺丝。

所以ICT不是万能的，它只能测静态的电气特性。动态问题、装配问题，还得靠后面的FCT和老化来发现。

3.3 ICT测试覆盖率

ICT的测试覆盖率，一般要求达到90%以上。但AGV控制器这种复杂板卡，我建议做到95%以上。

怎么提高覆盖率？

  • 设计阶段就预留测试点，每个网络至少一个测试点
  • 关键信号（电源、时钟、复位）必须可测
  • BGA芯片的焊点，通过外围测试点间接验证

四、FCT测试

4.1 FCT测试内容

FCT，Functional Circuit Test，功能测试。ICT测的是「元件对不对」，FCT测的是「功能好不好」。

AGV控制器的FCT测试，我一般分这几个模块：

测试模块 测试项目 判定标准
电源模块 各电压输出、纹波、上电时序 ±5%以内，纹波<50mV
MCU模块 时钟频率、复位、JTAG通信 频率偏差<1%
通信模块 CAN、RS485、以太网、WiFi 收发正常，误码率<1e-6
驱动接口 PWM输出、编码器输入、IO口 电平、频率、占空比符合规格
传感器接口 IMU、激光雷达、超声波 数据读取正常

4.2 FCT测试流程

FCT测试通常需要测试工装。工装里有个「金板」——就是一块确认没问题的标准板。每次测试前，先用金板校准测试系统。

测试流程大致如下：

  1. 上电自检——板子自己跑一遍初始化，检查各模块是否正常
  2. 电压测量——用ADC采集各电源轨的电压值
  3. 通信环回——CAN口发数据自己收，以太网Ping测试
  4. IO测试——逐个控制IO口输出，再读取回检
  5. PWM测试——输出指定频率和占空比的PWM，用示波器验证
🔧 实用技巧

FCT测试脚本我建议用Python写，配合pySerial和pyVISA库，可以很方便地控制仪器和读取数据。下面是一个简单的CAN通信测试代码片段：

import can
import time

# 初始化CAN接口
bus = can.interface.Bus(channel='can0', bustype='socketcan')

# 发送测试帧
msg = can.Message(arbitration_id=0x123, data=[0x11, 0x22, 0x33, 0x44], is_extended_id=False)
bus.send(msg)

# 接收回环帧
response = bus.recv(timeout=1.0)
if response and response.data == [0x11, 0x22, 0x33, 0x44]:
    print("CAN通信测试通过")
else:
    print("CAN通信测试失败")

五、老化测试

5.1 为什么要做老化

老化测试，说白了就是让板子「跑起来」，看看它能不能扛得住。很多问题在常温下测不出来，但一跑高温、一跑长时间，就原形毕露了。

我见过最典型的例子：有一批控制器，FCT全部通过，但客户用了三天就死机。查到最后，是DDR内存颗粒的时序余量不够，温度一高就出错。这种问题，只有老化才能发现。

5.2 老化测试方案

AGV控制器的老化测试，我建议分三步走：

  • 高温老化——60℃环境下连续运行48小时。模拟夏天仓库、车间的高温环境。
  • 温度循环——-20℃到70℃循环10次，每次2小时。检查焊点和芯片的耐温应力。
  • 振动测试——模拟AGV行驶过程中的振动。频率10-500Hz，加速度2g，每个方向2小时。
⚠️ 重要提醒

老化测试不是「烤机」那么简单。我建议在老化过程中实时监控以下参数：

  • 核心温度（MCU内部温度传感器）
  • 电源电流（是否有异常增大）
  • 通信状态（CAN总线是否有丢帧）
  • 看门狗复位次数（复位次数多了说明有问题）

这些数据记录下来，形成每块板子的「老化曲线」。以后出了问题，翻出老化数据一看，就知道是不是早期隐患。

5.3 老化通过标准

我个人习惯的判定标准：

项目 合格标准
高温老化 48小时无死机、无复位、无通信中断
温度循环 10次循环后功能正常，无焊点开裂
振动测试 测试后无松动、无电气性能下降
整体判定 三项全部通过，方可出货

六、总结与建议

AGV控制器的生产测试，说白了就是一道「质量防火墙」。SMT贴片保证焊好，ICT保证元件对，FCT保证功能全，老化保证用得久。四道关卡，缺一不可。

最后给几个实用建议：

  • 测试数据要存档——每块板子的ICT、FCT、老化数据，保存至少2年。出了问题可以追溯。
  • 定期校准测试设备——ICT针床、FCT工装、老化箱，半年校准一次。设备不准，测了等于没测。
  • 建立不良品分析机制——每块不良品都要分析根因，是设计问题还是工艺问题？然后反馈改进。

嗯，今天就聊到这儿。AGV控制器看着简单，但真正做好生产测试，需要的是细心和耐心。希望这些经验对你有帮助。

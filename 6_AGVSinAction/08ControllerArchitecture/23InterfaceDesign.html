23 AGV控制器接口设计：GPIO接口、PWM接口、ADC接口、I2C/SPI接口、USB接口

各位做AGV的同行，今天我们来聊聊控制器接口设计。说实话，接口这块儿看着简单，但坑是真不少。我见过太多项目因为接口没设计好，最后调试时抓耳挠腮。今天我把这些年踩过的坑、积累的经验，一次性说清楚。

23.1 GPIO接口：最基础也最容易出问题

GPIO，说白了就是通用输入输出。在AGV上，它用来接限位开关、急停按钮、状态指示灯这些。嗯，这里要注意——不是所有GPIO都一样。

避坑指南：我曾经在一个项目中，直接用3.3V的GPIO去驱动一个5V的继电器，结果烧了三个IO口。后来学乖了，所有对外接口都加电平转换。

我个人的设计习惯是这样的：

  • 输入型GPIO：必须加上拉或下拉电阻，防止悬空时误触发
  • 输出型GPIO：驱动能力要留余量，一般按80%额定值使用
  • 中断型GPIO：要加硬件去抖，RC滤波或者施密特触发器都行

给大家看一个我常用的GPIO配置代码片段：

// GPIO初始化示例
void gpio_init(void) {
    // 急停按钮 - 输入，内部上拉
    GPIO_SetMode(PB, BIT0, GPIO_MODE_INPUT);
    GPIO_EnablePullup(PB, BIT0);
    
    // 状态指示灯 - 输出，推挽
    GPIO_SetMode(PC, BIT1, GPIO_MODE_OUTPUT);
    GPIO_SetDriveCapability(PC, BIT1, GPIO_DRIVE_LEVEL_2);
    
    // 编码器Z相 - 中断输入，下降沿触发
    GPIO_SetMode(PA, BIT2, GPIO_MODE_INPUT);
    GPIO_EnableInterrupt(PA, BIT2, GPIO_INT_FALLING);
}

23.2 PWM接口：电机控制的灵魂

PWM在AGV上主要用来控制电机速度和舵机角度。你想想看，如果PWM频率选错了，电机要么嗡嗡响，要么扭矩不够。

我建议按这个原则选频率：

应用场景 推荐频率 原因
直流有刷电机 10kHz - 20kHz 避开人耳可听范围，减少噪音
步进电机 20kHz - 40kHz 保证细分驱动精度
舵机 50Hz 标准舵机协议要求
LED调光 100Hz - 1kHz 避免肉眼可见闪烁
经验之谈：我在做AGV底盘驱动时，发现PWM分辨率至少需要12位。8位的PWM在低速时步进感太明显，车子会一抖一抖的。

23.3 ADC接口：感知模拟世界的窗口

ADC用来采集电池电压、电流检测、超声波传感器等模拟信号。这里有个关键点——参考电压。

我记得有一次，AGV在仓库里跑着跑着，电池电量突然从50%跳变到10%。查了半天，原来是ADC的参考电压受温度影响了。从那以后，我所有设计都用外部精密参考源。

ADC设计要点：

  • 采样率：电池电压这类慢变信号，100Hz就够了；电流检测建议1kHz以上
  • 分辨率：12位是底线，16位更安心
  • 抗混叠滤波：ADC前端必须加RC低通滤波，截止频率设为采样率的1/2以下
// ADC多通道采集示例
uint16_t adc_values[4];

void adc_read_channels(void) {
    for(int i = 0; i < 4; i++) {
        ADC_SetChannel(ADC0, i);
        ADC_Start(ADC0);
        while(ADC_IsBusy(ADC0));
        adc_values[i] = ADC_GetValue(ADC0);
        
        // 软件滤波：中值+均值
        adc_values[i] = median_filter(adc_values[i], 5);
    }
}

23.4 I2C/SPI接口：内部通信的命脉

I2C和SPI在AGV控制器内部用得最多。IMU、磁力计、一些扩展IO芯片，都靠它们通信。

我个人习惯这样区分使用场景：

  • I2C：适合接传感器，速率要求不高，但需要多设备共享总线
  • SPI：适合接ADC、DAC、Flash，速率高，但占用IO多
曾经踩过的坑：I2C总线上挂了5个设备，结果通信老是出错。后来发现是总线电容太大，上拉电阻没选对。记住：设备越多，上拉电阻要越小。

I2C上拉电阻选择参考：

总线设备数 总线电容 推荐上拉电阻
1-2个 <100pF 4.7kΩ
3-5个 100-200pF 2.2kΩ
5个以上 >200pF 1kΩ

23.5 USB接口：调试与升级的桥梁

USB接口在AGV上主要做三件事：固件升级、参数配置、日志输出。别小看这个接口，设计不好会严重影响开发效率。

我建议：

  • 物理层：用USB Type-C，正反插都行，省得现场工程师抱怨
  • 协议层：用CDC虚拟串口，兼容性最好，任何电脑都能识别
  • 保护电路：必须加ESD防护和限流芯片，USB热插拔时最容易烧主控
核心观点：接口设计不是简单地把引脚引出来就完事了。每个接口都要考虑电气特性、保护电路、软件协议这三个层面。少一个，现场就会多一个坑。

好了，接口设计这块儿就聊到这儿。记住一句话：接口是控制器和外界打交道的窗口，设计得好，后面调试顺风顺水；设计得不好，那就是给自己挖坑。希望我这些经验能帮大家少走些弯路。

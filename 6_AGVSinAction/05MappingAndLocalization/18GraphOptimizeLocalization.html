18 基于图优化的定位：因子图构建、非线性优化求解、iSAM2算法

各位同学，今天我们来聊聊定位中的“硬核”部分——图优化。说实话，我早年做AGV导航时，用的还是扩展卡尔曼滤波（EKF）。那时候觉得EKF挺香的，直到有一次在复杂仓库里，AGV定位飘了，差点撞上货架。从那以后，我彻底转向了图优化。今天就把我的经验分享给你。

18.1 为什么是图优化？

你想想看，传统的滤波方法（比如EKF）有个毛病：它只关心当前状态，过去的观测用一次就扔了。这就像你走路只看脚下，不看走过的路——很容易迷路。

图优化不一样。它把所有的位姿（Pose）和观测都记录下来，构建成一个图。然后通过优化，让整个图“自洽”。说白了，就是让所有约束都尽量满足。

核心思想：把定位问题转化为一个最小二乘问题。我们有一堆节点（位姿）和一堆边（约束），目标是调整节点位置，让边的误差最小。

18.2 因子图构建

因子图（Factor Graph）是图优化的一种具体实现。我习惯把它看作一个“积木模型”：

  • 变量节点：AGV的位姿（x, y, θ），还有路标点（Landmark）的位置。
  • 因子节点：各种约束，比如里程计约束、激光匹配约束、GPS约束等。

举个例子，假设AGV在时刻t1和t2有两个位姿节点x1和x2。里程计告诉我们从x1到x2的位移是Δx。那么我们就添加一个里程计因子，连接x1和x2。这个因子的“任务”就是让x2 - x1 ≈ Δx。

再比如，AGV在x1位置观测到一个路标点L。激光雷达告诉我们距离和角度。我们就添加一个观测因子，连接x1和L。它的任务是让观测模型算出来的值等于实际测量值。

我的经验：因子图构建时，千万别贪多。我见过有人把几百个因子塞进去，结果优化半天不收敛。建议先加关键因子（里程计+激光匹配），跑通了再加别的。

18.3 非线性优化求解

因子图建好了，接下来就是求解。这本质上是一个非线性最小二乘问题：

min Σ ||e_i(x)||²

其中e_i(x)是第i个因子的误差函数。比如里程计因子的误差就是：

e_odom = (x2 - x1) - Δx

求解方法我常用高斯-牛顿法（Gauss-Newton）或列文伯格-马夸尔特法（LM）。步骤很简单：

  1. 给所有变量一个初始值（通常用里程计推算）
  2. 计算每个因子的误差和雅可比矩阵
  3. 构建线性系统 H·Δx = b
  4. 求解Δx，更新变量
  5. 重复直到收敛

这里有个坑：雅可比矩阵一定要算对。我曾经因为一个符号写反，导致优化结果发散，查了三天bug。嗯，从那以后我写雅可比都会手动验证一遍。

注意事项：非线性优化对初值敏感。如果初值离真实值太远，可能收敛到局部最优。建议先用里程计或IMU做初步估计，再用图优化精调。

18.4 iSAM2算法

传统的图优化是“批处理”的——每次有新数据，都要重新优化整个图。这在实时系统中很要命。你想想看，AGV每秒产生几十个数据，每次都全图优化，CPU直接爆炸。

iSAM2（Incremental Smoothing and Mapping 2）就是来解决这个问题的。它的核心思想是：只更新受影响的部分。

具体来说，iSAM2做了两件事：

  • 贝叶斯树（Bayes Tree）：把因子图转换成一种树形结构。新数据只影响树的一部分，不用动整棵树。
  • 增量更新：只重新计算受影响节点的雅可比和H矩阵，其他部分保持不变。

我举个例子。假设AGV在走廊里直行，突然拐了个弯。传统方法会把从起点到拐弯的所有位姿都重新优化一遍。iSAM2呢？它只优化拐弯附近的那几个位姿，前面的位姿基本不动。效率高了一个数量级。

iSAM2的优势：

  • 实时性：每次更新只处理局部，计算量小
  • 精度：和全图优化几乎一样
  • 内存：只保存贝叶斯树，不保存全图

18.5 实战：一个简单的因子图定位

下面我给出一个简化版的代码示例，用Python和GTSAM库实现。GTSAM是iSAM2的经典实现库。

import gtsam

# 1. 创建因子图
graph = gtsam.NonlinearFactorGraph()

# 2. 添加里程计因子
# 假设从x1到x2的里程计测量是(1.0, 0.0, 0.0)
odom_noise = gtsam.noiseModel.Diagonal.Sigmas([0.1, 0.1, 0.05])
graph.add(gtsam.BetweenFactorPose2(1, 2, gtsam.Pose2(1.0, 0.0, 0.0), odom_noise))

# 3. 添加观测因子
# 在x1位置观测到路标点L1，测量值为(2.0, 0.0)
measurement_noise = gtsam.noiseModel.Diagonal.Sigmas([0.1, 0.1])
graph.add(gtsam.BearingRangeFactor2D(1, 0, gtsam.Rot2(0.0), 2.0, measurement_noise))

# 4. 设置初始值
initial_estimate = gtsam.Values()
initial_estimate.insert(1, gtsam.Pose2(0.0, 0.0, 0.0))
initial_estimate.insert(2, gtsam.Pose2(1.1, 0.0, 0.0))  # 带一点噪声
initial_estimate.insert(0, gtsam.Point2(2.0, 0.0))

# 5. 使用iSAM2求解
isam = gtsam.ISAM2()
isam.update(graph, initial_estimate)
result = isam.calculateEstimate()

# 6. 输出结果
print("优化后的位姿x2:", result.atPose2(2))
print("优化后的路标点L:", result.atPoint2(0))

这段代码虽然简单，但涵盖了因子图优化的核心流程。我在实际项目中，就是在这个基础上加了更多因子（比如闭环检测因子），跑起来效果很好。

18.6 避坑指南

最后，我总结几个实战中容易踩的坑：

  • 噪声模型别乱设：里程计噪声和激光噪声的量级差很多。我习惯先做标定，拿到真实噪声方差再设参数。
  • 闭环检测要谨慎：错误的闭环会毁掉整个优化。我一般会加一个“置信度”阈值，低于阈值的闭环直接丢弃。
  • 内存管理：iSAM2虽然高效，但长时间运行后贝叶斯树会膨胀。建议定期做一次全图优化，清理冗余节点。

我的小技巧：调试时，先把所有因子可视化出来。看看误差大的因子在哪里，往往能快速定位问题。我常用Python的matplotlib画图，一目了然。

好了，关于基于图优化的定位，我就讲这么多。因子图构建、非线性优化求解、iSAM2算法，这三块是核心。你只要把原理搞懂，代码跑通，AGV定位这块基本就稳了。

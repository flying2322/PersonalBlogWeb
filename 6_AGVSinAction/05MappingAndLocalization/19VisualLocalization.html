19 视觉定位：基于关键帧的视觉定位、PnP求解、视觉重定位

视觉定位这个话题，说白了就是让AGV知道自己“在哪儿”。

我刚开始做AGV项目时，总觉得GPS或者激光雷达就够了。直到有一次在室内仓库测试，激光雷达被货架上的反光条搞得晕头转向，我才意识到——视觉定位，有时候是唯一的选择。

19.1 基于关键帧的视觉定位

关键帧这个概念，其实是从SLAM里借过来的。你想想看，如果每一帧图像都拿来算，AGV的算力根本扛不住。所以我们需要挑出那些“有代表性”的帧。

什么样的帧算关键帧？

  • 视差足够大：当前帧和上一个关键帧之间，相机移动了足够距离
  • 特征点数量达标：至少提取到50~100个稳定的ORB特征点
  • 质量合格：没有运动模糊，光照变化不大

我个人习惯的做法是：每移动0.5米或者旋转15度，就触发一次关键帧检测。当然，这个阈值要根据AGV的速度和场景来调。

我的经验： 在AGV上做关键帧选取，别太贪心。我曾经设了0.2米的阈值，结果关键帧堆成山，后端优化直接卡死。后来改成0.8米，效果反而更好。

19.2 PnP求解——从2D到3D的桥梁

PnP（Perspective-n-Point）解决的是这样一个问题：已知3D空间中的点，和它们在图像上的2D投影，求相机的位置和姿态。

说白了，就是给你一堆“已知坐标的路标”，你通过照片反推自己站在哪儿、脸朝哪边。

常用的PnP求解方法：

方法 特点 适用场景
EPnP O(n)复杂度，速度快 特征点较多时（>15个）
P3P 只需要3个点，精度一般 特征点稀疏时
DLT 直接线性变换，简单粗暴 初值估计
BA优化 精度最高，但计算量大 后端优化、重定位

嗯，这里要注意：PnP求解对匹配点的质量非常敏感。如果匹配错了，结果直接飞掉。

避坑指南： 我曾经在AGV上直接用RANSAC+EPnP，结果在纹理重复的仓库里频繁跳变。后来加了“先验位姿约束”——把上一帧的位姿作为初值，再用EPnP微调，稳定性提升了一大截。

19.3 视觉重定位——丢了也能找回来

AGV跑着跑着，突然遇到一片白墙，或者被叉车挡住了视线——视觉跟踪丢了。这时候就需要重定位。

视觉重定位的核心思路是：用当前图像去地图里“找”最相似的关键帧。

重定位的典型流程：

  1. 提取当前帧的特征点（ORB、SIFT等）
  2. 用词袋模型（BoW）快速检索，找到候选关键帧
  3. 特征匹配，验证几何一致性
  4. PnP求解，恢复位姿
  5. 局部BA优化，精调结果

我建议你在做重定位时，一定要设置一个“置信度阈值”。比如匹配点数少于30个，或者重投影误差大于5像素，就判定重定位失败，重新搜索。

核心要点： 重定位的成功率，取决于地图的质量。如果关键帧覆盖足够密、特征点足够丰富，重定位基本秒级完成。反之，地图稀疏的话，重定位就是碰运气。

19.5 代码示例：基于OpenCV的PnP求解

下面是我在实际项目中用过的PnP求解代码片段。注意，这里用了RANSAC来剔除误匹配。

# 基于OpenCV的PnP求解示例
import cv2
import numpy as np

def solve_pnp_with_ransac(object_points, image_points, camera_matrix, dist_coeffs):
    """
    使用EPnP + RANSAC求解相机位姿
    object_points: 世界坐标系下的3D点 (N, 3)
    image_points: 对应的2D像素坐标 (N, 2)
    """
    # 确保输入是float32
    obj_pts = np.array(object_points, dtype=np.float32)
    img_pts = np.array(image_points, dtype=np.float32)
    
    # 使用SOLVEPNP_EPNP + RANSAC
    success, rvec, tvec, inliers = cv2.solvePnPRansac(
        obj_pts, img_pts, camera_matrix, dist_coeffs,
        useExtrinsicGuess=False,
        iterationsCount=100,
        reprojectionError=8.0,
        confidence=0.99,
        flags=cv2.SOLVEPNP_EPNP
    )
    
    if success and inliers is not None:
        # 用内点再做一次BA优化
        if len(inliers) > 10:
            obj_inliers = obj_pts[inliers.flatten()]
            img_inliers = img_pts[inliers.flatten()]
            success, rvec, tvec = cv2.solvePnP(
                obj_inliers, img_inliers, camera_matrix, dist_coeffs,
                rvec, tvec, useExtrinsicGuess=True,
                flags=cv2.SOLVEPNP_ITERATIVE
            )
        return success, rvec, tvec, len(inliers)
    else:
        return False, None, None, 0
我的建议： 代码里的reprojectionError参数，我一般设8~10像素。设太小了，内点太少；设太大了，野点混进来。你可以根据实际场景微调。

19.6 视觉重定位的工程实现

重定位在AGV上跑，最怕的就是“假阳性”——明明没定位成功，却以为成功了。我吃过这个亏。

一个可靠的重定位流程：

  • 第一步：用词袋模型快速检索，返回Top-5候选关键帧
  • 第二步：对每个候选帧做特征匹配，要求匹配点数 > 30
  • 第三步：用PnP求解位姿，计算重投影误差
  • 第四步：如果误差 < 5像素，且内点比例 > 60%，判定成功
  • 第五步：连续3帧都成功，才切换为重定位状态

嗯，第五步是关键。单帧成功可能是巧合，连续3帧都成功，基本就稳了。

曾经踩过的坑： 有一次AGV在货架通道里重定位，词袋检索返回了隔壁通道的关键帧——因为货架长得太像了。后来我加了“空间一致性检查”：候选关键帧的位姿必须和当前估计位置在5米范围内，否则直接丢弃。这个改动，让重定位的误报率从15%降到了1%以下。

19.7 小结

视觉定位这件事，说难不难，说简单也不简单。关键帧、PnP、重定位，这三者是一个闭环：关键帧构建地图结构，PnP提供实时位姿，重定位处理异常情况。

我个人觉得，做AGV视觉定位，最重要的不是算法有多炫酷，而是鲁棒性。在真实场景里，光照变化、遮挡、纹理缺失，这些才是常态。把基础方法做扎实，比堆砌花哨的模型更管用。

一句话总结： 关键帧是地图的骨架，PnP是定位的引擎，重定位是系统的安全网。三者缺一不可。

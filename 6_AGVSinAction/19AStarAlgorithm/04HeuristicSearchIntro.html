4 启发式搜索入门：启发式函数概念、贪心最佳优先搜索、A星算法的直觉理解

各位同学，今天我们来聊聊启发式搜索。说实话，我刚入行那会儿，对“启发式”这三个字特别犯怵——总觉得这是什么高深莫测的数学魔法。后来做项目做多了才发现，说白了就是“凭经验猜一猜，但猜得有道理”。

4.1 什么是启发式函数？

先问大家一个问题：你在一个陌生城市找一家餐厅，你会怎么走？

正常人肯定不会把所有路口都走一遍吧？你会先看地图，判断餐厅大概在哪个方向，然后朝着那个方向走。这个“大概方向”的判断，就是启发式。

启发式函数（Heuristic Function），用数学语言说，就是h(n)——它估算从当前节点n到目标节点的代价。注意我的用词：“估算”。它不是精确值，而是预测值。

核心公式：

h(n) = 从节点n到目标节点的估计代价

常见的启发式函数：

  • 曼哈顿距离：|x1-x2| + |y1-y2|（适合四方向移动）
  • 欧几里得距离：sqrt((x1-x2)² + (y1-y2)²)（适合任意方向移动）
  • 切比雪夫距离：max(|x1-x2|, |y1-y2|)（适合八方向移动）

我在项目中遇到过最典型的坑：有人直接用欧几里得距离做AGV的路径估计，结果路径老是穿墙。为什么？因为AGV只能走网格，不能斜着飞啊！所以选启发式函数，一定要匹配你的运动模型。

4.2 贪心最佳优先搜索

理解了启发式函数，咱们先看一个最简单的应用——贪心最佳优先搜索（Greedy Best-First Search）。

它的逻辑特别直白：每次都选离目标最近的节点。只看h(n)，不看已经走了多远。

// 伪代码：贪心最佳优先搜索
openList.add(startNode);

while (openList不为空) {
    currentNode = openList中h(n)最小的节点;
    
    if (currentNode == goalNode) {
        return 成功;
    }
    
    openList.remove(currentNode);
    closedList.add(currentNode);
    
    for (neighbor : currentNode的邻居) {
        if (neighbor 不在 closedList 中) {
            neighbor.parent = currentNode;
            openList.add(neighbor);
        }
    }
}

你想想看，这算法有什么问题？

嗯，它太“贪心”了。我曾经用这个算法给AGV规划路径，结果遇到一个U形障碍物，小车直接冲进去，然后在里面转圈圈——因为它只看目标方向，不知道先绕路才是更优解。

避坑指南：

我曾经在仓库项目中用贪心最佳优先搜索做路径规划，结果AGV频繁陷入局部最优。后来我加了个“历史代价”才解决问题。记住：贪心算法适合障碍物少的场景，复杂环境慎用。

4.3 A星算法的直觉理解

好了，重头戏来了。A星算法，说白了就是“贪心最佳优先搜索”和“Dijkstra算法”的合体。

Dijkstra算法只看已经走了多远（g(n)），贪心最佳优先搜索只看还要走多远（h(n)）。A星呢？两个都看：

A星核心公式：

f(n) = g(n) + h(n)

  • g(n)：从起点到当前节点n的实际代价
  • h(n)：从当前节点n到目标节点的估计代价
  • f(n)：总估计代价

我个人的理解方式是这样的：g(n)是“过去”，h(n)是“未来”，f(n)是“全局视野”。

举个生活中的例子：你要从北京去上海。

  • Dijkstra算法：先把北京所有路口走一遍，再走天津所有路口……太慢了
  • 贪心最佳优先搜索：直接朝上海方向冲，遇到黄河就傻眼了
  • A星算法：先看地图，知道上海在东南方向，但也要考虑已经走了多远，综合判断

是不是一下子就理解了？

4.4 启发式函数对A星的影响

这里有个关键点：启发式函数的选择直接决定了A星的行为。

h(n) 的情况 算法行为 实际效果
h(n) = 0 A星退化为Dijkstra 保证最优解，但搜索范围大
h(n) ≤ 实际代价 可采纳的启发式 保证最优解，效率较高
h(n) = 实际代价 完美启发式 只走最优路径，效率最高
h(n) > 实际代价 不可采纳的启发式 可能不是最优解，但更快

我在做AGV调度系统时，就遇到过这个权衡。客户要求“路径必须最优”，那我就用曼哈顿距离（可采纳的）。另一个项目要求“实时响应”，我就稍微放大h(n)的值，牺牲一点最优性换取速度。

个人经验：

如果你不确定选什么启发式函数，先用曼哈顿距离。它在大多数网格地图上表现都不错。等系统跑起来后，再根据实际性能调优。

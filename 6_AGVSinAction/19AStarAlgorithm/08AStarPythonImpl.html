8.1 数据结构定义：把地图和节点管起来

写A*之前，得先把“架子”搭好。说白了，就是定义几个类，把地图、节点、路径这些概念用代码表达清楚。

8.1.1 节点类（Node）

每个格子就是一个节点。它得知道自己是谁（坐标）、从哪来（父节点）、以及三个关键值：g、h、f。

class Node:
    def __init__(self, x, y, parent=None):
        self.x = x          # 行坐标
        self.y = y          # 列坐标
        self.parent = parent  # 父节点，用于回溯路径
        self.g = 0          # 从起点到当前节点的实际代价
        self.h = 0          # 从当前节点到终点的估计代价
        self.f = 0          # f = g + h

    def __eq__(self, other):
        # 判断两个节点是否相同，比较坐标即可
        return self.x == other.x and self.y == other.y

    def __lt__(self, other):
        # 用于优先队列排序，按f值从小到大
        return self.f < other.f

    def __repr__(self):
        return f"({self.x},{self.y})"

这里我习惯把__lt__加上。为什么？因为后面要用heapq做优先队列，它需要比较大小。没有这个，堆排序会报错。我曾经在这卡了半小时，后来发现是忘了定义比较方法。

8.1.2 地图类（GridMap）

地图就是二维数组。0表示可通行，1表示障碍物。我建议把地图封装成一个类，方便后续扩展。

class GridMap:
    def __init__(self, width, height, obstacles=None):
        self.width = width
        self.height = height
        # 初始化全0地图
        self.grid = [[0 for _ in range(width)] for _ in range(height)]
        if obstacles:
            for (x, y) in obstacles:
                self.set_obstacle(x, y)

    def set_obstacle(self, x, y):
        if 0 <= x < self.height and 0 <= y < self.width:
            self.grid[x][y] = 1

    def is_passable(self, x, y):
        # 检查是否在地图范围内且不是障碍物
        return (0 <= x < self.height and
                0 <= y < self.width and
                self.grid[x][y] == 0)

    def get_neighbors(self, node, allow_diagonal=False):
        # 获取相邻的可通行节点
        neighbors = []
        # 四方向移动
        directions = [(-1,0), (1,0), (0,-1), (0,1)]
        if allow_diagonal:
            directions += [(-1,-1), (-1,1), (1,-1), (1,1)]
        for dx, dy in directions:
            nx, ny = node.x + dx, node.y + dy
            if self.is_passable(nx, ny):
                neighbors.append(Node(nx, ny, node))
        return neighbors

你想想看，把地图逻辑封装起来，后面改障碍物、改移动方式，都只需要动这一个类。我在项目里就是这么干的，维护起来特别省心。

8.2 核心函数实现：A*的灵魂

架子搭好了，接下来就是核心算法。A*的核心就两个东西：open list和closed list。open list存待探索的节点，closed list存已经探索过的节点。

8.2.1 启发函数

我一般用曼哈顿距离，简单高效。如果允许斜向移动，就用欧几里得距离。

def manhattan_distance(node, goal):
    return abs(node.x - goal.x) + abs(node.y - goal.y)

def euclidean_distance(node, goal):
    return ((node.x - goal.x)**2 + (node.y - goal.y)**2)**0.5

8.2.2 A*主函数

这是重头戏。我直接给你完整的实现，注释写得清清楚楚。

import heapq

def a_star_search(grid_map, start, goal, heuristic=manhattan_distance):
    # 初始化起点和终点节点
    start_node = Node(start[0], start[1])
    goal_node = Node(goal[0], goal[1])

    # open list用优先队列，按f值排序
    open_list = []
    heapq.heappush(open_list, start_node)

    # closed list用集合，快速查找
    closed_set = set()

    # 记录遍历过的节点数（用于统计）
    explored_count = 0

    while open_list:
        # 取出f值最小的节点
        current_node = heapq.heappop(open_list)

        # 到达终点，回溯路径
        if current_node == goal_node:
            path = []
            while current_node:
                path.append((current_node.x, current_node.y))
                current_node = current_node.parent
            return path[::-1], explored_count  # 反转得到从起点到终点的路径

        # 加入closed list
        closed_set.add((current_node.x, current_node.y))
        explored_count += 1

        # 遍历邻居
        for neighbor in grid_map.get_neighbors(current_node, allow_diagonal=False):
            # 如果邻居已在closed list中，跳过
            if (neighbor.x, neighbor.y) in closed_set:
                continue

            # 计算g值：从起点到当前节点再到邻居
            tentative_g = current_node.g + 1  # 四方向移动，代价为1

            # 检查邻居是否在open list中
            in_open = False
            for open_node in open_list:
                if neighbor == open_node:
                    in_open = True
                    # 如果新路径更短，更新
                    if tentative_g < open_node.g:
                        open_node.g = tentative_g
                        open_node.h = heuristic(open_node, goal_node)
                        open_node.f = open_node.g + open_node.h
                        open_node.parent = current_node
                    break

            # 如果不在open list中，直接加入
            if not in_open:
                neighbor.g = tentative_g
                neighbor.h = heuristic(neighbor, goal_node)
                neighbor.f = neighbor.g + neighbor.h
                neighbor.parent = current_node
                heapq.heappush(open_list, neighbor)

    # open list为空，说明没有路径
    return None, explored_count

这里有个细节：更新open list中的节点时，我没有重新堆化。严格来说，修改了堆中元素的值后，应该重新堆化。但Python的heapq没有提供直接更新元素的方法。我个人的做法是：如果性能要求不高，就这么写，因为大多数情况下路径不会频繁更新。如果性能要求高，可以用dict维护每个节点的f值，或者用heapq的_siftdown手动调整。不过那是进阶话题了，咱们先跑起来再说。

8.3 完整代码示例：跑一个看看

好了，所有零件都齐了。咱们组装起来，跑一个实际例子。

def main():
    # 创建10x10地图
    grid = GridMap(10, 10)

    # 添加一些障碍物
    obstacles = [(3,3), (3,4), (3,5), (4,3), (5,3), (6,3)]
    for obs in obstacles:
        grid.set_obstacle(obs[0], obs[1])

    # 设置起点和终点
    start = (1, 1)
    goal = (8, 8)

    # 运行A*
    path, explored = a_star_search(grid, start, goal)

    if path:
        print(f"找到路径！探索了 {explored} 个节点")
        print(f"路径长度：{len(path)} 步")
        print(f"路径：{path}")

        # 可视化地图
        for i in range(grid.height):
            row = ""
            for j in range(grid.width):
                if (i, j) == start:
                    row += "S "
                elif (i, j) == goal:
                    row += "G "
                elif (i, j) in path:
                    row += "* "
                elif grid.grid[i][j] == 1:
                    row += "# "
                else:
                    row += ". "
            print(row)
    else:
        print("没有找到路径！")

if __name__ == "__main__":
    main()

8.4 避坑指南：我踩过的那些坑

⚠️ 常见错误1：忘记检查边界

我曾经在get_neighbors里没加边界检查，结果索引越界，程序直接崩了。一定要用is_passable方法统一检查。

⚠️ 常见错误2：open list重复添加

如果不检查节点是否已在open list中，会导致同一个节点被多次加入，路径可能不是最优的。我早期代码就犯过这个错，跑出来的路径绕了一大圈。

💡 性能优化小技巧

如果地图很大（比如1000x1000），用set存closed list比用list快得多。查找操作从O(n)降到了O(1)。我做过测试，100万节点时，set比list快了近100倍。

10 运动控制抗干扰：PID控制器抗积分饱和与微分先行，前馈补偿与扰动观测器设计，电机电流环与速度环参数整定

各位工程师朋友，咱们今天聊点硬核的。运动控制抗干扰，说白了就是让AGV在乱七八糟的现场环境里，还能稳稳当当跑直线、转直角。

我见过太多项目，AGV在实验室跑得跟教科书一样完美，一到客户现场就抽风。为什么？干扰来了。地面油污、轮胎打滑、负载变化、通信延迟……这些才是真实世界。

这一章，咱们就聚焦三个核心问题：PID怎么调才不飘？扰动来了怎么扛？电流环和速度环怎么配合？

核心观点：运动控制抗干扰不是靠一个算法包打天下，而是靠「PID调优 + 前馈补偿 + 扰动观测」三件套组合出拳。

10.1 PID控制器抗积分饱和

积分饱和，这词听着专业，其实说白了就是：误差一直存在，积分项一直累加，累到天昏地暗。等误差终于反转了，积分项还傻乎乎地往反方向使劲，系统就 overshoot 了。

我在一个仓储AGV项目里遇到过这问题。AGV从A点去B点，中间要经过一段长直道。直道上有轻微坡度，PID的积分项一直在累加。等AGV到了B点要停车，好家伙，积分项还在往上顶，车子直接冲过了头，撞上了货架。

怎么解决？两种常用方法：

  • 积分限幅法：给积分项设个上限。我习惯设成输出限幅的80%。比如PWM最大1000，积分项最大就800。
  • 积分分离法：误差大的时候，干脆关掉积分。等误差小了再打开。阈值一般设在目标值的5%~10%。

我的经验：积分分离法效果更好，但要注意切换时的平滑过渡。我一般加个软切换，用sigmoid函数做权重，避免积分突然切入切出造成抖动。

// 抗积分饱和 - 积分分离法示例
float pid_integral_anti_windup(float error, float integral, float threshold) {
    if (fabs(error) < threshold) {
        // 误差小，正常积分
        integral += error * dt;
    } else {
        // 误差大，积分保持不动
        // 或者缓慢衰减
        integral *= 0.95f;
    }
    // 再加个限幅，双重保险
    if (integral > INTEGRAL_MAX) integral = INTEGRAL_MAX;
    if (integral < -INTEGRAL_MAX) integral = -INTEGRAL_MAX;
    return integral;
}

10.2 微分先行

微分项有个毛病：对噪声特别敏感。你想想看，AGV的编码器信号稍微抖一下，微分项就炸了。输出会剧烈跳动，电机嗡嗡响。

微分先行的思路很简单：不对误差求导，而是对测量值求导。这样设定值突变的时候，微分项不会跟着跳，只有实际值变化才起作用。

我曾经调试一台AGV，速度环微分增益稍微给大一点，电机就啸叫。后来改成微分先行，同样的增益，安静得像只猫。

关键区别：

  • 传统微分：D = Kd * d(error)/dt
  • 微分先行：D = Kd * d(measurement)/dt

效果：设定值突变时，传统微分会产生尖峰脉冲；微分先行则平滑过渡。

10.3 前馈补偿设计

PID是事后诸葛亮——有了误差才调整。前馈补偿是事前诸葛亮——提前知道要干啥，先给个预判。

AGV运动控制里，最常用的前馈有两种：

  • 速度前馈：知道目标速度，直接给一个对应的控制量。比如电机要跑1000rpm，先给60%的PWM，剩下的让PID去微调。
  • 加速度前馈：知道要加速，提前给一个额外的力矩。这对克服惯性特别有用。

我习惯的做法是：先做前馈标定。让AGV空载跑一遍，记录不同速度下需要的PWM值。拟合出一条曲线。以后直接查表或者用公式算。

// 速度前馈查表示例
float speed_feedforward(float target_speed) {
    // 标定数据：速度(rpm) -> PWM(%)
    static float calib_table[][2] = {
        {0,    0},
        {500,  30},
        {1000, 55},
        {1500, 78},
        {2000, 100}
    };
    // 线性插值
    for (int i = 0; i < 4; i++) {
        if (target_speed >= calib_table[i][0] && target_speed <= calib_table[i+1][0]) {
            float ratio = (target_speed - calib_table[i][0]) / 
                         (calib_table[i+1][0] - calib_table[i][0]);
            return calib_table[i][1] + ratio * (calib_table[i+1][1] - calib_table[i][1]);
        }
    }
    return 0;
}

注意：前馈补偿不是万能的。它依赖模型精度。如果AGV负载变化很大（比如空载和满载差一倍），前馈系数需要在线调整。我一般加个自适应因子，根据实际电流反馈修正前馈量。

10.4 扰动观测器设计

前馈补偿搞不定的，就是那些未知的、突发的扰动。比如AGV压到一块石头，或者轮胎打滑。

扰动观测器（DOB）的思路：把扰动当成一个状态量，用观测器把它估计出来，然后补偿掉。

我常用的两种：

  • 经典DOB：基于名义模型，用低通滤波器分离扰动。实现简单，但依赖模型精度。
  • 扩张状态观测器（ESO）：把扰动扩张成一个新状态，用状态观测器估计。鲁棒性更好，但参数整定麻烦一点。

记得有一次，AGV在仓库里跑，地面有一小滩油。没有DOB的时候，车子直接打滑偏了30度。加上DOB之后，观测器在10ms内就估计出了扰动，补偿力矩加上去，车子只偏了3度就拉回来了。

参数整定小技巧：DOB的带宽是关键。带宽太高，会把噪声当成扰动；带宽太低，扰动来了来不及补偿。我一般从电机电流环带宽的1/5开始调，慢慢往上加，直到看到扰动抑制效果满意为止。

10.5 电流环与速度环参数整定

好了，前面说的抗积分饱和、微分先行、前馈补偿、扰动观测器，最终都要落实到电流环和速度环的参数上。

我的整定顺序是：先电流环，后速度环。电流环是内环，速度环是外环。内环不稳，外环怎么调都没用。

环节 带宽范围 整定目标 常用方法
电流环 500Hz ~ 2kHz 快速响应，无超调 PI控制器，带宽法整定
速度环 20Hz ~ 200Hz 平稳跟踪，抗扰动 PI+前馈，对称最优法

电流环整定步骤：

  1. 先给一个小的比例增益，比如Kp=0.1
  2. 给一个阶跃电流指令，看响应
  3. 慢慢增大Kp，直到出现轻微振荡，然后退回80%
  4. 加积分项，消除稳态误差。Ki一般取Kp的1/10到1/5

速度环整定步骤：

  1. 电流环整定好之后，把速度环比例增益设小，比如Kp=1
  2. 给一个阶跃速度指令，看响应
  3. 增大Kp，直到速度出现超调，然后退回一点
  4. 加积分项，注意配合抗积分饱和
  5. 最后加前馈补偿，减少PID的负担

我的个人习惯：速度环的积分时间常数，我一般设成电流环闭环时间常数的5~10倍。这样内外环不会打架。你想想看，内环都响应完了，外环才开始积分，系统自然就稳了。

嗯，这一章内容不少。抗积分饱和、微分先行、前馈补偿、扰动观测器、电流环速度环整定——这些技术单独拿出来都不难，但组合在一起，就能让AGV在恶劣环境下依然跑得稳。

我曾经在一个项目里，客户说「你们AGV跑得跟老司机一样稳」。其实哪有什么魔法，就是把这些细节一个一个抠到位了。

16 抗干扰测试方法论

做AGV导航系统这么多年，我最大的体会就是——实验室跑得再顺，到了现场该翻车还是翻车。为什么？因为现场有干扰啊。电磁、振动、光照，这三样东西，随便来一个就能让你的定位精度从毫米级掉到分米级。

这一章，我就把抗干扰测试的完整方法论摊开来讲。说白了，就是教你怎么系统地“折磨”你的AGV，看看它在各种恶劣条件下还能不能撑住。

16.1 干扰注入测试：三大核心干扰源

我个人习惯把干扰分成三类：电磁、振动、光照。每一类都有它自己的脾气。

16.1.1 电磁干扰注入

电磁干扰是最隐蔽的。你想想看，AGV在工厂里跑，旁边就是变频器、电焊机、大功率电机。这些东西一开，电磁场就跟风暴一样。

我建议的测试方法：

  • 传导干扰注入：用耦合/去耦网络（CDN）把干扰信号直接怼到电源线上
  • 辐射干扰注入：用天线在特定频段发射电磁波，模拟现场环境
  • 静电放电（ESD）：模拟人手触摸或设备放电的场景
我的经验： 有一次在汽车厂调试，AGV一到焊装车间就丢定位。查了三天，最后发现是焊枪的电磁脉冲把激光雷达的通讯给打乱了。后来我们在雷达线束上加了个磁环，问题就解决了。所以，电磁干扰测试一定要做，而且要在实际工况下做。

16.1.2 振动干扰注入

振动这东西，对视觉导航和激光导航的影响特别大。AGV在粗糙地面跑，或者经过减速带、接缝处，摄像头一晃，特征点就匹配不上了。

我常用的方法：

  • 振动台测试：把AGV固定在振动台上，施加不同频率和幅度的振动
  • 冲击测试：模拟AGV撞到障碍物或急停时的冲击
  • 路面模拟：用不同粗糙度的路面板，让AGV反复跑
注意： 振动测试的频率范围要覆盖AGV的机械共振点。我曾经遇到过一台AGV，在15Hz振动下IMU数据直接漂移，后来发现是安装支架的共振。所以，测试前最好先做个模态分析。

16.1.3 光照干扰注入

光照变化是视觉导航的噩梦。从亮到暗，从冷光到暖光，从直射到漫射，摄像头看到的完全不一样。

我建议的测试场景：

  • 光照强度突变：从1000 lux瞬间降到10 lux，模拟AGV从室外进入室内
  • 频闪干扰：用50Hz/60Hz的频闪灯，模拟工厂里的荧光灯
  • 局部强光：在某个区域用聚光灯直射，模拟阳光或工位照明
核心观点： 光照干扰测试的关键不是“能不能看到”，而是“特征点能不能稳定匹配”。我见过很多视觉导航系统，在均匀光照下表现完美，但一遇到局部阴影就崩了。

16.2 定位精度与鲁棒性量化指标

光说“定位准不准”太模糊了。我们需要量化指标。我个人最常用的三个指标：RMSE、CEP、定位成功率。

16.2.1 RMSE（均方根误差）

RMSE是最直观的精度指标。它计算的是估计位置与真实位置之间的偏差。

RMSE = sqrt( (1/N) * Σ ( (x_est - x_true)^2 + (y_est - y_true)^2 ) )

举个例子：如果AGV在100个点上的RMSE是5cm，那说明平均偏差在5cm左右。但要注意，RMSE对大误差特别敏感——偶尔一次大的漂移会把RMSE拉得很高。

16.2.2 CEP（圆概率误差）

CEP是军事领域常用的指标，现在也被工业界广泛采用。它表示50%的定位点落在某个半径的圆内。

CEP值 含义 典型应用场景
CEP50 = 2cm 50%的定位点落在半径2cm的圆内 高精度仓储
CEP90 = 5cm 90%的定位点落在半径5cm的圆内 一般工业物流
CEP99 = 10cm 99%的定位点落在半径10cm的圆内 安全要求高的场景
我的习惯： 我一般同时看RMSE和CEP。RMSE告诉你“平均表现”，CEP告诉你“最差的那部分有多差”。如果RMSE很小但CEP很大，说明系统偶尔会抽风——这比一直不准更危险。

16.2.3 定位成功率

这个指标最简单，但也最容易被忽略。它定义是：在给定精度阈值下，定位成功的次数占总测试次数的比例。

比如：要求定位误差小于10cm，测试1000次，成功了980次，那成功率就是98%。

我个人认为，定位成功率比RMSE更能反映系统的鲁棒性。因为RMSE可以被大量“准”的数据拉低，但成功率直接告诉你“有多少次是靠谱的”。

16.3 测试场景设计与自动化测试

测试场景设计，说白了就是怎么让AGV“吃尽苦头”。我建议从三个维度来设计：

  • 环境维度：电磁强度、振动频率、光照条件
  • 运动维度：直线、转弯、加减速、原地旋转
  • 时间维度：短期测试（几分钟）、长期测试（几小时）、老化测试（几天）

16.3.1 典型测试场景矩阵

场景编号 电磁干扰 振动干扰 光照干扰 运动模式
S1 无 无 均匀 直线匀速
S2 强（100V/m） 无 均匀 直线匀速
S3 无 强（5g, 20Hz） 均匀 直线匀速
S4 无 无 频闪（50Hz） 直线匀速
S5 强 强 频闪 复杂路径

你看，从S1到S5，干扰强度逐渐增加。S5是“地狱模式”——所有干扰同时上，AGV还能不能稳住？

16.3.2 自动化测试框架

手动测试太慢了。我建议搭建一个自动化测试框架，核心流程如下：

1. 测试用例加载（从YAML/JSON读取场景参数）
2. 干扰设备控制（信号发生器、振动台、灯光控制器）
3. AGV运动控制（发送导航指令）
4. 数据采集（定位数据、传感器数据、时间戳）
5. 指标计算（RMSE、CEP、成功率）
6. 报告生成（自动输出测试报告）
关键点： 自动化测试的难点不在于“跑起来”，而在于如何保证测试的可重复性。我踩过最大的坑就是：两次测试结果不一样，分不清是AGV的问题还是环境变化的问题。所以，每次测试前都要记录环境参数，包括温度、湿度、电磁背景噪声等。

16.5 避坑指南

最后，我分享几个实战中踩过的坑：

  • 不要只测“干净”环境：很多团队在实验室里测得好好的，一到现场就崩。原因就是没加干扰。
  • 不要只看平均值：RMSE好看不代表系统稳定。一定要看CEP和成功率，尤其是极端情况下的表现。
  • 不要忽略长期测试：有些问题跑几分钟看不出来，跑几个小时就暴露了。比如温漂、累积误差。
  • 不要手动记录数据：自动化测试框架一定要搭好。手动记录不仅慢，还容易出错。
我曾经犯过的错： 有一次给客户做验收测试，只测了标准工况，结果客户现场有强电磁干扰，AGV直接罢工。后来我花了整整两周重新做抗干扰测试，才把问题定位到通讯模块。从那以后，抗干扰测试成了我项目流程里的必修课。

好了，这一章的内容就到这里。记住：抗干扰测试不是“锦上添花”，而是“雪中送炭”。你花在测试上的每一分钟，都是在为现场运行的稳定性买单。

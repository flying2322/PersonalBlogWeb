28 行业标准与认证——AGV导航系统抗干扰相关标准（ISO、IEC、GB）

各位同行，咱们直接切入正题。AGV导航系统的抗干扰能力，说白了就是“在恶劣电磁环境下还能不能好好干活”。这玩意儿不是靠嘴说的，得有标准来卡。我个人习惯，做项目第一件事就是翻标准，不然你设计得再好，认证过不去，客户不买单。

1.1 三大标准体系：ISO、IEC、GB

目前全球AGV行业主要遵循三套标准体系。我简单梳理一下，大家心里有个谱。

标准体系 典型标准号 核心关注点 我的经验
ISO（国际标准化组织） ISO 3691-4:2020 工业车辆安全，含AGV导航系统功能安全要求 这个标准我翻烂了，它把导航失效列为关键风险
IEC（国际电工委员会） IEC 61000系列 电磁兼容性（EMC）测试方法、限值 做EMC测试时，IEC 61000-4-2静电放电那章我背得下来
GB（中国国家标准） GB/T 30029-2013 自动导引车（AGV）通用技术条件 国内项目必须过GB，别想着绕过去

为什么会这样？因为AGV要在工厂、仓库、医院这些地方跑，环境里到处都是变频器、电机、无线信号。没有标准约束，导航系统分分钟被干扰到“迷路”。

1.2 电磁兼容性（EMC）测试与认证

EMC测试，我把它分成两大部分：发射和抗扰。你想想看，你的AGV不能干扰别人，也不能被别人干扰。

1.2.1 发射测试（EMI）

测的是你的AGV会不会往外“漏”电磁波。我在项目中遇到过一台AGV，导航控制器没做屏蔽，结果把旁边的扫码枪全干趴下了。后来加了金属屏蔽罩，问题才解决。

  • 辐射发射：30MHz-1GHz频段，限值按GB 9254 Class A或B
  • 传导发射：150kHz-30MHz，主要看电源线

1.2.2 抗扰测试（EMS）

这才是咱们导航系统抗干扰的核心。我建议重点关注这几项：

  1. 静电放电（ESD）：IEC 61000-4-2，接触放电±6kV，空气放电±8kV。嗯，这里要注意，触摸屏和外壳接缝处最容易出问题。
  2. 射频电磁场：IEC 61000-4-3，80MHz-6GHz，场强10V/m。AGV上的无线模块自己就是干扰源。
  3. 快速瞬变脉冲群：IEC 61000-4-4，±2kV，5kHz。电机启停时最容易产生这种干扰。
  4. 浪涌（雷击）：IEC 61000-4-5，线对线±1kV，线对地±2kV。室外AGV必须过这个。

核心观点：EMC认证不是“一次性”的事。我见过太多项目，实验室过了，现场就崩。为什么？因为实验室的线缆布局和现场不一样。所以我的习惯是：实验室测试通过后，必须做现场复测。

1.3 功能安全与抗干扰的关系

功能安全（Functional Safety）和抗干扰，其实是“一体两面”。你想想看，导航系统被干扰后，最坏的结果是什么？——撞人、撞货、翻车。所以ISO 3691-4里明确要求：导航系统的失效模式必须被识别和控制。

我个人习惯把抗干扰设计纳入功能安全框架。具体来说：

  • 诊断覆盖率：导航传感器（激光雷达、磁条、二维码）的故障检测率要达标。我曾经在项目里加了一个“信号质量监控”模块，专门检测激光雷达的反射强度异常，这就是抗干扰和功能安全的结合。
  • 安全状态：当导航系统检测到强干扰时，AGV应该进入什么状态？急停？降速？还是重新定位？这需要在设计阶段就定好。
  • 冗余设计：单一导航方式被干扰，另一套系统要能接管。比如激光SLAM+磁条双备份，我做过一个项目，磁条被叉车压坏了，激光导航自动顶上，AGV没停。

警告：千万不要把功能安全和EMC割裂开。我曾经见过一个团队，EMC测试全过了，但功能安全评审时发现，导航系统在强电磁场下会“静默失效”——就是数据不更新了，但控制器以为还在正常跑。这种问题，EMC测试是测不出来的，必须靠功能安全分析。

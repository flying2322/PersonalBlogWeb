5 环境光噪抑制：激光雷达抗环境光干扰算法

做AGV导航这么多年，环境光干扰是我最头疼的问题之一。你想想看，仓库里阳光从窗户照进来，或者车间里焊接弧光一闪，激光雷达的数据就乱了套。视觉相机更惨，曝光不对直接黑屏或过曝。今天我就把压箱底的经验掏出来说说。

5.1 激光雷达的抗光干扰策略

激光雷达的原理说白了就是发射激光、接收反射光。但太阳光里也有近红外成分，直接照到接收器上，信噪比就崩了。我遇到过最夸张的一次，AGV在仓库门口直接“失明”，因为下午的阳光正好直射雷达窗口。

5.1.1 多脉冲检测技术

单脉冲容易误判，多脉冲就靠谱多了。原理很简单：

  • 发射一串短脉冲（比如3-5个）
  • 接收端只认符合脉冲序列特征的信号
  • 环境光噪声是随机的，很难匹配这个序列

核心参数：脉冲宽度通常5-10ns，脉冲间隔20-50ns。太窄了能量不够，太宽了抗干扰差。

// 多脉冲检测伪代码示例
bool detectMultiPulse(uint32_t* samples, int len) {
    int pulseCount = 0;
    for (int i = 0; i < len; i++) {
        if (samples[i] > THRESHOLD_HIGH) {
            pulseCount++;
            // 检查后续脉冲间隔
            if (pulseCount >= 3) return true;
        }
    }
    return false;
}

5.1.2 编码调制方案

多脉冲还不够？那就上编码调制。我给激光脉冲加上特定的“指纹”，比如曼彻斯特编码或伪随机码。接收端只解码匹配的信号，其他一概过滤。

调制方式 抗干扰能力 实现复杂度 我推荐场景
多脉冲 中等 低 室内仓库
曼彻斯特编码 较高 中 半室外环境
伪随机码 高 高 强光车间

我的经验：伪随机码虽然效果好，但会降低测量频率。如果AGV速度不快（1m/s以内），用曼彻斯特编码性价比最高。

5.2 视觉相机的曝光与增益自适应

视觉导航的痛点就是光照变化。AGV从暗处走到亮处，相机得自己学会“眨眼”。我见过不少项目，白天调试得好好的，傍晚就抓瞎了。

5.2.1 自动曝光算法

别用简单的平均值法，那玩意儿在强光下直接过曝。我推荐用直方图均衡法：

  1. 统计图像亮度直方图
  2. 找到主峰位置（占像素最多的亮度值）
  3. 调整曝光时间，让主峰落在128-160之间
  4. 如果直方图两端有堆积，说明过曝或欠曝
// 直方图曝光调整
int calcExposure(uint8_t* image, int width, int height) {
    int hist[256] = {0};
    int peak = 0, peakVal = 0;
    
    // 统计直方图
    for (int i = 0; i < width * height; i++) {
        hist[image[i]]++;
    }
    
    // 找主峰
    for (int i = 0; i < 256; i++) {
        if (hist[i] > peakVal) {
            peakVal = hist[i];
            peak = i;
        }
    }
    
    // 目标亮度140，计算增益系数
    return (140 * 100) / peak;  // 返回百分比增益
}

5.2.2 增益自适应调节

曝光时间调完了还不够，增益也得跟上。我习惯分三段处理：

  • 低光照（<50 lux）：先拉增益到6dB，再增加曝光时间
  • 正常光照（50-500 lux）：固定增益0dB，只调曝光
  • 强光照（>500 lux）：降低增益到-3dB，缩短曝光

注意：增益别超过12dB，否则噪点会淹没特征点。我曾经吃过这个亏，AGV在暗处导航精度直接掉了50%。

5.3 红外补光与滤光片应用

环境光干扰最狠的时候，算法扛不住，就得靠硬件了。红外补光和滤光片是黄金搭档。

5.3.1 红外补光方案

我推荐850nm或940nm的红外LED。850nm效率高，但会有微弱的红光可见。940nm完全不可见，适合对光敏感的场景。

波长 效率 可见光干扰 典型距离
850nm 高（~30%） 微弱红光 5-10m
940nm 中（~20%） 完全不可见 3-8m

避坑指南：我曾经用850nm补光，结果AGV在夜间工作时，操作员总说看到“鬼火”。后来换成940nm就没事了。如果场景允许，优先选940nm。

5.3.2 滤光片选型

滤光片的作用就是只让有用的光进来。我一般用带通滤光片，中心波长对准补光光源：

  • 窄带滤光片（±10nm）：抗干扰最强，但安装精度要求高
  • 宽带滤光片（±25nm）：安装容差大，但抗干扰稍弱
  • 截止深度：OD4以上（透过率<0.01%）

嗯，这里要注意一点：滤光片会损失光能量。如果补光功率不够，反而得不偿失。我建议补光功率至少留30%的余量。

总结一下：环境光抑制没有银弹。激光雷达靠多脉冲和编码调制，视觉相机靠曝光和增益自适应，实在不行上红外补光和滤光片。我建议你在项目初期就把这三层都规划好，别等出了问题再补。

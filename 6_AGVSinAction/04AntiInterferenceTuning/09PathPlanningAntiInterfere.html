9 路径规划抗干扰：动态窗口法（DWA）参数调优

路径规划这事儿，说白了就是让AGV在复杂环境里找到一条能走的路。但现实往往很骨感——传感器有噪声、地面有油污、行人突然窜出来……这些干扰会让规划器“犯迷糊”。

我做了这么多年AGV，最头疼的就是局部路径规划被干扰带偏。今天咱们重点聊聊动态窗口法（DWA）的参数调优，以及局部避障、重规划、全局路径平滑这些实战技巧。

9.1 DWA的核心思想：速度空间采样

DWA的原理其实不复杂。它把AGV的运动限制在一个“动态窗口”里——这个窗口由当前速度、加速度极限、刹车距离共同决定。然后在这个窗口内采样多组速度组合，用评价函数打分，选最优的那组。

嗯，这里要注意：窗口的大小直接影响规划质量。窗口太大，采样点太多，计算慢；窗口太小，可能找不到可行路径。

关键参数速查表：

参数 含义 典型范围 抗干扰调优方向
v_max 最大线速度 0.5~2.0 m/s 干扰大时适当降低
w_max 最大角速度 0.5~2.0 rad/s 窄通道需增大
acc_lim 加速度极限 0.2~1.0 m/s² 地面湿滑时减小
dt 模拟时间步长 0.1~0.5 s 动态障碍物多时减小
predict_time 轨迹预测时长 1.0~4.0 s 高速场景适当延长

9.2 评价函数权重调优：避障与目标导向的平衡

DWA的评价函数通常包含三个分量：方位角代价（朝向目标）、障碍物代价（远离障碍）、速度代价（保持高速）。权重设置不合理，AGV就会“抽风”。

我遇到过最典型的案例：有个项目把障碍物代价权重设得太高，结果AGV在空旷区域也疯狂绕路，明明直走就能到，它非要画个弧线。后来我把权重从0.5降到0.2，问题立刻解决。

我的调优习惯：

  • 先固定障碍物权重为0.3，调方位角权重到0.6
  • 观察AGV在狭窄通道的表现，再微调
  • 速度权重一般保持0.1~0.2，别让它太“贪快”

9.3 局部避障与重规划策略

DWA本质上是局部规划器，它只关心眼前几米的路。但遇到动态障碍物（比如突然出现的人），就需要触发重规划。

我个人建议采用分层触发机制：

  1. 轻微偏离：只调整DWA参数，不重新规划全局路径
  2. 中等阻塞：局部路径重规划，保留全局路径的起点和终点
  3. 严重死锁：完全重新规划全局路径

为什么会这样设计？因为频繁重规划会消耗大量算力，而且可能导致路径抖动。我曾经见过一个项目，AGV每遇到一个人就重规划一次，结果在原地转圈——这就是典型的“过度反应”。

避坑指南：我曾经把重规划触发阈值设得太敏感，结果AGV在仓库里像喝醉了酒一样左右摇摆。后来我加了“连续3次采样都失败才触发重规划”的逻辑，才稳定下来。

9.4 全局路径的平滑与曲率约束

全局路径规划（比如A*算法）生成的路径往往是折线。直接让AGV沿着折线走，会出现两个问题：

  • 在拐角处急转弯，容易侧翻或打滑
  • 频繁加减速，降低运输效率

所以必须做路径平滑。我常用的方法是三次样条插值，加上曲率约束。

// 伪代码：曲率约束检查
bool checkCurvature(PathPoint p1, PathPoint p2, PathPoint p3, float maxCurvature) {
    // 计算三点确定的圆的曲率
    float curvature = calculateCurvature(p1, p2, p3);
    if (curvature > maxCurvature) {
        // 插入中间点，降低曲率
        insertWaypoint(p1, p3);
        return false;
    }
    return true;
}

你想想看，如果AGV的转弯半径是1米，但路径上有个曲率半径0.5米的弯，它肯定过不去。所以曲率约束必须小于AGV的最小转弯半径。

9.5 实战调优流程

说了这么多理论，咱们来点实际的。我总结了一套调优流程：

  1. 跑一次基准测试：用默认参数跑一圈，记录失败场景
  2. 调整DWA窗口：根据失败场景缩小或扩大窗口
  3. 微调评价权重：先调方位角，再调障碍物，最后调速度
  4. 测试动态障碍物：让人在AGV前方横穿，观察反应
  5. 检查路径平滑度：导出路径数据，计算曲率分布
  6. 迭代优化：重复2~5步，直到满意

记住：没有一套参数能适应所有场景。我通常会在不同区域加载不同的参数集——比如仓库通道用“窄通道模式”，开阔区域用“高速模式”。

9.6 知识体系图：DWA抗干扰调优全景

这张图把DWA抗干扰调优的核心要素串起来了。左边是参数调优，中间是评价函数，右边是路径平滑，底部是重规划策略。调优时，这四个方面要协同考虑。

最后说句实在话：DWA调优没有银弹。我见过有人花了两周调参数，最后发现是传感器安装角度偏了2度。所以，遇到问题先检查硬件，别一上来就调参数。

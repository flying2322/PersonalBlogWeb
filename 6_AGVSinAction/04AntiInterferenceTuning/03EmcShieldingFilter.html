3 电磁屏蔽与滤波：电机驱动与通信线缆的电磁屏蔽设计，电源滤波与信号滤波电路选型，接地与等电位连接技巧

各位同行，咱们直接切入正题。AGV 导航系统最怕什么？怕干扰。电机一启动，激光雷达数据跳变；变频器一工作，通信总线报错。我这些年调试过的 AGV，十有八九的「灵异故障」最后都查到了电磁兼容头上。说白了，屏蔽、滤波、接地这三板斧耍好了，系统稳定性至少提升一个档次。

3.1 电机驱动与通信线缆的电磁屏蔽设计

电机驱动线缆是 AGV 上最大的干扰源。我见过不少工程师把电机线和编码器线绑在一起走，结果编码器信号直接废掉。嗯，这里要注意，屏蔽不是把线裹起来就完事，关键在「接地」和「选型」。

3.1.1 电机驱动线缆的屏蔽

我个人习惯，电机驱动线必须用双屏蔽电缆。内层屏蔽接驱动器端的地，外层屏蔽接机壳地。为什么搞两层？你想想看，电机高频开关时产生的共模干扰，单层屏蔽根本扛不住。

线缆类型 屏蔽结构 接地方式 我踩过的坑
电机动力线 铝箔+编织网双层屏蔽 内层接驱动器GND，外层接机壳 单层屏蔽时，激光雷达偶尔丢包
编码器线 编织网屏蔽（覆盖率>85%） 单端接地（控制器侧） 双端接地导致地环路，烧过编码器
通信线（CAN/RS485） 铝箔+编织网 单端接地（推荐浮地+TVS管） 直接接地反而引入更多噪声

避坑指南：我曾经在一条产线上，电机线屏蔽层两端都接了机壳，结果低频地环路电流直接把驱动器搞保护了。后来改成单端接地，问题消失。记住，屏蔽层不是越接地越好。

3.1.2 通信线缆的屏蔽与布线

通信线缆的屏蔽设计，我总结了一个「三不原则」：不靠近、不平行、不共用。什么意思？

  • 不靠近：通信线与动力线保持至少 10cm 间距，交叉时垂直走
  • 不平行：实在避不开，用金属隔板隔开，别并排走超过 5cm
  • 不共用：屏蔽层接地线单独走，别跟电源地混在一起

我记得有一次调试 AGV，CAN 总线在电机加速时疯狂报错。查了两天，最后发现是 CAN 线跟电机线在同一个线槽里平行走了 1.2 米。重新布线后，误码率从 15% 降到 0.1% 以下。

核心要点：屏蔽层接地要「一点接地」，避免地环路。高频干扰时，屏蔽层长度不要超过干扰波长的 1/20，否则屏蔽效果急剧下降。

3.2 电源滤波与信号滤波电路选型

滤波电路选型，说白了就是「对症下药」。AGV 上的干扰分两类：电源线上的传导干扰和信号线上的耦合干扰。处理方式完全不同。

3.2.1 电源滤波电路

我建议在 AGV 主电源入口加一级共模扼流圈 + X/Y 电容。共模扼流圈对付电机驱动产生的共模噪声，X 电容（跨接在 L-N 之间）滤差模噪声，Y 电容（L/N 对地）滤共模噪声。

// 典型电源滤波电路参数（我常用的配置）
// 输入：24V DC，电流 10A
// 共模扼流圈：2mH，饱和电流 15A
// X 电容：0.47μF，耐压 100V
// Y 电容：2.2nF，耐压 250V
// 注意：Y 电容容值不能太大，否则漏电流超标

为什么这么选？我做过对比测试：不加滤波时，电源线上 100kHz 的纹波高达 2Vpp；加上上述电路后，纹波降到 50mVpp 以下。导航系统的定位精度直接提升了一个量级。

个人经验：电源滤波器的安装位置很关键。一定要紧贴电源入口，输入输出线不能平行走，否则高频干扰会直接耦合过去，滤波器等于白装。

3.2.2 信号滤波电路

信号滤波，我习惯用 RC 低通滤波 + 磁珠的组合。RC 滤低频噪声，磁珠吸收高频尖峰。具体参数看信号频率：

信号类型 滤波方案 截止频率 注意事项
编码器信号（5V） RC：100Ω + 1nF ~1.6MHz R 不能太大，否则信号边沿变缓
模拟量输入（0-10V） RC：1kΩ + 100nF ~1.6kHz 加 TVS 管防浪涌
CAN 总线 共模扼流圈 + 终端电阻 — 终端电阻 120Ω，靠近节点

避坑指南：我曾经在编码器信号线上用了 10kΩ 的电阻，结果信号上升时间从 20ns 拖到 200ns，控制器直接误判脉冲数。嗯，滤波不是越狠越好，要兼顾信号完整性。

3.3 接地与等电位连接技巧

接地是电磁兼容里最容易被忽视、也最容易出问题的一环。我见过太多 AGV 因为接地不当，出现各种「玄学」故障。

3.3.1 单点接地 vs 多点接地

低频电路（<1MHz）用单点接地，高频电路（>10MHz）用多点接地。AGV 上既有低频的电源地，又有高频的通信地，怎么办？

我的做法是：分区接地，最后汇总。把 AGV 分成几个区域：驱动区、控制区、通信区。每个区域内部用星形接地，区域之间用 10mm² 以上的铜编织带连接，最后统一接到车体一点。

警告：千万不要把数字地和模拟地直接连在一起！我吃过亏——AGV 的模拟量传感器读数一直跳，查到最后发现数字地回流串到了模拟地。后来用 0Ω 电阻或磁珠隔离，问题解决。

3.3.2 等电位连接

等电位连接，说白了就是让 AGV 上所有金属部件都处于同一个电位。电机外壳、驱动器散热器、控制器机箱、电池箱体，这些都要用接地线连起来。

我建议用 6mm² 以上的黄绿双色线，走最短路径。连接点要打磨掉油漆，涂导电膏。为什么？我曾经遇到一台 AGV，电机外壳和车体之间靠螺丝连接，螺丝生锈后接触电阻变大，干扰直接从电机耦合到车体，导航系统直接罢工。

// 等电位连接检查清单（我每次调试必查）
// 1. 电机外壳 → 驱动器 PE 端子：电阻 < 0.1Ω
// 2. 驱动器 PE → 车体主接地点：电阻 < 0.05Ω
// 3. 控制器机箱 → 车体主接地点：电阻 < 0.1Ω
// 4. 电池负极 → 车体：不直接连接（浮地系统）
// 5. 通信线屏蔽层 → 控制器侧单点接地

核心逻辑：接地和等电位连接的目标是「提供一个低阻抗的回流路径」。干扰电流走最短路径回到源端，就不会耦合到敏感电路上。记住，接地不是「把干扰泄放到大地」，而是「给干扰一个回家的路」。

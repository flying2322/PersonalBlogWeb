3 路径规划算法：Dijkstra算法原理与实现、A*算法原理与实现、动态路径规划策略

各位同学，今天我们来聊聊AGV调度系统的核心——路径规划。说白了，就是给小车找一条从A到B的路。你想想看，一个仓库里几十台AGV跑来跑去，要是路线规划不好，轻则绕远路，重则堵成一锅粥。我在项目里见过最夸张的一次，三台车在十字路口互不相让，硬生生堵了五分钟——从那以后，我就特别重视路径规划这块。

一、Dijkstra算法：最朴素的寻路方式

Dijkstra算法，我个人习惯叫它“老实人算法”。为什么？因为它会老老实实地把从起点到所有点的最短路径都算出来，然后挑一条最短的给你。

1.1 算法原理

核心思想其实很简单：从起点出发，一层层往外扩散，每次选一个当前距离最近的点，更新它的邻居。直到所有点都被访问过。

关键点：Dijkstra算法要求所有边的权重不能为负。我在实际项目中踩过这个坑——有一次地图里不小心配了个负权重的边，结果算法跑出来的路径完全不对。排查了半天才发现问题。

1.2 代码实现

下面是我在项目中常用的一个简化版实现，去掉了复杂的工程化封装，保留了核心逻辑：

def dijkstra(graph, start, end):
    # graph: 邻接矩阵或邻接表
    # start: 起点节点ID
    # end: 终点节点ID
    
    INF = float('inf')
    n = len(graph)
    
    # 初始化距离数组和前驱节点数组
    dist = [INF] * n
    prev = [-1] * n
    visited = [False] * n
    
    dist[start] = 0
    
    for _ in range(n):
        # 找当前未访问节点中距离最小的
        u = -1
        min_dist = INF
        for i in range(n):
            if not visited[i] and dist[i] < min_dist:
                min_dist = dist[i]
                u = i
        
        if u == -1:
            break
        
        visited[u] = True
        
        # 更新邻居的距离
        for v in range(n):
            if graph[u][v] > 0 and not visited[v]:
                new_dist = dist[u] + graph[u][v]
                if new_dist < dist[v]:
                    dist[v] = new_dist
                    prev[v] = u
    
    # 回溯路径
    path = []
    cur = end
    while cur != -1:
        path.append(cur)
        cur = prev[cur]
    path.reverse()
    
    return path, dist[end]

个人经验：实际项目中，我一般不会用纯Python写Dijkstra，而是用C++或者Rust实现核心逻辑，然后用Python做上层封装。为什么？因为AGV调度对实时性要求高，纯Python在大地图（比如上千个节点）上跑起来太慢了。

二、A*算法：带方向的寻路

Dijkstra有个问题——它像个无头苍蝇一样四面八方都找。而A*算法聪明多了，它会朝着目标方向优先搜索。说白了，Dijkstra是“广撒网”，A*是“精准打击”。

2.1 算法原理

A*的核心在于估价函数：f(n) = g(n) + h(n)。其中g(n)是起点到当前点的实际代价，h(n)是当前点到终点的估计代价。

这里有个关键：h(n)必须满足“可采纳性”——也就是不能高估实际代价。我在项目中用过曼哈顿距离、欧几里得距离，还有切比雪夫距离。对于AGV在网格地图上的运动，我个人最推荐曼哈顿距离，因为它跟AGV的实际运动方式最匹配。

避坑指南：我曾经在一个项目里用了欧几里得距离作为启发函数，结果算法找出来的路径经常穿墙。后来才发现，因为AGV只能走水平和垂直方向，欧几里得距离严重低估了实际路径长度，导致启发函数失效。嗯，这个坑我记了好几年。

2.2 代码实现

import heapq

def a_star(grid, start, end):
    # grid: 0表示可通行，1表示障碍物
    # start, end: (x, y)坐标
    
    def heuristic(a, b):
        # 曼哈顿距离
        return abs(a[0] - b[0]) + abs(a[1] - b[1])
    
    rows, cols = len(grid), len(grid[0])
    open_set = [(0, start)]
    came_from = {}
    g_score = {start: 0}
    f_score = {start: heuristic(start, end)}
    
    while open_set:
        current = heapq.heappop(open_set)[1]
        
        if current == end:
            # 重建路径
            path = []
            while current in came_from:
                path.append(current)
                current = came_from[current]
            path.append(start)
            path.reverse()
            return path
        
        # 四个方向：上、下、左、右
        for dx, dy in [(0,1), (0,-1), (1,0), (-1,0)]:
            neighbor = (current[0] + dx, current[1] + dy)
            
            # 边界检查
            if (neighbor[0] < 0 or neighbor[0] >= rows or
                neighbor[1] < 0 or neighbor[1] >= cols):
                continue
            
            # 障碍物检查
            if grid[neighbor[0]][neighbor[1]] == 1:
                continue
            
            tentative_g = g_score[current] + 1
            
            if neighbor not in g_score or tentative_g < g_score[neighbor]:
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score[neighbor] = tentative_g + heuristic(neighbor, end)
                heapq.heappush(open_set, (f_score[neighbor], neighbor))
    
    return None  # 无路径

三、动态路径规划策略

静态路径规划有个致命问题——地图是死的，但AGV是活的。你想想看，一台AGV刚规划好路径，另一台车突然插进来，原来的路径就废了。所以我们需要动态路径规划。

3.1 重规划策略

最简单的做法就是定期重规划。比如每5秒重新跑一次A*。但这样做有个问题——计算量大，而且路径可能频繁变化，导致AGV走“蛇形”路线。

我建议的做法是：

  • 事件触发重规划：只有当检测到路径被阻塞时才重规划，而不是定时重规划
  • 局部重规划：只重新规划受影响的那一段路径，而不是整条路径
  • 路径缓存：保留多条备选路径，当主路径被阻塞时快速切换

3.2 时间窗法

这是我在实际项目中用得最多的方法。核心思想是：给每条路径分配一个时间窗，确保同一时间同一路段只有一台AGV通过。

路段ID AGV编号 进入时间 离开时间
R001 AGV-01 10:00:00 10:00:15
R001 AGV-02 10:00:20 10:00:35
R002 AGV-01 10:00:15 10:00:30

核心要点：时间窗法要求AGV的行驶速度相对稳定。如果AGV走走停停，时间窗就会频繁失效。我在一个项目里遇到过AGV因为电池电量不足导致速度下降，结果时间窗全乱了。后来我们加了一个速度预测模块，根据电池电量动态调整时间窗。

3.3 动态避让策略

当两台AGV在狭窄通道相遇时，谁让谁？我总结了一套规则：

  1. 任务优先级：紧急任务优先，普通任务让行
  2. 距离终点远近：离终点近的优先，远的让行
  3. 空载让重载：空车让路给载货车辆
  4. 就近避让：离避让区近的AGV主动进入避让区

这套规则看起来简单，但实际落地时有很多细节。比如“任务优先级”怎么定义？我一般用三个等级：紧急（比如生产线断料）、普通（日常搬运）、低优先级（充电或待命）。

我的建议：别把Dijkstra和A*对立起来。在实际项目中，我经常用A*做全局规划，用Dijkstra做局部重规划。为什么？因为局部区域小，Dijkstra的劣势不明显，而且它保证最优解，适合做精细调整。

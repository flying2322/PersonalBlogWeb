19 路径平滑与插值：贝塞尔曲线、B样条曲线、多项式插值

各位做AGV的同行，你们有没有遇到过这种情况？

规划出来的路径，明明起点到终点都对了，但车子跑起来就是一顿一顿的。拐弯的时候，要么急停急转，要么直接撞货架。嗯，说白了，就是路径不够平滑。

我入行第三年的时候，给一个大型电商仓库做项目。AGV在巷道里转弯，每次都要停下来原地旋转，效率低得让人抓狂。后来我才明白，问题出在路径规划只给了折线，没有做平滑处理。今天我们就聊聊怎么让AGV走得更顺溜。

为什么需要路径平滑？

AGV的运动学模型决定了它不能像理想质点那样瞬间改变方向。你想想看，差速轮也好，麦克纳姆轮也罢，都有最小转弯半径和加速度限制。如果路径上出现尖锐的拐角，AGV要么减速到零再转向，要么产生剧烈抖动。

我在项目中遇到过最典型的情况：规划出的路径由一系列离散点组成，点与点之间用直线连接。AGV跑到拐点处，控制器突然给出一个很大的角速度指令，电机嗡嗡响，货物差点甩出去。这就是典型的「路径不平滑病」。

核心目标： 在保证路径通过关键点的前提下，让路径曲率连续变化，且满足AGV的运动学约束。

三种主流平滑方法

我个人习惯把平滑方法分成三类：贝塞尔曲线、B样条曲线、多项式插值。它们各有各的脾气，选对了事半功倍。

1. 贝塞尔曲线

贝塞尔曲线是法国工程师皮埃尔·贝塞尔在雷诺汽车公司搞出来的。说白了，就是用几个控制点来「拉」出一条光滑曲线。

它的数学形式很简单：

B(t) = Σ P_i * B_{i,n}(t),  t ∈ [0,1]

其中 B_{i,n}(t) 是伯恩斯坦基函数：
B_{i,n}(t) = C(n,i) * t^i * (1-t)^(n-i)

我建议初学者先从三次贝塞尔曲线入手。四个控制点，两个端点固定，中间两个点用来调节弯曲程度。在仓储场景中，我常用它来做转弯处的平滑过渡。

实战技巧： 贝塞尔曲线有个特点——它不通过中间控制点，只通过首尾两点。所以如果你要求路径必须经过某些关键位置（比如货架通道口），需要分段拼接贝塞尔曲线。

举个例子，AGV要从A点走到B点，中间经过一个90度转弯。我会在转弯处插入两个控制点，让曲线平滑地绕过拐角。代码实现大致是这样：

def bezier_curve(p0, p1, p2, p3, num_points=100):
    t = np.linspace(0, 1, num_points)
    # 三次贝塞尔公式
    B = (1-t)**3 * p0 + 3*(1-t)**2*t * p1 + 3*(1-t)*t**2 * p2 + t**3 * p3
    return B

不过要注意，贝塞尔曲线是全局控制的。你动一个控制点，整条曲线都会变。这在某些场景下不太灵活。

2. B样条曲线

B样条曲线是贝塞尔曲线的升级版。它解决了全局控制的问题——每个控制点只影响局部区域。

我记得有一次做密集存储仓库的项目，货架间距只有1.2米，AGV需要在狭窄通道里频繁变道。用贝塞尔曲线调了半天，总是顾此失彼。换成B样条后，问题迎刃而解。

B样条的数学定义：

C(u) = Σ N_{i,p}(u) * P_i

其中 N_{i,p}(u) 是p次B样条基函数，由节点向量 U 决定。

它的核心优势有三个：

  • 局部性： 移动一个控制点，只影响附近几段曲线
  • 连续性： 可以控制到C2连续（曲率连续）
  • 凸包性： 曲线始终在控制点形成的凸包内，不会乱跑
避坑指南： 我曾经在一条路径上用了均匀B样条，结果在路径末端出现了奇怪的抖动。后来发现是节点向量分布不合理。建议在路径曲率变化大的地方，适当加密节点。

实际应用中，我常用三次B样条（p=3）。它既能保证C2连续，计算量又不大。代码示例：

def bspline_curve(control_points, degree=3, num_points=200):
    # 生成节点向量（这里用均匀节点）
    n = len(control_points)
    knots = np.concatenate([
        np.zeros(degree),
        np.linspace(0, 1, n - degree + 1),
        np.ones(degree)
    ])
    # 计算曲线上的点
    t = np.linspace(0, 1, num_points)
    curve = []
    for ti in t:
        # 找到ti所在的节点区间
        span = find_span(n, degree, ti, knots)
        # 计算基函数值
        basis = basis_function(span, ti, degree, knots)
        # 加权求和
        point = np.sum([basis[i] * control_points[span - degree + i] for i in range(degree+1)], axis=0)
        curve.append(point)
    return np.array(curve)

3. 多项式插值

多项式插值是最直接的方法——给定一系列路径点，找一个多项式函数穿过所有点。

但这里有个坑：高次多项式容易产生龙格现象，也就是在端点附近剧烈振荡。我刚开始做的时候吃过这个亏，用10次多项式插值，结果路径在中间段扭成了麻花。

我的选择建议：
  • 简单场景（2-3个控制点）：用贝塞尔曲线，直观好调
  • 复杂路径（多个控制点，需要局部调整）：用B样条曲线
  • 要求严格通过所有给定点：用三次样条插值

实际项目中的选择策略

说了这么多理论，到底怎么选？我分享几个实战经验：

场景 推荐方法 原因
AGV在通道内直线行驶后转弯 贝塞尔曲线 控制点少，计算快，转弯平滑
多AGV协同，路径频繁调整 B样条曲线 局部调整不影响全局，实时性好
AGV需要精确停靠在货架前 三次样条插值 保证路径通过指定位置
高速运行（>2m/s） B样条曲线 C2连续，加速度无突变
我的个人习惯： 在项目初期，先用贝塞尔曲线快速验证路径可行性。等系统稳定后，再根据实际运行数据，切换到B样条或样条插值做精细化调优。别一上来就搞复杂的，容易把自己绕进去。

最后说一句，路径平滑不是越光滑越好。你想想看，如果曲率变化太小，AGV转弯半径会很大，反而浪费仓库空间。关键是在平滑度和路径长度之间找到平衡点。这个度，得靠实际跑出来的数据慢慢调。

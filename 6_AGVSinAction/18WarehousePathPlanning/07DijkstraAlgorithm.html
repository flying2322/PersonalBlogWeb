7 Dijkstra算法：原理、伪代码、在仓储地图上的应用实例

各位工程师朋友，今天我们来聊聊Dijkstra算法。

说实话，这个算法在AGV路径规划里，就像螺丝刀在工具箱里一样——基础，但离不开。我最早接触它是在大学的数据结构课上，当时觉得就是个找最短路径的数学游戏。直到后来做仓储项目，才发现这玩意儿是真能解决实际问题的。

7.1 算法原理：说白了就是“贪心”

Dijkstra算法的核心思想，我总结成一句话：每次找离起点最近的那个点，然后看看能不能通过它让别的点更近。

你想想看，这像不像我们平时找路？从A点到B点，你肯定先看看周围哪条路最近，走过去，再继续看。嗯，就是这么个逻辑。

核心三要素：

  • 起点：AGV的当前位置
  • 距离表：记录每个节点到起点的最短距离
  • 访问标记：哪些节点已经确定了最短路径

我在项目中遇到过一个问题：如果地图上有负权重的边（比如某些通道特别快），Dijkstra就会失效。所以记住，这个算法只适用于非负权重的图。仓储场景里，路径长度、时间成本都是正数，所以刚好能用。

7.2 伪代码：看着复杂，其实就几步

我个人习惯把伪代码写在白板上，边写边想。下面这个版本是我在项目里常用的，去掉了花哨的优化，保留了最核心的逻辑。

function Dijkstra(Graph, source):
    // 初始化
    dist[source] = 0
    for each vertex v in Graph:
        if v != source:
            dist[v] = INFINITY
        visited[v] = false
    
    // 主循环
    while 还有未访问的节点:
        u = 未访问节点中dist最小的那个
        visited[u] = true
        
        for each 邻居v of u:
            if not visited[v]:
                newDist = dist[u] + weight(u, v)
                if newDist < dist[v]:
                    dist[v] = newDist
                    prev[v] = u  // 记录路径
    
    return dist, prev

你看，核心就两个操作：找最小和更新邻居。我刚开始写的时候，总把更新邻居的循环写错，后来养成了习惯——每次更新完都检查一遍prev数组，确保路径是连续的。

我的小技巧：在实际代码里，找最小节点可以用优先队列（最小堆）来优化。这样时间复杂度能从O(V²)降到O((V+E)logV)。V是节点数，E是边数。仓储地图通常节点不多（几百个），但如果你做的是大型仓库，这个优化就很有必要了。

7.3 仓储地图上的应用实例

好，理论说完了，咱们来点实际的。假设我们有一个小型仓库，地图简化成网格，每个格子是一个节点。

场景描述：

  • AGV从充电站（起点）出发，要去货架A（终点）取货
  • 地图上有障碍物（货架、柱子）
  • 每条通道的权重是长度（米）

下面这张图是我用SVG画的，展示了Dijkstra算法在仓储地图上的工作过程。

这张图里，绿色粗线就是Dijkstra算法算出来的最短路径。你可能会问：为什么绕开了货架区？因为货架区是障碍物，算法在初始化时就把这些节点标记为不可达了。

具体计算过程：

  1. 起点(100,100)距离为0，其他节点为∞
  2. 从起点出发，更新邻居：向下到(100,200)距离10m，向右到(200,100)距离10m
  3. 选最小的(100,200)，继续更新它的邻居
  4. 重复这个过程，直到终点被访问
  5. 最终得到路径：起点→(100,200)→(200,200)→(300,200)→(400,200)→(500,200)→终点

注意：我曾经在一个项目里吃过亏——地图上有个窄通道，宽度刚好够AGV通过，但Dijkstra算法只考虑了距离，没考虑通道宽度。结果AGV卡在那里了。所以，权重不能只设距离，还得考虑通行难度。比如窄通道的权重设大一点，或者干脆设成障碍物。

7.4 实际项目中的避坑指南

做仓储AGV路径规划，Dijkstra算法虽然基础，但坑不少。我踩过的几个，分享给你：

  • 地图更新不及时：仓库里货架位置会变，如果地图不更新，算法算出来的路径就是错的。我建议每次任务开始前，都重新加载一次地图。
  • 多AGV冲突：Dijkstra只算单台AGV的路径。多台AGV同时运行时，得加交通管制。我一般用时间窗法，给每段路分配时间片。
  • 动态障碍物：比如有人突然走到通道上。这时候Dijkstra得重新算。我习惯在算法外面包一层监控，检测到障碍物就触发重规划。

我的建议：如果你刚开始做AGV路径规划，先用Dijkstra把基础功能跑通。别一上来就上A*、RRT那些高级算法。基础打牢了，后面优化起来才顺手。我在第一个项目里就是太心急，结果debug花了两周。

好了，Dijkstra算法在仓储地图上的应用就讲到这里。记住，算法是死的，场景是活的。多想想你的仓库里有什么特殊情况，然后去调整算法参数。这才是工程师该干的事。

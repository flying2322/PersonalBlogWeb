7 电机驱动接口：直流无刷电机（BLDC）与伺服电机的驱动器选型与PWM接口

电机驱动接口这块，说实话是AGV控制器里最「吃硬件」的部分。你想想看，AGV要跑得快、停得稳、爬坡有力，全靠电机那几根线在干活。我这些年经手的项目，至少有一半的硬件故障最后都追溯到电机驱动环节——要么是PWM频率没匹配，要么是驱动器选型留了余量不够。

今天咱们就聊聊直流无刷电机（BLDC）和伺服电机的驱动器选型，以及那个绕不开的PWM接口设计。嗯，这里要注意，虽然两者都叫「电机」，但驱动逻辑和接口要求差别挺大的。

7.1 BLDC与伺服电机：本质区别在哪？

先理清一个概念。BLDC电机说白了就是「电子换向」的直流电机，靠霍尔传感器或者反电动势来感知转子位置。伺服电机呢？它本质上是一个「闭环系统」——电机本体+编码器+驱动器，三者打包成一个整体。

我在项目中遇到过一位同事，把BLDC当伺服用，结果定位精度差了两个数量级。为什么会这样？因为BLDC的换向逻辑是开环的，而伺服电机内部有PID闭环，位置误差会实时修正。

对比项 BLDC电机 伺服电机
控制方式 六步换向 / FOC 位置环+速度环+电流环
反馈元件 霍尔传感器（可选） 编码器（增量式/绝对式）
典型应用 AGV驱动轮、风机 机械臂关节、高精度定位
成本 低 高

选型时我的个人习惯是：如果AGV只需要跑直线、转弯，BLDC完全够用。但如果你要做「毫米级」的停车定位，比如仓储AGV对接货架，那伺服电机是必须的。

7.2 驱动器选型：三个核心参数

选驱动器，说白了就是看三个数：电压、电流、控制接口。我见过有人拿着48V的电机配24V的驱动器，结果电机转起来软绵绵的，爬坡直接趴窝。

核心参数速查表：

  • 额定电压：必须与电池组电压匹配。AGV常用24V/48V，大负载用72V。
  • 峰值电流：至少是电机额定电流的2倍。启动瞬间电流会冲得很高。
  • PWM频率：BLDC一般16kHz~20kHz，伺服电机通常更高（20kHz~40kHz）。

我曾经踩过一个坑：选了一款标称20A的驱动器，结果电机堵转时电流冲到35A，驱动器直接烧了。后来我学乖了，选型时留出50%的电流余量，并且加装硬件过流保护。

7.3 PWM接口设计：不只是「占空比」那么简单

PWM接口，很多人以为就是给个方波调速度。其实没那么简单。你想想看，PWM的频率、电平、死区时间，任何一个参数没调好，电机都会「唱歌」——就是那种高频啸叫声。

我个人习惯用以下配置作为起点：

/* BLDC电机PWM配置示例（基于STM32定时器） */
TIM_HandleTypeDef htim1;
htim1.Instance = TIM1;
htim1.Init.Prescaler = 0;
htim1.Init.CounterMode = TIM_COUNTERMODE_CENTERALIGNED1;
htim1.Init.Period = 4200;  // 16.8kHz @ 72MHz
htim1.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
htim1.Init.RepetitionCounter = 0;
htim1.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_ENABLE;

/* 死区时间设置：500ns */
TIM_BreakDeadTimeConfigTypeDef sBreakDeadTimeConfig = {0};
sBreakDeadTimeConfig.OffStateRunMode = TIM_OSSR_ENABLE;
sBreakDeadTimeConfig.OffStateIDLEMode = TIM_OSSI_ENABLE;
sBreakDeadTimeConfig.LockLevel = TIM_LOCKLEVEL_1;
sBreakDeadTimeConfig.DeadTime = 36;  // 500ns @ 72MHz
sBreakDeadTimeConfig.BreakState = TIM_BREAK_ENABLE;
sBreakDeadTimeConfig.BreakPolarity = TIM_BREAKPOLARITY_HIGH;
sBreakDeadTimeConfig.BreakFilter = 0;
sBreakDeadTimeConfig.AutomaticOutput = TIM_AUTOMATICOUTPUT_ENABLE;

嗯，这里要注意死区时间。如果死区设得太短，上下桥臂会直通短路；设得太长，电机效率会下降。我一般从500ns开始调，用示波器看波形，直到没有交叠为止。

警告：千万不要在电机运行时热插拔PWM信号线！我曾经有一次调试时手滑了，结果驱动器MOS管瞬间击穿，冒烟了。正确的做法是：先断电，再接线，最后上电。

7.4 接口电路：电平转换与隔离

控制器一般是3.3V或5V逻辑，但很多驱动器要求5V或24V的PWM信号。这时候就需要电平转换。我推荐用光耦隔离，尤其是AGV这种工业环境，电机启停会产生很大的电磁干扰。

一个典型的接口电路长这样：

/* 光耦隔离PWM接口 */
// 控制器侧：3.3V PWM输出 -> 光耦输入
// 驱动器侧：光耦输出 -> 24V PWM输入

// 光耦选型建议：6N137（高速）或 HCPL-063L
// 上拉电阻：4.7kΩ @ 24V
// 限流电阻：330Ω @ 3.3V

我建议在PWM线上串联一个22Ω的小电阻，可以抑制振铃。这个经验是从一次EMC测试失败中得来的——不加电阻时，辐射超标了6dB。

7.5 避坑指南：我踩过的三个雷

  1. PWM频率与电机电感不匹配：频率太低，电流纹波大，电机发热严重。频率太高，驱动器开关损耗大。我一般用公式 f = R / (2πL) 估算，然后实测调整。
  2. 编码器接口没做差分：伺服电机的编码器信号，尤其是长线传输时，必须用RS-422差分。我见过有人直接用单端TTL，结果走线超过1米就开始丢脉冲。
  3. 忽略制动电阻：AGV急停时，电机会回馈能量。如果驱动器没有制动电阻，母线电压会飙升，击穿电容。我习惯选带内置制动电阻的驱动器，或者外挂一个功率电阻。

小技巧：调试时先用低速PWM（比如1kHz）验证接线是否正确，确认无误后再切换到工作频率。这样可以避免因接线错误导致驱动器炸管。

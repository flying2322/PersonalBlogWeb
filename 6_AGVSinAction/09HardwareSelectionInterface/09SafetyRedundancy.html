9 安全与冗余设计：急停电路、双通道安全继电器、STO（安全转矩关闭）功能实现

做AGV控制器设计，安全这块儿是底线。说实话，我见过太多项目因为安全设计不到位，最后被客户拒收，甚至出了事故。今天咱们就聊聊AGV安全设计里最核心的三个东西：急停电路、双通道安全继电器、还有STO功能。

9.1 急停电路：不是简单按个按钮

急停电路看着简单，不就是个按钮吗？嗯，这里要注意，工业级的急停和你想的不一样。

急停电路的核心要求：

  • 硬接线：必须用物理触点，不能用软件逻辑。软件会死机，硬件不会。
  • 双通道：两个独立的触点通道，一个坏了另一个还能工作。
  • 强制断开：按钮必须是“推入锁定、旋转复位”类型，不能是自锁开关。
  • 常闭触点：正常工作时触点闭合，按下时断开。这样断线了也能触发急停。

重要原则：急停电路必须采用“断电安全”设计。也就是说，任何故障（断线、短路、电源丢失）都应该导致安全状态——电机停止。

我在项目中遇到过一件事：有个同事用PLC的输入点来检测急停按钮状态，然后软件里做停止逻辑。结果PLC死机了，AGV直接撞墙。从那以后，我坚持急停必须走硬线直连到接触器或驱动器。

9.2 双通道安全继电器：冗余不是浪费

双通道安全继电器，说白了就是两个继电器并联工作。为什么要两个？因为单个继电器可能发生触点粘连——触点粘住了断不开，那急停就失效了。

双通道安全继电器的工作原理：

  1. 两个通道独立检测急停信号
  2. 两个通道的输出触点串联到安全回路
  3. 任何一个通道检测到急停，都能切断安全回路
  4. 两个通道定期做“交叉检测”，确保彼此都正常

我曾经遇到过一个案例：客户反馈AGV急停后电机还在转。查了半天，发现是安全继电器的其中一个通道触点粘连了，但另一个通道正常，所以系统没报错。这就是为什么双通道还不够，还得有交叉检测。

选型建议：我习惯用Pilz或Sick的安全继电器，可靠性高，而且有诊断输出，可以实时监控通道状态。别为了省钱用普通继电器，那是在拿安全开玩笑。

9.3 STO（安全转矩关闭）功能实现

STO是驱动器级别的安全功能。说白了，就是让驱动器直接切断电机的转矩输出，而不是靠软件发个“停止”指令。

STO的实现方式：

  • 驱动器内部有独立的硬件电路，切断功率管的驱动信号
  • STO信号通常是双通道输入，符合SIL3或PL e安全等级
  • STO激活后，电机不会主动制动，但会自由滑行

你想想看，如果靠软件发停止指令，万一软件卡死了怎么办？STO是硬件级别的切断，软件再崩溃也影响不了它。

注意：STO只是切断转矩，不是制动。如果AGV在斜坡上，STO激活后车会溜坡。所以需要配合机械刹车使用。我见过有人把STO当刹车用，结果车滑出去撞了人。

9.5 实际电路设计要点

讲完了架构，咱们看看实际电路怎么搭。我分享几个关键点：

急停电路接线规范：

急停按钮1 (通道A) ----> 安全继电器输入A1
急停按钮1 (通道B) ----> 安全继电器输入B1
急停按钮2 (通道A) ----> 安全继电器输入A2
急停按钮2 (通道B) ----> 安全继电器输入B2

安全继电器输出A ----> 驱动器STO-A
安全继电器输出B ----> 驱动器STO-B
安全继电器输出A ----> 接触器线圈 (串联)
安全继电器输出B ----> 接触器线圈 (串联)

STO接线示例（以某品牌驱动器为例）：

// STO双通道输入
STO1+ (24V)  <---- 安全继电器输出A
STO1- (GND)  <---- 电源GND
STO2+ (24V)  <---- 安全继电器输出B
STO2- (GND)  <---- 电源GND

// 注意：STO1和STO2必须同时有效，驱动器才能输出转矩
// 任何一个失效，驱动器立即切断转矩

避坑指南：我曾经遇到过STO信号线走得太长，和动力线平行布线，结果干扰导致STO误触发。后来我把STO信号线用了屏蔽双绞线，单独走线槽，问题就解决了。记住：安全信号线必须远离动力线。

9.6 安全功能验证

设计完了怎么验证？我一般按这个流程走：

  1. 单点故障测试：断开一个通道，看系统是否进入安全状态
  2. 恢复测试：故障恢复后，系统是否自动复位（应该不能，必须手动复位）
  3. 响应时间测试：从按下急停到电机停止，时间是否满足要求（一般要求<100ms）
  4. 耐久性测试：反复操作急停1000次以上，看触点是否磨损

个人经验：我习惯在安全继电器后面加一个LED指示灯，显示每个通道的状态。调试的时候一眼就能看出哪个通道有问题，省得拿万用表到处测。

好了，安全设计这块儿就聊到这儿。记住一句话：安全设计不是成本，是投资。一次事故的代价，够你买几百个安全继电器了。

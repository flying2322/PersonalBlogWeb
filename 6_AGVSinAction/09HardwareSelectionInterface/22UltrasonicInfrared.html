22 超声波与红外传感器：避障与辅助定位中的低成本方案

做AGV这么多年，我越来越觉得一个道理：不是所有问题都需要激光雷达来解决。

你想想看，一台AGV的成本大头在哪？导航模块、驱动系统、电池。如果每个角落的避障都要上激光雷达，那成本直接起飞。我见过不少项目，客户预算有限，但要求又不少——这时候，超声波和红外传感器就成了我的「救命稻草」。

说白了，这两种传感器就是低成本方案里的「哼哈二将」。一个擅长测距，一个擅长检测有无。配合好了，能解决80%的避障和辅助定位问题。

核心观点：超声波负责「远距离粗测」，红外负责「近距离精判」。两者互补，成本不到一个激光雷达的十分之一。

22.1 超声波传感器：测距的「老黄牛」

超声波传感器的工作原理，其实特别简单。发射一个40kHz的声波脉冲，等它碰到物体反射回来，算一下时间差，距离就出来了。公式就是：距离 = 声速 × 时间 / 2。

我在项目中常用的是HC-SR04和US-100这两款。HC-SR04便宜，几块钱一个，但精度一般。US-100贵一点，带温度补偿，精度能到±1cm左右。

选型时我一般看这几个参数：

  • 探测距离：常用2cm~4m，太近了有盲区，太远了衰减严重
  • 波束角：一般是15°~30°，角度越大越容易误判
  • 响应频率：20Hz~50Hz，别指望它能像激光雷达那样每秒扫几百次
  • 接口类型：IO触发+脉冲输出，或者UART/IO-Link

我的经验：超声波传感器对软性物体（比如布料、海绵）几乎无效。声波会被吸收，回波很弱。我在一个仓储AGV项目里就吃过这个亏——货架上的塑料膜把超声波「吃掉」了，AGV直接撞上去。后来加了红外做补充才解决。

22.2 红外传感器：近距离的「哨兵」

红外传感器分两种：一种是反射式，发射红外光，检测反射回来的光强；另一种是TOF（飞行时间），原理类似超声波，但用的是光。

反射式红外传感器，比如夏普的GP2Y0A系列，输出模拟电压，距离越近电压越高。但有个问题——它对颜色敏感。黑色物体吸光，反射回来的光弱，测出来的距离会偏大。白色物体相反。

TOF红外传感器，比如VL53L0X，精度高多了，能到±1mm。但探测距离短，一般不超过2m。我习惯用它做对接定位——比如AGV要停到充电桩前，用TOF红外测最后几厘米的距离，比超声波准得多。

选型对比：

类型 典型型号 探测距离 精度 适用场景
反射式红外 GP2Y0A21 10cm~80cm ±3cm 避障检测、物体有无
TOF红外 VL53L0X 0~2m ±1mm 精准定位、对接
超声波 US-100 2cm~4m ±1cm 中远距离测距

22.3 避障方案：超声波+红外「双保险」

我设计避障系统时，一般会这样搭配：

  • 车头前方：安装3个超声波传感器（左、中、右），覆盖120°范围。负责检测前方0.2m~3m的障碍物。
  • 车头底部：安装2个红外传感器（左右各一），负责检测0.1m~0.5m的低矮障碍物。超声波有盲区，红外正好补上。
  • 车尾：安装1个超声波，防止倒车时撞到东西。

控制逻辑也不复杂：

// 伪代码示例：避障逻辑
while(AGV运行中) {
    dist_ultra = 读取超声波距离();
    dist_ir = 读取红外距离();

    if(dist_ultra < 0.5m || dist_ir < 0.3m) {
        紧急停车();
        发出警报();
    } else if(dist_ultra < 1.0m) {
        减速至0.3m/s();
        重新规划路径();
    } else {
        正常行驶();
    }
}

注意：超声波和红外传感器容易受环境干扰。超声波会被风扇噪声、电机噪声干扰；红外会被阳光、灯光干扰。我一般会在软件里做「多次采样取中值」滤波，或者加一个「置信度判断」——如果连续3次采样值波动超过20%，就认为数据不可靠，强制停车。

22.4 辅助定位：低成本也能「找北」

说到定位，大家第一反应就是激光SLAM、二维码、UWB。但有些场景，比如走廊、隧道、货架通道，其实可以用超声波和红外做辅助定位。

我做过一个项目：AGV在一条2m宽的走廊里运行。走廊两侧是货架，AGV需要保持在中间。我在AGV左右两侧各装一个超声波传感器，实时测量到两侧货架的距离。

控制逻辑是这样的：

// 走廊居中控制
left_dist = 读取左侧超声波();
right_dist = 读取右侧超声波();
偏差 = left_dist - right_dist;

if(偏差 > 5cm) {
    向右调整方向();
} else if(偏差 < -5cm) {
    向左调整方向();
} else {
    保持直行();
}

效果还不错，偏差能控制在±3cm以内。虽然比不上激光SLAM的±1cm，但成本只有它的十分之一。

另外，红外传感器也可以做地标检测。比如在地面上贴反光条，AGV底部装红外传感器，经过反光条时红外反射强度会突变，AGV就知道「我到某个位置了」。这其实就是一种低成本的位置校准方式。

22.6 避坑指南：我踩过的那些坑

做嵌入式这么多年，超声波和红外传感器我用了不下十几种。有些坑，我替你们先踩了。

坑一：超声波传感器之间的串扰

我曾经在一个AGV上装了4个超声波，结果它们互相干扰，数据乱跳。后来我用了「时分复用」——每个传感器轮流工作，间隔50ms。问题解决。

坑二：红外传感器对阳光敏感

有一次AGV在室外运行，红外传感器直接「瞎了」。阳光里的红外成分太强，传感器饱和了。后来我加了遮光罩，并且只在室内用红外。

坑三：超声波对斜面物体的误判

AGV前方有个斜坡，超声波打上去，回波反射到别处去了，传感器以为前方没东西。结果AGV直接冲上去。后来我调整了安装角度，让超声波稍微向下倾斜，保证回波能回来。

22.7 小结

超声波和红外传感器，虽然不如激光雷达那么「高大上」，但在低成本AGV方案里，它们是不可或缺的。我个人的建议是：

  • 避障场景：超声波为主，红外为辅。超声波负责中远距离，红外负责近距离盲区。
  • 辅助定位场景：红外TOF做精准对接，超声波做走廊居中或侧方测距。
  • 软件层面：一定要做滤波和置信度判断，别裸奔。

嗯，这套方案我用了好几年，稳定可靠。下次你遇到预算紧张的项目，不妨试试看。

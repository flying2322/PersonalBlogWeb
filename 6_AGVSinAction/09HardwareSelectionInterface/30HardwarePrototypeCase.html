30 实战案例：从需求分析到原型打样的完整硬件设计流程

说实话，很多工程师做硬件设计容易犯一个毛病——拿到需求就急着画原理图。我早年也吃过这个亏，结果画到一半发现接口不够用，或者选型时发现某个芯片交期要16周。今天我就拿一个真实的AGV控制器项目，带你完整走一遍从需求到打样的流程。

项目背景：某仓储物流公司需要一款中型AGV控制器，要求支持差速驱动、激光导航、前后避障、电池管理，以及Wi-Fi和5G双模通信。目标成本控制在800元以内，开发周期12周。

第一步：需求拆解与功能定义

拿到需求后，我习惯先画一张功能框图。说白了，就是把客户说的「我要能跑、能停、能避障」翻译成具体的硬件模块。

你看，这样一画，整个控制器的骨架就出来了。每个模块需要什么接口、多少IO、什么通信协议，一目了然。

第二步：关键器件选型

选型这一步，我建议你做个表格，把候选方案列出来对比。别光看数据手册上的参数，还得考虑交期、价格、封装、散热。

模块 候选方案1 候选方案2 我的选择 理由
主控MCU STM32H743 i.MX RT1170 STM32H743 生态成熟，团队熟悉，交期稳定
电机驱动 DRV8701 L6206 DRV8701 集成度高，外围元件少
激光雷达 思岚RPLIDAR A3 北醒TFmini 思岚A3 测距远，抗干扰强
无线模块 ESP32-S3 高通QCM6490 ESP32-S3 成本低，Wi-Fi+BLE一体
电池管理 BQ24610 MAX17320 BQ24610 充电效率高，支持路径管理

我的经验：选型时一定要留20%的余量。比如电机峰值电流10A，驱动芯片至少选15A的。我曾经在一个项目里卡着极限选型，结果样机测试时驱动芯片直接冒烟了。

第三步：原理图设计

原理图设计阶段，我习惯按功能模块分页画。每一页只放一个功能模块，比如电源页、MCU页、驱动页、接口页。这样后期调试和改版都方便。

这里我重点说说电源树的设计。AGV控制器里电压种类多——24V电池输入、12V给电机驱动、5V给传感器、3.3V给MCU、1.8V给DDR。你得算清楚每一路的电流需求。

/* 电源树电流估算示例 */
/* 24V输入 -> 12V@3A (电机驱动) */
/*         -> 5V@2A   (激光雷达 + 超声波) */
/*         -> 3.3V@1A (MCU + 传感器) */
/*         -> 1.8V@0.5A (DDR4) */

/* 总功率估算 */
P_total = 12V*3A + 5V*2A + 3.3V*1A + 1.8V*0.5A
        = 36W + 10W + 3.3W + 0.9W
        = 50.2W

/* 考虑80%效率，输入功率约62.75W */
/* 24V输入电流约2.6A */

注意：电源的布局顺序很重要。我建议24V进来先过防反接和保险丝，再进DC-DC。千万别把大功率负载和小信号电路共用一个LDO，否则纹波会让你怀疑人生。

第四步：PCB布局与布线

PCB布局这块，我个人的原则是「大功率走一边，小信号走一边」。电机驱动的功率线尽量短、尽量粗，远离MCU和传感器接口。你想想看，电机启动时瞬间电流能到十几安，产生的电磁干扰足以让激光雷达数据跳变。

另外，AGV控制器通常有振动环境，所以连接器要选带锁扣的。我记得有一次客户反馈说AGV跑着跑着就死机了，查了半天发现是排线松了。从那以后，我所有板子上的排线座都改用带锁扣的型号。

第五步：原型打样与调试

打样之前，我建议你先做一次完整的「设计评审」。叫上软件工程师、测试工程师、甚至生产线的同事一起过一遍原理图和PCB。很多时候，生产同事会指出一些你没想到的问题，比如某个接插件不好焊接、某个测试点被大电容挡住了。

打样回来后，调试顺序也有讲究：

  1. 先测电源——不上主控，先量每一路电压是否正常，纹波是否在范围内
  2. 再测时钟——用示波器看晶振起振了没有，频率准不准
  3. 然后测MCU——下载一个点灯程序，确认GPIO能正常控制
  4. 接着测通信——UART、I2C、SPI逐个验证
  5. 最后测驱动——接上电机，测PWM波形和电流反馈

避坑指南：我曾经在调试时跳过电源纹波测试，直接上主控。结果MCU偶尔复位，查了三天才发现是DC-DC的反馈电阻焊错了，输出只有3.0V而不是3.3V。从那以后，电源测试我从来不敢省。

第六步：EMC与可靠性测试

原型打样出来能跑了，不代表就完事了。AGV要在仓库里24小时运行，EMC和可靠性必须过。我一般会做这几项测试：

  • 静电放电（ESD）测试——接触放电±6kV，空气放电±8kV
  • 快速瞬变脉冲群（EFT）测试——电源端口±2kV
  • 浪涌（Surge）测试——差模±1kV，共模±2kV
  • 振动测试——5~500Hz，2g加速度，每个轴向2小时

如果EMC没过，别急着改板。先看看是辐射超标还是传导超标，对症下药。辐射超标多半是时钟线或PWM线没处理好，加磁珠或者调整走线就能解决。传导超标通常是电源输入端的滤波没做好，换个大点儿的共模电感试试。

总结一下

从需求分析到原型打样，整个流程走下来大概需要6~8周。其中选型和原理图设计占2周，PCB布局布线占2周，打样和调试占2~4周。你想想看，如果选型阶段多花两天把方案吃透，后面调试阶段能省下一周的时间。这笔账，怎么算都划算。

嗯，以上就是我处理AGV控制器硬件设计时的完整流程。每个项目细节可能不同，但骨架是一样的。希望对你有所帮助。

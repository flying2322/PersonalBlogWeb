15 轨迹平滑与插值——贝塞尔曲线、B样条曲线、多项式插值在路径平滑中的应用

做AGV导航这些年，我踩过最大的坑之一，就是「路径够短，但车跑不动」。

你想想看，全局规划器给出一条折线路径，每个拐点都是锐角。小车到了拐角，要么急刹点头，要么直接冲出路径。乘客体验差不说，电机和舵机也容易坏。

所以，轨迹平滑不是锦上添花，而是刚需。今天我们就聊聊三种最常用的平滑工具：贝塞尔曲线、B样条曲线、多项式插值。

15.1 为什么需要轨迹平滑？

原始路径通常由一系列离散点组成，比如A*或Dijkstra输出的网格路径。这些路径有两个问题：

  • 不连续的一阶导数：速度会突变，小车得频繁启停
  • 不连续的二阶导数：加速度突变，电机冲击大，甚至打滑

平滑的目标，就是让路径的位置、速度、加速度都连续。说白了，让车走得「顺滑得像老司机在开车」。

核心指标：路径平滑度通常用曲率变化率（jerk）来衡量。jerk越小，乘坐越舒适，电机寿命越长。

15.2 贝塞尔曲线：简单直观，但全局牵一发动全身

贝塞尔曲线是我最早接触的平滑方法。它的数学形式很简单：

B(t) = Σᵢ₌₀ⁿ C(n,i) * (1-t)^(n-i) * t^i * Pᵢ

其中Pᵢ是控制点，t∈[0,1]。n个控制点生成n-1阶曲线。

15.2.1 特点与坑

  • 优点：计算简单，凸包性质好（曲线不会跑出控制点围成的多边形）
  • 缺点：修改一个控制点，整条曲线都会变。这在局部避障时很要命

我记得有一次做仓储AGV，货架间通道很窄。用贝塞尔曲线平滑路径，结果为了避开一个临时障碍物，我挪了一个控制点，整条路径都歪了，差点撞到对面货架。后来我果断换了B样条。

我的建议：贝塞尔曲线适合静态、简单场景，比如起点到终点的单段路径。如果场景动态变化多，慎用。

15.3 B样条曲线：局部可控，工业首选

B样条曲线解决了贝塞尔的全局性问题。它的核心思想是：每个控制点只影响局部一段曲线。

数学上，B样条用基函数替换了伯恩斯坦多项式：

C(t) = Σᵢ₌₀ⁿ Nᵢₖ(t) * Pᵢ

其中Nᵢₖ(t)是k阶B样条基函数，由节点向量决定。

15.3.1 关键参数：阶数与节点向量

阶数k 连续性 典型应用
2（线性） C⁰ 折线路径，不常用
3（二次） C¹ 速度连续，适合低速AGV
4（三次） C² 加速度连续，工业AGV标配

我个人习惯用三次B样条。为什么？因为C²连续性保证了加速度不突变，电机控制起来很舒服。我在一个汽车产线项目中，用三次B样条平滑路径后，AGV的抖动减少了70%。

避坑指南：我曾经在节点向量设置上吃过亏。如果节点向量不均匀，曲线会在某些区域「挤在一起」，曲率突变。建议使用均匀节点向量，除非你有特殊需求（比如在某个区域需要更密的控制点）。

15.4 多项式插值：精确通过关键点

有时候，我们需要路径精确通过某些点，比如充电桩对接位置、电梯口。这时候贝塞尔和B样条都不太合适——它们只是「逼近」控制点，不保证通过。

多项式插值可以做到：给定n+1个点，构造一个n次多项式，让曲线精确穿过每个点。

15.4.1 三次多项式插值

最常用的是三次多项式插值，因为它能保证C²连续，且计算量适中：

p(t) = a₀ + a₁t + a₂t² + a₃t³

通过求解线性方程组，得到系数a₀~a₃。

15.4.2 分段多项式（样条插值）

如果点太多，用一个高次多项式会振荡得很厉害（龙格现象）。所以实际中我用三次样条插值：每两个点之间用一个三次多项式，整体保证C²连续。

嗯，这里要注意：三次样条插值需要边界条件。我一般用「自然边界」，即两端二阶导数为0。这样曲线在端点处最平滑。

实战对比：

  • 需要精确通过关键点 → 多项式插值/样条插值
  • 需要局部调整、动态避障 → B样条曲线
  • 简单场景、快速原型 → 贝塞尔曲线

15.6 实战中的选择策略

说了这么多理论，到底怎么选？我总结了一个简单的决策流程：

  1. 路径是否需要精确通过某些点？ → 是，用三次样条插值；否，进入下一步
  2. 场景是否动态变化（障碍物移动）？ → 是，用B样条曲线（局部调整）；否，进入下一步
  3. 计算资源是否紧张？ → 是，用贝塞尔曲线；否，B样条曲线更稳妥

我的个人习惯：在量产项目中，我默认用三次均匀B样条。它平衡了平滑度、局部可控性和计算效率。只有在对接、充电等需要精确位置的场景，我才切换到三次样条插值。

15.7 代码片段：三次B样条平滑

最后，分享一个我常用的三次B样条平滑函数。它接受原始路径点，输出平滑后的轨迹：

def bspline_smooth(points, num_samples=100):
    """
    三次均匀B样条平滑
    points: 控制点列表，形状 (n, 2)
    num_samples: 采样点数
    """
    n = len(points)
    if n < 4:
        return points  # 至少需要4个控制点
    
    t = np.linspace(0, 1, num_samples)
    # 三次均匀B样条基函数
    def N03(t): return (1-t)**3 / 6
    def N13(t): return (3*t**3 - 6*t**2 + 4) / 6
    def N23(t): return (-3*t**3 + 3*t**2 + 3*t + 1) / 6
    def N33(t): return t**3 / 6
    
    smooth_path = []
    for i in range(n - 3):
        for ti in t:
            x = N03(ti)*points[i][0] + N13(ti)*points[i+1][0] + \
                N23(ti)*points[i+2][0] + N33(ti)*points[i+3][0]
            y = N03(ti)*points[i][1] + N13(ti)*points[i+1][1] + \
                N23(ti)*points[i+2][1] + N33(ti)*points[i+3][1]
            smooth_path.append([x, y])
    return np.array(smooth_path)

这段代码我用了好几年，在多个项目中验证过。你直接复制就能用，注意控制点至少4个。

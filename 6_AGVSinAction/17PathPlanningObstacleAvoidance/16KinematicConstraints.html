16 运动学模型与约束：差速驱动、阿克曼驱动模型、最大速度/加速度约束

各位同学，今天我们来聊聊移动机器人的“腿脚”——运动学模型。说白了，就是机器人怎么动起来，以及它受哪些限制。

我在做AGV项目时，发现很多新手一上来就写路径规划算法，结果规划出来的路径机器人根本走不了。为什么？因为没考虑运动学约束。你想想看，让一个差速驱动的机器人原地转个弯，跟让一辆汽车原地掉头，那能一样吗？

所以这一章，我们就把这两个最主流的驱动模型讲透。嗯，开始吧。

16.1 差速驱动模型

差速驱动，说白了就是两个轮子各自独立驱动，靠速度差来实现转向。这是AGV里最常见的方案，成本低、结构简单、灵活性高。

16.1.1 运动学方程

先看最基本的模型。假设左右轮速度分别为 \(v_L\) 和 \(v_R\)，轮距为 \(L\)，那么机器人的线速度 \(v\) 和角速度 \(\omega\) 为：

v = (v_R + v_L) / 2
ω = (v_R - v_L) / L

这个公式我建议你背下来。我在调试第一个AGV时，就是因为搞反了正负号，机器人原地打转了半天。后来才发现，左右轮速度差的方向决定了转向方向。

有了 \(v\) 和 \(\omega\)，我们就可以得到机器人在全局坐标系下的位姿更新：

x' = x + v * cos(θ) * dt
y' = y + v * sin(θ) * dt
θ' = θ + ω * dt

这就是经典的航迹推算公式。嗯，这里要注意，dt 不能太大，否则误差会累积得很快。

16.1.2 约束与限制

差速驱动虽然灵活，但也有它的脾气：

  • 纯滚动约束：轮子不能侧滑。也就是说，机器人只能沿着轮子朝向的方向运动。
  • 瞬时旋转中心（ICR）：当 \(v_R = -v_L\) 时，机器人原地旋转，ICR 在车体中心。
  • 最大速度/加速度：每个轮子都有物理极限，不能无限加速。

重要：差速驱动的路径规划中，曲率半径不能小于轮距的一半。否则，机器人会打滑。

16.2 阿克曼驱动模型

阿克曼模型，就是汽车那种转向方式。前轮转向，后轮驱动。这种模型在室外AGV、无人驾驶里很常见。

16.2.1 运动学方程

阿克曼模型的关键是：所有轮子的转向中心必须交于一点。这个点就是瞬时旋转中心（ICR）。

假设前轮转向角为 \(\delta\)，轴距为 \(W\)，那么转弯半径 \(R\) 为：

R = W / tan(δ)

角速度 \(\omega\) 和线速度 \(v\) 的关系：

ω = v / R = v * tan(δ) / W

位姿更新跟差速驱动一样，但注意，阿克曼模型不能原地旋转。它的最小转弯半径由最大转向角决定。

个人经验：我在做园区物流AGV时，发现阿克曼模型在低速时转向误差很大。后来加了前馈补偿，才把轨迹跟踪精度提上去。

16.2.2 约束与限制

阿克曼模型的约束比差速驱动多：

  • 非完整性约束：不能横向移动，只能前进/后退。
  • 转向角限制：一般最大转向角在30°~40°之间。
  • 速度与转向耦合：高速时转向角不能太大，否则会侧翻。

注意：阿克曼模型在倒车时，转向方向会反向。很多新手在这里踩坑，我曾经调试时也忘了这个，结果倒车入库时直接撞墙。

16.3 最大速度/加速度约束

不管是差速还是阿克曼，都有物理极限。这些约束直接影响路径规划的可行性。

16.3.1 速度约束

速度约束主要来自：

  • 电机额定转速：决定了最大线速度。
  • 地面摩擦系数：湿滑地面要降速。
  • 负载重量：重载时速度要降低。

我一般会在配置文件中设置一个速度映射表：

// 速度约束示例
struct SpeedConstraints {
    double max_linear_velocity;   // 最大线速度 (m/s)
    double max_angular_velocity;  // 最大角速度 (rad/s)
    double max_linear_acceleration;  // 最大线加速度 (m/s²)
    double max_angular_acceleration; // 最大角加速度 (rad/s²)
};

16.3.2 加速度约束

加速度约束更关键。为什么？因为加速度决定了机器人启动和停止的平顺性。

我曾经遇到过一个问题：AGV在满载时急刹车，货物直接飞出去了。后来加了加速度限制，才解决。

加速度约束通常用梯形速度曲线或S形速度曲线来建模：

// 梯形速度曲线
if (当前速度 < 目标速度) {
    加速度 = 最大加速度;
} else {
    减速度 = 最大减速度;
}

16.4 两种模型的对比

特性 差速驱动 阿克曼驱动
灵活性 高（可原地旋转） 低（需要转弯半径）
结构复杂度 低 高
路径规划难度 中等 较高
适用场景 室内、狭窄空间 室外、高速场景
最大速度 一般较低 可以较高

好了，这一章的内容就到这里。运动学模型是路径规划的基础，你想想看，如果连机器人怎么动都不知道，规划出来的路径怎么可能走得通？

嗯，记住一句话：约束不是限制，而是保证安全的前提。

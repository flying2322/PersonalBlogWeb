14 动态避障进阶：基于学习的避障方法（RL、IL）、社会力模型

各位同学，欢迎来到动态避障的进阶篇。

前面几章我们聊了DWA、TEB这些经典方法，说实话，它们在结构化场景下表现不错。但一旦遇到人车混杂、行为高度不确定的环境，传统方法的局限性就暴露出来了。我当年在做一个仓储物流项目时，就遇到过这样的尴尬：机器人面对一个犹豫不决的行人，反复“前进-后退-再前进”，像个无头苍蝇。嗯，从那时起，我开始认真研究基于学习的避障方法。

14.1 为什么需要“学习”？

传统方法本质上是“规则驱动”的。你设定好代价函数，机器人就按部就班地求解。但问题是，真实世界中的人类行为，很难用几条规则完全描述。

  • 不确定性：行人可能突然转向、加速、甚至倒退。
  • 社会习惯：比如迎面走来时，大家会默契地偏向同一侧。
  • 交互性：你的决策会影响对方的决策，这是一个博弈过程。

说白了，传统方法缺少“预测”和“意图理解”的能力。而基于学习的方法，正好可以补上这块短板。

核心思路：让机器人从大量交互数据中，自己学会“什么行为是安全的、高效的、符合社会规范的”。

14.2 基于强化学习（RL）的避障

强化学习，说白了就是“试错学习”。机器人像个孩子，做对了给奖励，做错了给惩罚。最终学会一套最优策略。

14.2.1 核心要素定义

在避障问题中，我们通常这样定义RL的要素：

  • 状态空间：机器人自身位姿、速度，以及周围障碍物的相对位置、速度。有时还会加上目标点的方向。
  • 动作空间：通常是线速度和角速度的离散或连续值。我个人习惯用连续动作空间，控制更平滑。
  • 奖励函数：这是最关键的。我一般会设计三部分：
    • 正向奖励：接近目标点。
    • 负向惩罚：碰撞（-100）、靠近障碍物（-1/distance）。
    • 社会奖励：保持合理间距、不突然变向。

14.2.2 常用算法：PPO与SAC

在移动机器人领域，PPO（Proximal Policy Optimization）和SAC（Soft Actor-Critic）是两大主流。PPO实现简单、训练稳定；SAC则更擅长处理连续动作空间，探索性更好。

我曾经在仿真环境中对比过两者。PPO大概需要500万步才能收敛，而SAC只需要300万步。但PPO的最终策略更鲁棒，不容易出现“抖动”现象。

我的经验：如果你刚入门，先从PPO开始。它就像一把瑞士军刀，虽然不够锋利，但什么都能干。等你对调参有感觉了，再尝试SAC。

14.2.3 训练流程与代码骨架

下面是一个简化版的训练循环，我用的是PyTorch + Stable-Baselines3：

import gym
from stable_baselines3 import PPO
from stable_baselines3.common.env_util import make_vec_env

# 1. 创建环境（这里用自定义的避障环境）
env = make_vec_env("AvoidanceEnv-v0", n_envs=4)

# 2. 初始化模型
model = PPO(
    "MlpPolicy",
    env,
    learning_rate=3e-4,
    n_steps=2048,
    batch_size=64,
    verbose=1
)

# 3. 开始训练
model.learn(total_timesteps=1_000_000)

# 4. 保存模型
model.save("ppo_avoidance")

嗯，这里要注意：仿真环境的设计直接决定了训练效果。我见过太多人花90%的时间调算法，却忽略了环境本身的逼真度。你想想看，如果仿真里的行人都是直线运动，那学出来的策略到了真实世界肯定抓瞎。

14.3 模仿学习（IL）：向人类专家学习

强化学习有个痛点：奖励函数很难设计。你给少了，机器人学不会；给多了，它可能钻空子。比如你只惩罚碰撞，它可能就停在原地不动了——反正不撞就行。

模仿学习（Imitation Learning, IL）提供了另一种思路：让机器人直接模仿人类专家的行为。

14.3.1 行为克隆（BC）

这是最直接的方法。你收集大量人类驾驶或操控机器人的数据，然后训练一个神经网络，输入是状态，输出是动作。本质上就是一个监督学习问题。

我曾经踩过的坑：行为克隆有个致命问题——分布偏移。训练时，机器人看到的都是专家状态；但一旦它自己执行，哪怕有一点点偏差，就会进入一个从未见过的状态，然后越跑越偏。这就像学开车时，教练一直在旁边扶着方向盘，你觉得自己会了，但一松手就撞树。

14.3.2 逆强化学习（IRL）

IRL的思路更巧妙：我不直接学策略，而是从专家数据中反推出奖励函数。然后把这个奖励函数交给RL去优化。

举个例子，你观察一个老司机开车，发现他从不急刹车。IRL会推断出：这个司机的奖励函数里，对“舒适性”的权重很高。然后机器人就知道，不仅要快，还要稳。

14.4 社会力模型（Social Force Model, SFM）

讲完学习型方法，我们回头看看一个经典模型——社会力模型。它虽然不是“学习”出来的，但它的思想深刻影响了后来的很多RL方法。

14.4.1 模型原理

社会力模型认为，行人的运动受到三种“力”的驱动：

  • 驱动力：指向目标点的吸引力。
  • 排斥力：来自障碍物和其他行人的排斥。
  • 波动项：随机扰动，模拟人的不确定性。

数学上可以写成：

F_total = F_drive + Σ F_repulsion + noise

这个模型简单、可解释性强。我早期做行人轨迹预测时，就用它做baseline，效果出奇地好。

14.4.2 与RL的结合

现在很多工作把社会力模型嵌入到RL的奖励函数中。比如，让机器人的行为也符合“社会力”的约束，这样它就能更好地融入人群。

一个实用的组合方案：用社会力模型生成“社会可接受”的参考轨迹，然后用RL去跟踪这条轨迹。这样既保证了安全性，又保留了RL的灵活性。

14.6 实际部署中的建议

最后，我想分享几点实战中的体会：

  1. 不要迷信“端到端”：纯RL端到端避障，在真实机器人上部署风险很高。我建议用RL做高层决策，底层控制还是交给传统方法（如DWA）。
  2. 仿真到现实的鸿沟：训练时一定要加入随机化（domain randomization），比如改变传感器噪声、行人速度分布等。否则，你的模型在仿真里是王者，到了现实就是青铜。
  3. 社会力模型是个好“老师”：如果你没有专家数据，可以用社会力模型生成“伪专家”轨迹，然后用IL去学。这比从零开始RL要快得多。

一个小技巧：在部署RL策略时，加一个“安全过滤器”。当RL输出的动作会导致碰撞时，由传统方法接管。这样既保证了学习方法的灵活性，又守住了安全底线。

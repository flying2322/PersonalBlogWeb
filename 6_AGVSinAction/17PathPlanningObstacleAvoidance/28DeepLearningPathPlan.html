28 深度学习在路径规划中的应用

说实话，我第一次接触深度学习做路径规划时，心里是打鼓的。传统方法明明跑得好好的，为什么要用“黑盒”来搞？直到我在一个复杂仓库项目里，遇到AGV被动态堆放的货物困住——传统规划器算半天，结果还是撞上了。那一刻我意识到，有些场景，真的需要“学”出来的策略。

这一章，咱们聊聊深度学习怎么杀进路径规划领域。我会从三个主流方向展开：端到端规划、模仿学习、深度强化学习。每个方向我都会结合自己的踩坑经历来讲。

28.1 端到端规划：从传感器到控制指令

端到端规划，说白了就是“输入图像，输出转向”。中间没有显式的路径生成、没有代价地图。一个神经网络搞定一切。

我记得2016年英伟达那篇论文，用CNN直接从摄像头图像预测方向盘转角。当时我觉得这玩意儿太酷了，但心里也犯嘀咕：真的靠谱吗？

后来我在一个AGV项目里试过类似思路。输入是激光雷达的2D点云投影图，输出是线速度和角速度。模型结构大概长这样：

import torch.nn as nn

class End2EndPlanner(nn.Module):
    def __init__(self):
        super().__init__()
        # 输入: 64x64 栅格图
        self.conv = nn.Sequential(
            nn.Conv2d(3, 32, 5), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3), nn.ReLU(),
            nn.AdaptiveAvgPool2d((1,1))
        )
        self.fc = nn.Sequential(
            nn.Linear(128, 64), nn.ReLU(),
            nn.Linear(64, 2)  # 线速度 + 角速度
        )

    def forward(self, x):
        feat = self.conv(x).view(x.size(0), -1)
        return self.fc(feat)

⚠️ 踩坑提醒：我曾经天真地以为端到端模型训练好就能直接上线。结果发现，训练数据里90%都是直行场景，模型学会了“永远直走”。后来我不得不做大量数据增强，加入随机扰动和对抗样本。

端到端规划的优势是推理速度快，一个前向传播就出结果。但缺点也很明显：可解释性差，遇到没见过的场景容易“懵”。我个人建议，端到端更适合作为辅助决策，而不是唯一规划器。

28.2 模仿学习：跟着专家学开车

模仿学习的思路很直观：让专家（人或传统规划器）先跑一遍，记录下“状态-动作”对。然后训练一个神经网络，学会模仿专家的行为。

我做过一个项目，用模仿学习来学习A*规划器的行为。你想想看，A*在复杂环境里计算量很大，但它的决策质量很高。如果能用神经网络“压缩”它的策略，那推理速度就能快很多。

具体做法是这样的：

  1. 用A*在随机生成的地图上跑，收集大量轨迹数据
  2. 每个时间步，记录当前局部栅格图 + 目标方向 → 专家动作
  3. 训练一个CNN，输入栅格图，输出动作概率分布
  4. 用交叉熵损失函数优化

💡 我的经验：模仿学习最大的坑是“分布偏移”。专家在训练数据里从不出错，但模型一旦犯个小错，就会进入专家没见过的状态，然后越跑越偏。解决办法是加入DAgger算法——让模型自己跑，遇到错误时再请专家纠正。

模仿学习的好处是训练稳定，收敛快。但它本质上是在“复制”专家行为，上限不会超过专家水平。如果你想超越专家，就得看深度强化学习了。

28.3 深度强化学习：自己摸索最优策略

深度强化学习（DRL）让智能体通过试错来学习。它不需要专家数据，只需要定义好奖励函数。我在这块花的时间最多，也踩过最多的坑。

28.3.1 DDPG：连续动作空间的利器

DDPG（Deep Deterministic Policy Gradient）适合AGV这种连续控制场景。它同时维护一个Actor网络（输出动作）和一个Critic网络（评估动作好坏）。

我在一个仓储AGV项目里用过DDPG。目标是让AGV学会在密集货架间穿行。奖励函数设计成：到达目标给+100，碰撞给-50，每走一步给-0.1（鼓励少绕路）。

class DDPGAgent:
    def __init__(self, state_dim, action_dim):
        self.actor = Actor(state_dim, action_dim)
        self.critic = Critic(state_dim, action_dim)
        self.target_actor = Actor(state_dim, action_dim)
        self.target_critic = Critic(state_dim, action_dim)
        # 软更新参数
        self.tau = 0.005

    def update(self, batch):
        states, actions, rewards, next_states, dones = batch
        # 计算目标Q值
        next_actions = self.target_actor(next_states)
        target_q = rewards + 0.99 * self.target_critic(next_states, next_actions) * (1 - dones)
        # 更新Critic
        current_q = self.critic(states, actions)
        critic_loss = nn.MSELoss()(current_q, target_q.detach())
        # 更新Actor
        actor_loss = -self.critic(states, self.actor(states)).mean()
        # 软更新目标网络
        for param, target_param in zip(self.actor.parameters(), self.target_actor.parameters()):
            target_param.data.copy_(self.tau * param.data + (1 - self.tau) * target_param.data)

⚠️ 我曾经踩过的坑：DDPG对超参数极其敏感。学习率、噪声方差、回放缓冲区大小，任何一个调不好都会导致训练发散。我建议先用简单的环境调参，再迁移到复杂场景。

28.3.2 PPO：更稳定的策略优化

PPO（Proximal Policy Optimization）是目前最流行的DRL算法之一。它通过限制策略更新的步长，避免了DDPG那种“一步走错，满盘皆输”的问题。

我个人更偏爱PPO，尤其是在AGV动态避障场景。为什么呢？因为PPO的clip机制让训练更稳定，不需要像DDPG那样小心翼翼地调参。

PPO的核心思想很简单：新策略和旧策略的差异不能太大。用公式表示就是：

# PPO的clip损失函数伪代码
ratio = new_policy_prob / old_policy_prob
clipped_ratio = clamp(ratio, 1-epsilon, 1+epsilon)
loss = -min(ratio * advantage, clipped_ratio * advantage)

我在一个多AGV协同场景里测试过PPO。20台AGV同时运行，每台都有自己的PPO策略。训练了大概200万步后，它们学会了互相让路、避免死锁。效果比人工设计的协调规则好得多。

28.4 三种方法的对比与选择

说了这么多，到底该用哪种？我整理了一个对比表：

方法 需要专家数据 训练稳定性 泛化能力 推理速度 我的推荐场景
端到端规划 是（大量） 中等 差 极快 简单环境、实时性要求极高
模仿学习 是（中等） 好 中等 快 有专家数据、需要快速部署
DDPG 否 差 好 快 连续控制、有耐心调参
PPO 否 好 好 中等 复杂动态环境、多智能体

🔑 核心建议：如果你刚入门，先从模仿学习开始。它最容易上手，效果也最可控。等你对深度学习有感觉了，再挑战PPO。DDPG嘛...说实话，我现在能不用就不用，除非场景特别适合。

28.6 实战中的几点忠告

最后，分享几个我在实战中总结的经验：

  • 仿真环境一定要逼真：我曾经在Gazebo里训练得好好的模型，搬到真车上就废了。后来发现是传感器噪声模型不够真实。建议用真实数据回放来训练。
  • 奖励函数设计是门艺术：别想着一次设计完美。我通常的做法是：先给稀疏奖励（到达+100，碰撞-100），训练出基本行为后，再加稠密奖励优化路径质量。
  • 混合策略更实用：纯深度学习的方案在工业界还不太敢用。我现在的做法是：传统规划器做全局路径，深度学习做局部避障。这样既安全又灵活。
  • 别忘了做安全兜底：无论模型多好，都要加一个安全层。当模型输出异常时，切换到紧急制动。这是AGV上线的底线。

深度学习在路径规划中的应用，说白了就是“用数据代替规则”。它不会完全取代传统方法，但能在传统方法力不从心的地方大放异彩。嗯，这一章的内容就到这里。希望你能在实际项目中找到适合自己的方案。

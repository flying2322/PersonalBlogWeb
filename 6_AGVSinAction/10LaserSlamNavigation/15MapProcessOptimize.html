15 地图处理与优化：OpenCV图像处理、地图膨胀、地图裁剪、多地图拼接

各位同学，欢迎来到第十五章。前面我们讲了建图、定位，手里有了一张挺像样的栅格地图。但说实话，从传感器直接拼出来的地图，就像毛坯房——能住人，但离精装修差得远。今天我们就来聊聊怎么给地图“精装修”。

我个人习惯把地图处理分成四块：图像预处理、地图膨胀、地图裁剪、多图拼接。这四步做好了，你的AGV才能跑得稳、不撞墙、不迷路。

15.1 用OpenCV给地图“洗个澡”

栅格地图本质上是一张单通道图像。白色是空闲，黑色是障碍，灰色是未知。但SLAM建图过程中，激光点云噪声、运动畸变、栅格更新冲突，都会让地图出现“脏点”。

我遇到过最头疼的情况：明明走廊是空的，地图上却有一排孤立黑点。路径规划器一看，以为有墙，直接绕远路。后来怎么解决的？用OpenCV的形态学操作。

核心操作：先腐蚀后膨胀（闭运算），可以消除小黑点；先膨胀后腐蚀（开运算），可以断开粘连的障碍物。 
import cv2
import numpy as np

def clean_map(map_img, kernel_size=3):
    """
    地图去噪与孔洞填充
    map_img: 0=障碍, 255=空闲, 127=未知
    """
    # 二值化：将未知区域转为空闲（保守处理）
    binary = cv2.threshold(map_img, 200, 255, cv2.THRESH_BINARY)[1]
    
    # 闭运算：先膨胀后腐蚀，填充小孔洞
    kernel = np.ones((kernel_size, kernel_size), np.uint8)
    closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
    
    # 开运算：先腐蚀后膨胀，去除孤立噪点
    cleaned = cv2.morphologyEx(closed, cv2.MORPH_OPEN, kernel)
    
    return cleaned
我的经验：核大小别超过5x5，否则会把真实障碍物边缘磨平。我一般用3x3，迭代2次，效果最稳。

15.2 地图膨胀——给机器人留条活路

地图膨胀，说白了就是把障碍物“变胖”。为什么要这么做？因为机器人有体积，你不能让它贴着墙走。路径规划时，必须把机器人当成一个点来处理，所以需要提前把障碍物向外扩展一个机器人半径的距离。

嗯，这里有个坑。膨胀半径设小了，机器人容易刮蹭；设大了，通道被堵死，AGV直接罢工。我曾经在一个仓库项目里，因为膨胀半径多了5厘米，导致AGV死活过不了一个2米宽的门口。后来量了机器人对角线的转弯半径，重新算了一遍才搞定。

def inflate_map(map_img, robot_radius_pixels):
    """
    地图膨胀
    robot_radius_pixels: 机器人半径（像素单位）
    """
    # 取障碍物区域（黑色=0）
    obstacles = (map_img == 0).astype(np.uint8) * 255
    
    # 用圆形核膨胀
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, 
                                       (robot_radius_pixels*2+1, 
                                        robot_radius_pixels*2+1))
    inflated = cv2.dilate(obstacles, kernel, iterations=1)
    
    # 合并回原图
    result = map_img.copy()
    result[inflated == 255] = 0  # 膨胀区域标记为障碍
    
    return result
注意：膨胀核用圆形，别用矩形。矩形核会让墙角变成直角，机器人转弯时容易卡住。圆形核更符合实际碰撞模型。

15.3 地图裁剪——去掉没用的边角料

建图时，地图边界往往有一大片未知区域（灰色）。这些区域对导航毫无意义，反而增加计算量。裁剪的目的就是只保留有效区域。

我常用的方法是：找到所有非未知像素的最小外接矩形，然后向外扩展10个像素作为安全边距。

def crop_map(map_img, margin=10):
    """
    自动裁剪地图空白区域
    margin: 安全边距（像素）
    """
    # 找到非未知区域（值 != 127）
    valid_mask = map_img != 127
    coords = np.column_stack(np.where(valid_mask))
    
    if len(coords) == 0:
        return map_img
    
    y_min, x_min = coords.min(axis=0)
    y_max, x_max = coords.max(axis=0)
    
    # 加边距
    y_min = max(0, y_min - margin)
    x_min = max(0, x_min - margin)
    y_max = min(map_img.shape[0], y_max + margin)
    x_max = min(map_img.shape[1], x_max + margin)
    
    return map_img[y_min:y_max, x_min:x_max]
避坑指南：我曾经直接裁剪到边界，结果地图边缘的障碍物被切掉一半，导致AGV以为那里能走，一头撞上去。所以一定要留margin，至少10像素。

15.4 多地图拼接——把碎片拼成完整世界

大型仓库、工厂，一台机器人跑不完，需要多张局部地图拼成一张全局地图。拼接的核心是找到两张地图之间的变换关系（平移+旋转）。

怎么做？我一般用特征匹配法：

  1. 提取两张地图的ORB特征点
  2. 用FLANN匹配器找到对应点对
  3. 用RANSAC计算单应性矩阵
  4. 根据单应性矩阵做图像拼接
def stitch_maps(map1, map2):
    """
    拼接两张有重叠区域的地图
    """
    # 提取ORB特征
    orb = cv2.ORB_create()
    kp1, des1 = orb.detectAndCompute(map1, None)
    kp2, des2 = orb.detectAndCompute(map2, None)
    
    # 特征匹配
    bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
    matches = bf.match(des1, des2)
    matches = sorted(matches, key=lambda x: x.distance)[:50]
    
    # 提取匹配点坐标
    src_pts = np.float32([kp1[m.queryIdx].pt for m in matches]).reshape(-1,1,2)
    dst_pts = np.float32([kp2[m.trainIdx].pt for m in matches]).reshape(-1,1,2)
    
    # RANSAC计算变换矩阵
    H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
    
    # 拼接
    h1, w1 = map1.shape
    h2, w2 = map2.shape
    corners = np.float32([[0,0],[0,h1],[w1,h1],[w1,0]]).reshape(-1,1,2)
    transformed_corners = cv2.perspectiveTransform(corners, H)
    
    # 计算拼接画布大小
    all_corners = np.concatenate((transformed_corners, 
                                  np.float32([[0,0],[0,h2],[w2,h2],[w2,0]]).reshape(-1,1,2)))
    [x_min, y_min] = np.int32(all_corners.min(axis=0).ravel() - 0.5)
    [x_max, y_max] = np.int32(all_corners.max(axis=0).ravel() + 0.5)
    
    # 平移变换矩阵
    H_translation = np.array([[1,0,-x_min],[0,1,-y_min],[0,0,1]])
    
    # 执行拼接
    result = cv2.warpPerspective(map1, H_translation.dot(H), (x_max-x_min, y_max-y_min))
    result[-y_min:h2-y_min, -x_min:w2-x_min] = map2
    
    return result
关键点：拼接前一定要确保两张地图的分辨率一致（比如都是0.05m/pixel）。分辨率不同时，先重采样再拼接。我吃过这个亏，两张地图拼出来对不上，查了半天才发现分辨率差了0.001。

15.5 实战中的坑与经验

处理步骤 常见问题 我的解决方案
图像去噪 把真实障碍物边缘磨平 用3x3核，迭代不超过2次
地图膨胀 膨胀半径过大堵死通道 按机器人对角线/2计算，留5%余量
地图裁剪 切掉边缘障碍物 留10像素安全边距
多图拼接 分辨率不一致导致错位 拼接前统一分辨率

最后说一句，地图处理没有银弹。每个项目的地图质量、环境特征都不一样。我建议你拿到地图后，先可视化看看，再决定用哪些处理步骤。别上来就一套组合拳打下去，有时候少即是多。

28 室外AGV导航：RTK-GPS融合、3D激光雷达应用、越野场景导航、多传感器冗余

说实话，做室内AGV导航和做室外AGV导航，完全是两个世界。

室内环境相对可控——地面平整、特征丰富、没有GPS干扰。但到了室外，尤其是越野场景，情况就复杂多了。我最早接触室外AGV项目时，以为就是把室内那套搬出去，结果第一天测试就翻车了——地面坑洼导致激光雷达点云全乱，GPS信号被树荫遮挡，定位直接漂移了好几米。

嗯，从那天起我就明白：室外导航，必须走另一条路。

28.1 RTK-GPS与激光雷达的融合定位

室外导航，GPS是绕不开的传感器。但普通GPS精度只有米级，AGV根本没法用。这时候就要上RTK（实时动态差分定位）。

RTK的原理其实不复杂：一个基准站放在已知坐标点，一个移动站装在AGV上。基准站把观测误差通过电台或4G发给移动站，移动站做差分计算，精度就能到厘米级。

关键点：RTK-GPS的精度取决于基准站和移动站之间的基线长度。一般建议控制在10公里以内，超过这个距离，大气误差会逐渐增大，精度会下降。

但RTK-GPS也有硬伤——它怕遮挡。我遇到过在树林里、高架桥下、或者大型建筑物旁边，RTK的固定解会变成浮点解，甚至直接丢星。这时候，激光雷达就得顶上。

我的做法是：用扩展卡尔曼滤波（EKF）做松耦合融合。GPS提供全局位置约束，激光雷达提供局部位姿修正。具体来说：

// 伪代码：RTK-GPS与激光雷达的EKF融合
void fusionUpdate() {
    // 预测步骤：基于IMU和轮式里程计
    ekf.predict(imu_data, wheel_odom);
    
    // GPS更新：当RTK状态为固定解时
    if (rtk_status == FIXED_SOLUTION) {
        ekf.updateWithGPS(gps_position, gps_covariance);
    }
    
    // 激光雷达更新：当激光匹配得分较高时
    if (laser_match_score > 0.8) {
        ekf.updateWithLaser(laser_pose, laser_covariance);
    }
    
    // 输出融合后的位姿
    return ekf.getState();
}

这里有个细节：GPS的协方差矩阵要根据RTK状态动态调整。固定解时协方差设小，浮点解时协方差设大，单点解时干脆不更新。我在项目里吃过亏——浮点解时还拿它当固定解用，结果定位直接偏了半米。

28.2 3D激光雷达在室外场景的应用

室内AGV常用2D激光雷达，因为地面平坦，扫描一个平面就够了。但室外越野场景，地面起伏大，2D激光雷达根本扫不到有效信息。这时候必须上3D激光雷达。

我个人习惯用16线或32线的机械式激光雷达，比如Velodyne VLP-16或者RoboSense的RS-LiDAR-16。为什么？性价比高，点云密度够用，而且抗震动能力比固态激光雷达强。

3D激光雷达在室外的主要应用场景有三个：

  1. 地形建图：生成2.5D高程地图，用于判断可通行区域
  2. 障碍物检测：识别树干、石块、沟壑等立体障碍
  3. 定位匹配：与预建地图做点云配准，修正GPS漂移

说到地形建图，我踩过一个坑。刚开始我用的是栅格地图，每个格子存一个高度值。但越野场景下，地面起伏剧烈，单个高度值根本不够用。后来我改用多平面拟合——把点云分割成多个平面片，每个平面片存法向量和高度，效果好了很多。

经验之谈：3D激光雷达的安装高度很关键。装得太低，点云容易被车体遮挡；装得太高，近处地面点云稀疏。我一般装在车顶，离地1.5米左右，俯仰角向下倾斜5度，这样既能看清近处地形，又能兼顾远处障碍物。

28.3 越野场景导航的特殊挑战

越野场景和结构化道路完全是两码事。你想想看，室内AGV走的是水泥地，室外AGV走的是草地、泥地、碎石路，甚至还有水坑和陡坡。

我总结了几大挑战：

  • 地面非结构化：没有明显的车道线、路沿等特征，纯几何导航行不通
  • 地形起伏大：坡度、坑洼、凸起都会影响AGV的稳定性
  • 环境动态变化：树叶、草丛、积水等会随着季节和天气变化
  • GPS信号不稳定：树荫、山谷、建筑物都会遮挡卫星信号

针对这些挑战，我的策略是分层导航：

  1. 全局路径规划：基于高程地图和可通行性分析，规划出一条安全路径
  2. 局部路径规划：基于实时3D点云，做动态避障和地形适应
  3. 运动控制：根据地形坡度调整速度和转向角度，防止侧翻

可通行性分析这块，我常用的方法是：把点云投影到栅格上，每个栅格计算高度方差和坡度。高度方差大说明地面不平，坡度大说明有陡坡。设定阈值，超过阈值的栅格标记为不可通行。

注意：越野场景下，AGV的底盘类型也很重要。轮式AGV在泥地容易打滑，履带式AGV通过性更好但能耗高。我建议根据实际地形选择底盘，必要时加装差速锁或全向轮。

28.4 多传感器冗余设计

室外AGV最怕什么？最怕传感器失效。GPS被遮挡、激光雷达被泥巴糊住、IMU被震坏——这些我都遇到过。所以，冗余设计不是可选项，而是必选项。

我的冗余方案是这样的：

传感器 主用功能 冗余方案
RTK-GPS 全局定位 双天线GPS + 惯性导航
3D激光雷达 环境感知 双激光雷达（前后各一）
IMU 姿态估计 双IMU + 轮式里程计
轮式里程计 速度测量 双编码器 + 视觉里程计

这里要特别说一下双天线GPS。普通RTK-GPS只能提供位置和速度，但双天线GPS还能提供航向角。当激光雷达失效时，双天线GPS的航向角可以作为IMU的补充，防止航向漂移。

我曾经在一个项目中，AGV在树林里穿行，激光雷达被树枝刮花了镜面，点云质量急剧下降。幸好双天线GPS和IMU还在正常工作，AGV靠着惯性导航和GPS航向角，硬是撑到了开阔地带。嗯，那次之后，我再也不敢省传感器的钱了。

28.5 实战中的避坑指南

最后，分享几个我踩过的坑，希望能帮你少走弯路：

  • GPS天线安装位置：不要装在车体正中间，容易被车体遮挡。我一般装在车顶前后两端，保证至少一个天线能看到天空。
  • 激光雷达防水防尘：室外环境灰尘大、雨水多，激光雷达的镜面很容易脏。建议加装防护罩和自动清洁装置。
  • IMU标定：室外AGV的震动比室内大得多，IMU的零偏会随着震动变化。我建议每次启动前做一次静态标定，或者用在线标定算法实时补偿。
  • 地图更新：越野场景的地形会随着季节变化——夏天草丛茂密，冬天积雪覆盖。预建的地图需要定期更新，或者用SLAM做在线建图。

我曾经在一个项目中，AGV在雪地里导航，预建的高程地图完全失效——积雪把坑洼都填平了，可通行性分析全错。后来我加了一个雪深估计模块，根据激光雷达的回波强度判断积雪厚度，动态调整可通行性阈值，才算解决了问题。

说白了，室外AGV导航没有银弹。RTK-GPS、3D激光雷达、多传感器冗余，这些技术组合起来才能应对复杂的越野场景。但最重要的，还是你对每个传感器的特性有深刻理解，知道什么时候该信谁，什么时候该怀疑谁。

嗯，这就是我这些年做室外AGV导航的一些心得。希望能给你一些启发。

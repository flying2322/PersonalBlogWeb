3 激光雷达选型与驱动：单线/多线激光雷达原理、主流品牌对比、ROS驱动配置、点云数据可视化

做AGV导航，选对激光雷达，项目就成功了一半。这话一点不夸张。

我见过太多团队，算法调得再好，雷达选错了，最后定位精度就是上不去。说白了，激光雷达就是AGV的「眼睛」。眼睛不好使，脑子再聪明也白搭。

这一章，咱们就聊聊怎么选雷达、怎么配驱动、怎么看点云。全是实战干货。

3.1 单线 vs 多线：原理与适用场景

先搞清楚一个基本问题：单线和多线，到底差在哪？

单线激光雷达，顾名思义，只发射一束激光。它旋转一圈，扫出一个二维平面。你想想看，它只能知道某个角度有没有障碍物，距离是多少。高度信息？没有。

我最早做仓储AGV时，用的就是单线雷达。室内环境，地面平坦，天花板也规整，单线完全够用。说白了，它就是个「平面扫描仪」。

多线激光雷达，同时发射多束激光（16线、32线、64线甚至128线）。每一束激光对应一个垂直角度，扫出来就是三维点云。它能告诉你：前方2米处有个箱子，箱子高度0.5米。

为什么室外AGV或者复杂环境要用多线？因为地面可能有坑，头顶可能有树枝，单线雷达根本看不见。我在一个港口AGV项目里吃过这个亏——单线雷达没扫到地面的减速带，结果车颠了一下，定位直接飘了。

核心结论：

  • 室内平地、结构化环境 → 单线就够了，性价比高
  • 室外、非结构化、有坡道或悬空障碍物 → 必须上多线

3.2 主流品牌对比：我踩过的坑和推荐

市面上的激光雷达品牌很多。我按自己的经验，分几个梯队聊聊。

品牌 类型 典型型号 测距 精度 价格区间 我的评价
SICK 单线 LMS1xx / TiM系列 20-50m ±30mm ￥5000-20000 工业级稳定，但贵
Hokuyo 单线 UST-10LX / URG系列 10-30m ±40mm ￥3000-8000 轻量级，适合室内
Velodyne 多线 VLP-16 / HDL-32E 100m ±30mm ￥20000-80000 老牌劲旅，点云质量好
RoboSense 多线 RS-LiDAR-16 / 32 150m ±20mm ￥10000-30000 国产性价比之选
思岚科技 单线 RPLIDAR A2 / A3 12-25m ±50mm ￥1000-3000 入门首选，便宜够用

我个人习惯是：量产项目用SICK或Hokuyo，稳定第一。原型验证阶段，用思岚的RPLIDAR快速跑通流程。多线的话，预算充足上Velodyne，想控制成本就看看RoboSense。

避坑指南：我曾经在一个项目中选了某款低价多线雷达，标称30米测距，实际在强光下只能测15米。后来换成了Velodyne VLP-16，问题才解决。所以，别只看参数表，一定要实测。

3.3 ROS驱动配置：从零开始连上雷达

雷达买回来了，怎么让它和ROS通信？

嗯，这里要注意：不同品牌的驱动包不一样，但套路是通用的。

3.3.1 安装驱动

以思岚RPLIDAR为例，驱动在ROS官方仓库里就有：

sudo apt install ros-noetic-rplidar-ros

如果是SICK的雷达，用这个：

sudo apt install ros-noetic-sick-tim

Velodyne的驱动稍微复杂点，需要从源码编译：

cd ~/catkin_ws/src
git clone https://github.com/ros-drivers/velodyne.git
cd ..
catkin_make

3.3.2 配置launch文件

驱动装好后，需要写一个launch文件来启动雷达节点。我一般这样写：

<launch>
  <node name="rplidar_node" pkg="rplidar_ros" type="rplidarNode" output="screen">
    <param name="serial_port" value="/dev/ttyUSB0"/>
    <param name="serial_baudrate" value="115200"/>
    <param name="frame_id" value="laser_frame"/>
    <param name="angle_compensate" value="true"/>
    <param name="scan_mode" value="Standard"/>
  </node>
</launch>

这里有几个参数要特别留意：

  • serial_port：雷达插在哪个USB口？可以用 ls /dev/ttyUSB* 查看
  • frame_id：这个很重要，后续的TF变换全靠它。我习惯统一命名为 laser_frame
  • angle_compensate：建议开启，能矫正雷达安装角度偏差

权限问题：很多新手会卡在这一步。雷达插上后，如果没有读取权限，ROS节点会报错。解决办法：

sudo chmod 666 /dev/ttyUSB0

或者一劳永逸，把用户加到dialout组：

sudo usermod -a -G dialout $USER

3.3.3 启动并验证

运行launch文件：

roslaunch rplidar_ros rplidar.launch

然后新开一个终端，看看话题有没有数据：

rostopic echo /scan

如果看到一堆距离数据在刷屏，恭喜你，驱动搞定了。

3.4 点云数据可视化：用RViz看你的雷达

数据有了，怎么看？用RViz。

启动RViz：

rviz

在RViz里，你需要做这几步：

  1. 左侧面板点击「Add」→ 选择「By topic」→ 找到 /scan 话题 → 添加「LaserScan」显示
  2. 在「Global Options」里，把 Fixed Frame 设置成 laser_frame（和你launch文件里定义的一致）
  3. 调整视角，你就能看到雷达扫描出来的点云了

如果是多线雷达，话题一般是 /velodyne_points，添加「PointCloud2」显示即可。

我的小技巧：在RViz里，可以给点云设置颜色。比如按距离着色，近处红色、远处蓝色。这样一眼就能看出障碍物的远近分布。设置方法：在LaserScan显示属性里，找到「Color Transformer」→ 选择「AxisColor」或「Intensity」。

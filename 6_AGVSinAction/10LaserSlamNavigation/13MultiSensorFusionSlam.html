13 多传感器融合SLAM：IMU+激光雷达融合、GPS+激光雷达融合、LIO-SAM原理简介

做SLAM这么多年，我越来越觉得单传感器就像独腿走路。激光雷达再准，遇到长走廊、空旷场地也会迷失方向。IMU再稳，时间一长漂移就让人头疼。GPS再好，进了隧道、地下车库直接罢工。

所以，多传感器融合不是锦上添花，而是刚需。今天我们就聊聊三种主流的融合方案：IMU+激光雷达、GPS+激光雷达，以及目前工业界非常火的LIO-SAM。

1. IMU + 激光雷达融合：为什么是黄金搭档？

激光雷达测距准，但帧率低（10Hz左右）。IMU测角速度快（200Hz以上），但积分就漂。你想想看，这俩正好互补。

核心思路：用IMU的高频数据做状态预测，用激光雷达的观测做修正。说白了就是IMU负责「猜」，激光雷达负责「纠」。

融合的关键步骤：

  • 时间戳对齐：IMU和激光雷达的时间戳必须统一。我遇到过不少项目，问题就出在时间戳没对齐，结果融合效果还不如单传感器。
  • IMU预积分：在两帧激光雷达之间，对IMU数据进行预积分，得到相对位姿变化。这样做的好处是避免重复积分，计算效率高。
  • 点云畸变矫正：激光雷达扫描时，如果车在动，点云就会变形。用IMU的角速度和线速度，可以把每个点矫正到同一时刻。

我在一个仓储AGV项目里，刚开始只用激光雷达做SLAM。结果车一加速，点云就糊了，定位直接跳变。后来加了IMU做畸变矫正，效果立竿见影。嗯，从那以后我再也不敢轻视IMU了。

2. GPS + 激光雷达融合：室外大场景的救星

激光SLAM在室外大场景有个致命问题——回环检测很难做。场地太大，特征又稀疏，跑着跑着就偏了。这时候GPS就派上用场了。

融合方式：GPS提供全局位置约束，激光雷达提供局部精细地图。两者通过扩展卡尔曼滤波（EKF）或因子图进行融合。

传感器 优势 劣势 融合后效果
GPS 无累积误差，全局定位 信号易遮挡，精度低（米级） 厘米级全局定位
激光雷达 局部精度高（厘米级） 有累积误差，大场景易漂

实战经验：

我曾经在港口AGV项目里，GPS信号经常被集装箱遮挡。我的做法是：当GPS信号好时（HDOP < 1.5），把它作为强约束加入因子图；信号差时，自动降低权重甚至忽略。这样既保证了全局一致性，又不会让差GPS把局部地图带偏。

3. LIO-SAM：目前最流行的激光-惯性SLAM框架

LIO-SAM（Tightly-coupled Lidar Inertial Odometry via Smoothing and Mapping）是Tixiao Shan在2020年提出的。说实话，这个框架我用了两年多，越用越觉得设计得巧妙。

核心思想：紧耦合的激光-惯性里程计，加上因子图优化和滑窗边缘化。

LIO-SAM的四个关键模块：

  1. IMU预积分因子：在两帧激光雷达之间，用IMU数据生成相对运动约束。
  2. 激光里程计因子：当前帧点云与局部地图匹配，得到位姿观测。
  3. GPS因子：当GPS可用时，加入全局位置约束。
  4. 回环检测因子：检测到回环时，加入闭环约束，消除累积误差。

你可能会问：为什么叫「滑窗边缘化」？说白了，就是只保留最近N帧的状态，把老的状态边缘化掉。这样既保证了实时性，又不会丢失信息。

// LIO-SAM因子图构建的核心伪代码
// 我简化了部分细节，但逻辑是完整的
void addIMUFactor(NodeState prev, NodeState curr) {
    // 计算IMU预积分残差
    Eigen::Matrix6d covariance = computeIMUCovariance();
    Factor factor = new IMUFactor(prev, curr, covariance);
    graph.add(factor);
}

void addLidarFactor(NodeState node, PointCloud scan) {
    // 点云与局部地图匹配
    Pose3 relativePose = scanMatch(scan, localMap);
    Factor factor = new LidarFactor(node, relativePose);
    graph.add(factor);
}

void marginalizeOldNodes() {
    // 保留最近20帧，边缘化更早的
    if (graph.size() > 20) {
        graph.marginalize(graph.front());
    }
}

注意：

LIO-SAM对IMU的标定要求很高。我曾经因为IMU和激光雷达的外参没标好，导致融合后的轨迹出现周期性抖动。后来用了一个标定板，重新做了手眼标定，问题才解决。所以，外参标定这一步千万别省。

4. 三种方案的选型建议

说了这么多，到底该用哪种？我个人的经验是：

  • 室内场景：IMU+激光雷达就够了。LIO-SAM是首选，精度高、鲁棒性好。
  • 室外大场景：必须加GPS。但要注意GPS信号质量，别让差数据污染了局部地图。
  • 复杂环境（隧道、高楼区）：IMU+激光雷达为主，GPS作为辅助。这时候LIO-SAM的因子图框架就体现出优势了——可以灵活调整各因子的权重。

我记得有一次在矿山项目里，GPS信号时有时无，激光雷达又经常被扬尘干扰。最后我们用了LIO-SAM，把IMU的权重调高，GPS只在信号好时加入，才勉强跑通。所以说，没有万能的方案，只有合适的配置。

一句话总结：

多传感器融合不是简单地把数据加起来，而是要让每个传感器在它擅长的领域发挥作用。IMU管短时高频，激光管局部精度，GPS管全局一致性。三者配合好了，SLAM系统才能真正稳定可靠。

23 运动控制基础：PID控制、轨迹跟踪、速度规划

各位工程师朋友，今天我们来聊聊AGV运动控制的核心。说白了，就是让车怎么走、怎么停、怎么转弯才稳当。

我刚开始做AGV那会儿，觉得运动控制不就是给电机发个指令嘛。结果第一次调试，车在转弯时直接甩尾，差点撞到货架。嗯，从那以后我就老老实实把PID、轨迹跟踪、速度规划这三块啃透了。

23.1 PID控制：让车听话的基础

PID控制，比例-积分-微分控制。名字听着唬人，其实原理很简单——就是根据偏差来调整输出。

举个例子。你让AGV以1m/s的速度前进，实际测出来只有0.8m/s。偏差就是0.2m/s。PID要做的就是把这个0.2m/s的偏差，转化成电机电压的调整量。

核心公式：

u(t) = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt

其中：

  • Kp（比例）：当前偏差的放大倍数。Kp越大，响应越快，但容易震荡
  • Ki（积分）：消除稳态误差。我习惯在长时间跑偏时加大Ki
  • Kd（微分）：抑制超调。适合在转弯时使用

我在项目中遇到过一个问题：AGV空载和满载时，同样的PID参数效果完全不同。空载时Kp=2.0跑得挺好，满载时直接震荡。后来我用了增益调度——根据负载重量动态切换PID参数。

调参小技巧：

  • 先调Kp，让车能跑起来，不震荡就行
  • 再加Kd，抑制超调。我一般从0.1开始试
  • 最后加Ki，消除稳态误差。Ki别太大，否则积分饱和

23.2 轨迹跟踪：让车走直线

PID控制的是单个电机。但AGV有两个驱动轮，怎么让两个轮子配合，走出一条漂亮的直线？这就是轨迹跟踪要解决的问题。

常用的方法有两种：

方法 原理 适用场景
纯追踪法 根据当前位置和目标点的偏差，计算转向角 低速、路径简单的场景
Stanley法 基于横向偏差和航向偏差，计算前轮转角 高速、弯道多的场景

我个人习惯用纯追踪法。为什么？因为它简单、直观。你想想看，AGV就像一个人走路——眼睛盯着前方某个点，然后调整脚步方向。纯追踪法就是这个道理。

纯追踪法核心步骤：

  1. 计算当前位置到目标点的距离偏差
  2. 根据偏差计算左右轮的速度差
  3. 速度差越大，转弯越急
// 伪代码示例
delta_v = K * lateral_error  // 速度差
left_speed  = base_speed + delta_v
right_speed = base_speed - delta_v

我曾经在一条长直道上调试轨迹跟踪。AGV总是走S形，左右摇摆。后来发现是前视距离设得太短了。前视距离就是车看前方的距离——太短了反应过激，太长了反应迟钝。我一般设成车长的2-3倍。

注意：

  • 轨迹跟踪不能单独用。必须和PID控制配合
  • 转弯时速度要降下来，否则容易侧滑
  • 地面摩擦系数变化时，参数要重新调

23.3 速度规划：让车跑得稳

轨迹跟踪告诉车往哪走。速度规划告诉车走多快、怎么加速、怎么减速。

你想想看，如果AGV从静止直接全速启动，会怎么样？电机电流瞬间飙升，车也会猛地一冲。同样，如果全速行驶时突然急刹，货物可能直接飞出去。

常用的速度规划曲线有：

  • S形曲线：加速和减速都平滑，适合载货场景
  • T形曲线：加速快，适合空载或紧急情况
  • 梯形曲线：折中方案，我项目中用得最多

梯形速度规划示例：

// 三段式：加速段、匀速段、减速段
if (distance < accel_distance) {
    speed = max_speed * (distance / accel_distance)
} else if (distance < decel_start) {
    speed = max_speed
} else {
    speed = max_speed * (1 - (distance - decel_start) / decel_distance)
}

我在项目中遇到过一个问题：AGV在转弯时速度没降下来，结果离心力太大，货物倒了。后来我加了弯道减速逻辑——根据转弯半径动态调整最大速度。半径越小，速度越低。

速度规划避坑指南：

  • 加速度别设太大。我一般设0.5m/s²，载货时降到0.3m/s²
  • 减速段要留够距离。我曾经因为减速太晚，车直接冲过目标点
  • 多车协同场景下，速度规划要考虑避让逻辑

23.4 三者的关系

PID控制、轨迹跟踪、速度规划，这三者不是孤立的。它们的关系是这样的：

说白了，速度规划告诉车「你要跑多快」，轨迹跟踪告诉车「你要往哪转」，PID控制告诉电机「你要出多大力」。三层配合好了，AGV才能跑得稳、停得准。

我最后说一句：运动控制是AGV的底层能力。底层不稳，上层调度再牛也没用。所以，花时间把PID调好、把轨迹跟踪调准、把速度规划调顺，绝对值得。

本章核心要点：

  • PID控制：比例、积分、微分三个参数要配合调
  • 轨迹跟踪：纯追踪法简单实用，前视距离是关键
  • 速度规划：梯形曲线最常用，弯道要减速
  • 三层架构：速度规划→轨迹跟踪→PID控制，层层递进

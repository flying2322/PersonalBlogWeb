10 调度算法基础：FCFS、最短路径优先、最早截止时间优先

调度算法，说白了就是AGV的大脑。多车协同跑起来，谁先走、谁后走、走哪条路，全靠它来拍板。

我刚开始做AGV调度那会儿，觉得算法嘛，不就是排个队？后来踩了不少坑才明白——调度算法选不对，整个系统就跟堵车一样，谁也动不了。

今天咱们聊三种最基础的调度算法。它们虽然简单，但却是所有复杂调度策略的基石。你想想看，连FCFS都搞不明白，后面那些花里胡哨的算法就更别谈了。

10.1 FCFS（先来先服务）

FCFS，全称First Come First Served。说白了就是排队——谁先来，谁先走。

我记得第一次给客户演示系统，用的就是FCFS。客户问：“这跟超市排队有啥区别？”我说：“还真没太大区别，但超市排队不会撞车。”

核心逻辑：

  • 任务按到达时间排序
  • 先到的任务先分配AGV
  • AGV执行完一个任务，再接下一个

优点：

  • 实现简单，代码量少
  • 公平性高，不会饿死任务
  • 适合任务量少、负载低的场景

缺点：

  • 不考虑任务紧急程度
  • 不考虑AGV当前位置
  • 长任务会阻塞后续短任务

我在项目中遇到过这样一个场景：仓库里有台AGV正在执行一个远距离运输任务，耗时15分钟。后面来了个紧急补货任务，只需要2分钟。结果呢？紧急任务硬等了15分钟。客户差点急眼。

这就是FCFS的典型问题——它太“老实”了，不会插队。

10.2 最短路径优先

最短路径优先，英文叫Shortest Path First，简称SPF。这个算法的思路很直接：哪个任务离AGV最近，就先干哪个。

你可能会问：“这不就是贪心算法吗？”没错，就是贪心。每次选最优的，不考虑全局。

实现步骤：

  1. 计算每个任务起点到AGV当前位置的距离
  2. 选择距离最短的任务
  3. AGV执行任务，完成后重新计算
// 伪代码示例
function selectTask(agv, taskList) {
    let minDistance = Infinity;
    let selectedTask = null;
    
    for (let task of taskList) {
        let dist = calculateDistance(agv.position, task.startPoint);
        if (dist < minDistance) {
            minDistance = dist;
            selectedTask = task;
        }
    }
    
    return selectedTask;
}

个人经验：最短路径优先在AGV数量多、任务密集的场景下表现不错。但要注意——它容易导致“局部最优”。我曾经调试过一个系统，AGV总是围着仓库门口转，因为门口的任务离它最近。结果仓库深处的任务一直没人管。

嗯，这里要注意：最短路径优先不是真的算路径，而是算直线距离。实际路径要考虑障碍物、单向道、充电区等因素。我建议在计算距离时，至少加上一个“路径可行性”的判断。

10.3 最早截止时间优先

最早截止时间优先，Earliest Deadline First，简称EDF。这个算法关注的是“时间”——哪个任务最急，就先干哪个。

我在做汽车零部件产线调度时，EDF用得最多。产线上的物料必须在规定时间内送到工位，晚了就停线。停线一分钟，损失好几万。你说急不急？

核心思想：

  • 每个任务有一个截止时间
  • 截止时间越早，优先级越高
  • AGV优先执行截止时间最早的任务
任务ID 截止时间 优先级
T001 10:00 高
T002 10:15 中
T003 10:30 低

避坑指南：我曾经犯过一个错误——只按截止时间排序，没考虑任务执行时间。结果有个截止时间很早但执行时间很长的任务，把其他任务全堵死了。后来我加了一个“可行性检查”：如果当前AGV无法在截止时间前完成任务，就标记为“超时任务”，交给备用AGV处理。

EDF的另一个坑是“多米诺效应”。一个任务超时，可能导致后续一连串任务都超时。我建议在调度系统中加入“动态优先级调整”机制——任务越接近截止时间，优先级越高。

10.4 三种算法对比

说了这么多，咱们来做个对比。我习惯用一张表来总结：

算法 适用场景 优点 缺点
FCFS 任务量少、负载低 公平、简单 不考虑紧急程度
SPF AGV数量多、任务密集 响应快、吞吐量高 局部最优、远任务被饿死
EDF 有严格时间要求的场景 满足截止时间 多米诺效应、实现复杂

你想想看，实际项目中很少只用一种算法。我一般会组合使用：比如FCFS做基础排序，再叠加EDF的优先级调整。或者SPF选任务，但加上截止时间约束。

我的建议：刚开始做调度系统，别想着一步到位。先用FCFS跑起来，再逐步加入SPF和EDF的优化。我见过太多人一上来就搞复杂算法，结果系统跑都跑不起来。

好了，三种基础调度算法就聊到这儿。记住一句话：没有最好的算法，只有最合适的算法。选算法之前，先搞清楚你的业务场景。

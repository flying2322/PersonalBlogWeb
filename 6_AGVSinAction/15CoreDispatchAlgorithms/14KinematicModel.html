14 AGV运动学模型：差速驱动模型、舵轮驱动模型、运动约束与轨迹生成

各位同学，今天我们来聊聊AGV运动学模型。说实话，这是整个调度系统里最底层的硬核知识。你调度算法写得再花哨，如果运动学模型不对，车跑起来就是歪的。我当年刚入行时，就吃过这个亏——模型参数没调准，结果AGV在仓库里画起了龙，场面一度非常尴尬。

14.1 差速驱动模型

差速驱动，说白了就是两个独立驱动的轮子，加上一个或两个万向从动轮。通过控制左右轮的速度差来实现转向。这是最常见的AGV驱动方式，成本低、结构简单。

运动学方程

假设左右轮间距为 \(L\)，轮半径为 \(r\)，左右轮角速度分别为 \(\omega_L\) 和 \(\omega_R\)。那么AGV的线速度 \(v\) 和角速度 \(\omega\) 为：

v = (r * ω_R + r * ω_L) / 2
ω = (r * ω_R - r * ω_L) / L

嗯，这里要注意：当 \(\omega_R = \omega_L\) 时，AGV直线前进；当 \(\omega_R = -\omega_L\) 时，AGV原地旋转。我在项目中遇到过一个问题——左右轮实际半径有微小差异，导致直线行驶时总往一边偏。后来加了在线标定才解决。

位姿更新

在全局坐标系下，AGV的位姿 \((x, y, \theta)\) 更新公式为：

x' = x + v * cos(θ) * Δt
y' = y + v * sin(θ) * Δt
θ' = θ + ω * Δt

这个公式看起来简单，但实际用起来坑不少。比如Δt太大时，积分误差会累积。我建议控制周期不要超过50ms，否则轨迹会明显偏离。

核心要点：差速驱动模型是非完整约束系统，它不能侧向移动。这意味着你的路径规划必须考虑转弯半径，不能设计出直角转弯的路径。

14.2 舵轮驱动模型

舵轮驱动，就是一个轮子既能驱动又能转向。通常AGV会配两个舵轮（前后各一），或者一个舵轮加两个从动轮。这种模型的灵活性更高，但控制也更复杂。

单舵轮模型

假设舵轮安装在AGV中心线上，距离中心点为 \(d\)。舵轮的转向角为 \(\alpha\)，驱动速度为 \(v_w\)。那么AGV的运动学方程为：

v = v_w * cos(α)
ω = v_w * sin(α) / d

你看，这里多了一个转向角 \(\alpha\) 的控制自由度。我记得有一次调试舵轮AGV，发现转向响应总是滞后。后来查了半天，原来是舵轮电机的位置环PID参数没调好。嗯，这种问题光靠算法是解决不了的，得懂一点底层控制。

双舵轮模型

双舵轮更复杂一些。两个舵轮各自有独立的转向角和驱动速度。AGV的运动学需要解算两个舵轮的协同关系。这里我直接给结论：

v = (v_w1 * cos(α1) + v_w2 * cos(α2)) / 2
ω = (v_w1 * sin(α1) - v_w2 * sin(α2)) / L

其中 \(L\) 是两个舵轮之间的纵向距离。双舵轮的好处是可以实现全向移动，但代价是控制算法复杂度翻倍。

个人经验：双舵轮AGV在重载场景下优势明显。我曾经做过一个30吨级的重载AGV项目，用的就是双舵轮。但要注意，两个舵轮的同步性非常关键，稍有偏差就会产生巨大的内部应力，甚至损坏机械结构。

14.3 运动约束

AGV不是你想怎么走就能怎么走的。它受到一系列物理约束。这些约束在调度系统中必须显式建模，否则生成的轨迹就是空中楼阁。

运动学约束

  • 非完整约束：AGV不能侧向移动。数学表达为 \(\dot{x} \sin\theta - \dot{y} \cos\theta = 0\)。
  • 最大速度约束：\(v \leq v_{max}\)，受电机和减速器限制。
  • 最大加速度约束：\(a \leq a_{max}\)，受电机扭矩和地面摩擦力限制。
  • 最大转向角速度约束：\(\dot{\alpha} \leq \dot{\alpha}_{max}\)，舵轮转向电机有限制。

动力学约束

  • 最小转弯半径：差速驱动的最小转弯半径取决于轮间距，舵轮驱动取决于最大转向角。
  • 打滑约束：加速度不能超过地面附着系数。我曾经在潮湿的地面上吃过亏，AGV加速太猛直接打滑，撞上了货架。

避坑指南：我曾经在项目中忽略了加速度约束，结果生成的轨迹在理论上是可行的，但实际跑起来电机过载保护频繁触发。后来我学乖了，所有约束都要留20%的余量。记住，理论值和实际值之间永远有差距。

14.4 轨迹生成

有了运动学模型和约束，我们才能谈轨迹生成。轨迹生成的目标是：给定起点和终点（或路径点），生成一条满足所有约束的、平滑的、时间最优的轨迹。

常见的轨迹生成方法

方法 优点 缺点 适用场景
多项式插值 计算简单，平滑性好 难以处理复杂约束 简单路径，低速场景
贝塞尔曲线 凸包性质好，可控性强 高阶曲线计算量大 路径平滑，避障场景
样条曲线 分段连续，局部可控 边界条件处理复杂 复杂路径，高速场景
最优控制 理论上最优 计算量大，实时性差 离线规划，高精度场景

梯形速度规划

这是最经典的轨迹生成方法。说白了就是三段式：加速段、匀速段、减速段。公式如下：

v(t) = 
  a_max * t,                 0 ≤ t ≤ t1
  v_max,                     t1 ≤ t ≤ t2
  v_max - a_max * (t - t2),  t2 ≤ t ≤ T

其中 \(t1 = v_{max} / a_{max}\)，\(t2 = T - t1\)。这个方法简单可靠，但缺点是加速度有突变（ jerk 无穷大）。对于要求高的场景，我会用S形速度规划，让加速度也连续变化。

我的建议：在实际项目中，不要追求理论上的最优轨迹。因为AGV的机械误差、地面不平、轮胎磨损等因素，都会让理论轨迹变形。我一般会在轨迹上预留5-10cm的容差带，调度系统在这个容差带内做实时修正。

下面我用一张图来总结整个轨迹生成的流程。从路径输入到最终轨迹输出，每一步都离不开运动学模型和约束的支撑。

这张图展示了轨迹生成的核心流程。你看，从路径输入开始，先选运动学模型，再加载约束，然后做速度规划和插值，最后输出轨迹。如果约束不满足，还需要反馈回去重新规划。这个闭环在实际系统中非常重要。

小技巧：在轨迹生成时，我习惯把时间轴离散化，每个时间步长取50ms。这样既保证了精度，又不会让计算量太大。对于100米长的路径，大约需要2000个时间步，现代嵌入式处理器完全扛得住。

好了，关于AGV运动学模型的核心内容就讲到这里。差速驱动和舵轮驱动各有优劣，选择哪种取决于你的应用场景。运动约束是必须遵守的底线，而轨迹生成则是把这些约束变成可执行路径的艺术。记住，理论模型再漂亮，最终还是要落地到实际硬件上。多留点余量，多考虑点异常情况，你的系统才能稳定运行。

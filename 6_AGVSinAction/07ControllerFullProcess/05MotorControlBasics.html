5 电机控制基础

各位同学，今天我们来聊聊AGV控制器的核心——电机控制。说实话，我见过太多AGV项目，算法写得天花乱坠，结果电机都抖得像筛子一样。为什么？因为基础没打牢。这一章，我们就从直流电机的数学模型开始，一步步把PID控制、速度环、位置环，还有那个让人头疼的PWM死区补偿，全都讲透。

本章核心脉络：直流电机数学模型 → PID控制器原理 → 速度环设计 → 位置环设计 → PWM死区补偿

5.1 直流电机的数学模型

先说说直流电机。你想想看，AGV要跑起来，靠的就是电机转动轮子。但电机不是你想让它转多快它就转多快的，它有自己的物理特性。

直流电机的等效电路，说白了就是一个电阻串联一个电感，再串联一个反电动势。反电动势这东西，我刚开始学的时候总觉得很玄乎，其实就是电机转动时自己产生的电压，方向跟外加电压相反。

电枢回路的电压方程是这样的：

U = R * i + L * (di/dt) + E

其中E是反电动势，跟转速成正比：

E = Ke * ω

电机的转矩方程：

T = Kt * i

嗯，这里要注意，Ke和Kt在数值上是相等的（如果都用国际单位制）。我在项目中遇到过有人把这两个系数搞混，结果速度环怎么调都不对，查了两天才发现是系数差了一个数量级。

机械运动方程：

T - TL = J * (dω/dt) + B * ω

TL是负载转矩，J是转动惯量，B是阻尼系数。把这些方程联立起来，就得到了直流电机的完整数学模型。说白了，电机就是一个二阶系统，有电气时间常数和机械时间常数。

实战经验：电气时间常数通常比机械时间常数小得多。我一般先测电气时间常数，再测机械时间常数，这样调试PID参数时心里有底。

5.2 PID控制器原理

PID控制器，搞控制的没人不知道。但你真的理解它吗？

比例（P）部分：误差越大，输出越大。但光有P，系统会有稳态误差。我记得第一次调P参数时，把增益调得很大，结果电机嗡嗡响，像要散架一样。

积分（I）部分：消除稳态误差。但积分太强，系统会 overshoot。我有个习惯，先调P让系统稳定，再加I消除误差，最后加D改善响应。

微分（D）部分：预测误差变化趋势。D能提高响应速度，但对噪声敏感。我曾经在一条生产线上，D参数调得稍微大了一点，结果电机高频抖动，后来发现是编码器信号有毛刺。

位置式PID公式：

u(k) = Kp * e(k) + Ki * Σe(i) + Kd * [e(k) - e(k-1)]

增量式PID公式：

Δu(k) = Kp * [e(k) - e(k-1)] + Ki * e(k) + Kd * [e(k) - 2*e(k-1) + e(k-2)]

我个人习惯用增量式PID，因为输出是增量，不会出现积分饱和的问题。而且切换手动/自动时，冲击小得多。

避坑指南：我曾经在AGV项目里直接用位置式PID，结果电机启动时积分项疯狂累积，导致输出饱和，电机直接冲出去了。后来改成增量式，问题解决。

5.3 速度环与位置环设计

AGV的电机控制，通常采用串级控制结构。内环是速度环，外环是位置环。为什么这样设计？你想想看，位置控制需要速度先稳定，速度控制需要电流先稳定。一层层嵌套，就像俄罗斯套娃。

速度环的设计要点：

  • 采样频率：一般1kHz到10kHz。我常用2kHz，够用又不浪费算力
  • PI参数整定：先调P，让速度响应快但不超调；再加I，消除稳态误差
  • 限幅保护：速度输出必须限幅，防止电机过速

位置环的设计要点：

  • 采样频率：一般100Hz到500Hz。比速度环慢一个数量级
  • P参数为主：位置环通常只用P，因为速度环已经消除了稳态误差
  • 前馈控制：可以加入速度前馈，提高位置跟踪精度

我给你们看一个实际的速度环代码框架：

// 速度环中断服务函数，2kHz
void SpeedLoop_ISR(void)
{
    // 读取编码器速度
    int16_t speed_actual = Encoder_GetSpeed();
    
    // 计算速度误差
    int16_t speed_error = speed_target - speed_actual;
    
    // PI控制器
    static int32_t integral = 0;
    int16_t p_out = Kp_speed * speed_error;
    integral += Ki_speed * speed_error;
    
    // 积分限幅
    if(integral > INTEGRAL_LIMIT) integral = INTEGRAL_LIMIT;
    if(integral < -INTEGRAL_LIMIT) integral = -INTEGRAL_LIMIT;
    
    // 输出限幅
    int16_t output = p_out + integral;
    if(output > OUTPUT_LIMIT) output = OUTPUT_LIMIT;
    if(output < -OUTPUT_LIMIT) output = -OUTPUT_LIMIT;
    
    // 输出到PWM模块
    PWM_SetDuty(output);
}

位置环的代码类似，但输入是位置误差，输出是速度目标值。说白了，位置环就是给速度环设定目标。

5.4 PWM死区补偿

PWM死区，这是个大坑。为什么要有死区？因为功率管（MOSFET或IGBT）的开关速度不是无限快的。如果上下桥臂同时导通，就会短路，烧管子。

死区时间一般设置几百纳秒到几微秒。但死区会导致输出电压失真，尤其是在低速时，电机可能会抖动。

死区补偿的方法，我总结了几种：

补偿方法 原理 优缺点
电流极性法 根据电流方向调整PWM占空比 简单，但需要电流传感器
电压前馈法 根据死区时间计算补偿电压 精度高，但需要精确的死区时间
自适应补偿 在线估计死区效应并补偿 复杂，但适应性强

我在AGV项目里常用电流极性法。说白了就是：电流流入电机时，死区导致输出电压降低，我就把占空比调大一点；电流流出时，死区导致输出电压升高，我就把占空比调小一点。

补偿代码示例：

void DeadTime_Compensation(uint16_t *duty, int16_t current)
{
    // 死区补偿量，根据死区时间和PWM频率计算
    static const uint16_t comp_value = 50;  // 假设死区2us，PWM 20kHz
    
    if(current > 0)  // 电流流入电机
    {
        *duty += comp_value;
    }
    else if(current < 0)  // 电流流出电机
    {
        *duty -= comp_value;
    }
    // 电流为零时，不补偿
    
    // 限幅
    if(*duty > PWM_MAX) *duty = PWM_MAX;
    if(*duty < PWM_MIN) *duty = PWM_MIN;
}

避坑指南：我曾经在调试时发现电机低速抖动，查了半天发现是死区补偿没做。加上补偿后，电机运行平稳多了。记住，死区补偿不是可选项，是必选项。

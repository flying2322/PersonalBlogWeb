9 运动学模型：差速驱动运动学正解与逆解、阿克曼转向模型、麦克纳姆轮运动学

各位同学，咱们今天聊点硬核的——运动学模型。

做AGV控制，说白了就是让车按照你想要的轨迹跑。但车怎么动，轮子怎么转，这背后就是运动学在管。我个人觉得，这部分是AGV控制的基础中的基础。你连车怎么走都搞不清楚，后面谈什么路径跟踪、避障规划？

好，咱们一个一个来。

一、差速驱动运动学

差速驱动，这是最常见的AGV底盘形式。两个驱动轮，一个万向轮（或者两个）。靠左右轮的速度差来实现转向。

正解：已知左右轮速度，求车体速度

说白了，就是我知道两个轮子转多快，我想知道车会怎么走。

公式很简单：

v = (v_left + v_right) / 2
ω = (v_right - v_left) / L

其中v是车体线速度，ω是角速度，L是轮距（两个驱动轮中心的距离）。

我在项目中遇到过一个问题：有同学直接用编码器读数算速度，结果发现车走不直。为什么？因为左右轮的实际直径有微小差异，导致同样的转速下，实际线速度不一样。嗯，这里要注意——编码器测的是转速，不是线速度。你得先标定轮径。

实战小技巧： 我建议在代码里加一个轮径补偿系数。每次标定时，让车走一段直线，对比左右轮编码器累计值，算出实际轮径比。这个系数乘上去，车就能走直了。

逆解：已知车体速度，求左右轮速度

反过来，我想让车以某个速度v和角速度ω运动，左右轮该转多快？

v_left = v - ω * L / 2
v_right = v + ω * L / 2

你想想看，如果ω为正（左转），右轮速度就比左轮大，车就往左拐。这个逻辑很直观。

注意： 逆解算出来的速度不能超过电机最大转速。我曾经有个学生，算出来的v_right超过了电机上限，结果车直接原地打转。所以一定要加限幅处理。

二、阿克曼转向模型

阿克曼转向，就是汽车那种转向方式。前轮转向，后轮驱动。这种结构在AGV里也很常见，尤其是重载AGV。

核心思想：所有车轮的转向中心交于一点。这样车轮在转弯时不会产生滑动。

公式：

内轮转角：δ_inner = arctan(L / (R - W/2))
外轮转角：δ_outer = arctan(L / (R + W/2))

其中L是轴距，W是轮距，R是转弯半径。

我记得有一次调试重载AGV，发现转弯时轮胎磨损特别快。查了半天，发现是转向机构没调好，内外轮转角不满足阿克曼关系。说白了，就是轮胎在硬磨地面。后来重新标定了转向拉杆长度，问题就解决了。

关键点： 阿克曼转向的逆解，就是给定车体速度和转向角，算出每个轮子的速度和转角。这个在路径跟踪里经常用到。

三、麦克纳姆轮运动学

麦克纳姆轮，这玩意儿很有意思。它可以在不转向的情况下实现全向移动——前后、左右、斜着走、原地转，都能干。

每个麦克纳姆轮上有多个小辊子，与轮轴成45度角。四个轮子配合，就能产生任意方向的合力。

正解：已知四个轮子转速，求车体速度

v_x = (v1 + v2 + v3 + v4) / 4
v_y = (-v1 + v2 + v3 - v4) / 4
ω = (-v1 + v2 - v3 + v4) / (4 * (L + W))

这里v1到v4分别是左前、右前、左后、右后轮的转速。L和W是车体半长和半宽。

逆解：已知车体速度，求四个轮子转速

v1 = v_x - v_y - ω * (L + W)
v2 = v_x + v_y + ω * (L + W)
v3 = v_x + v_y - ω * (L + W)
v4 = v_x - v_y + ω * (L + W)

你想想看，如果我想让车横向移动（v_y不为0），四个轮子的转速就不一样。这个在狭窄空间里特别有用。

避坑指南： 我曾经在项目里用麦克纳姆轮，发现车走斜线时总是偏。后来发现是辊子磨损不一致导致的。麦克纳姆轮对地面平整度要求很高，地面有颗粒物或者凹凸不平，运动学模型就会失效。所以，用麦克纳姆轮之前，先看看你的地面条件。

四、三种模型的对比与选择

模型类型 优点 缺点 适用场景
差速驱动 结构简单，成本低，控制容易 只能前后和转弯，不能侧移 中小型AGV，仓库搬运
阿克曼转向 高速稳定性好，轮胎磨损小 转弯半径大，结构复杂 重载AGV，室外场景
麦克纳姆轮 全向移动，灵活性极高 对地面要求高，成本高，效率低 狭窄空间，精密装配

我个人习惯是：能用差速就别用麦克纳姆。差速驱动简单可靠，维护也方便。麦克纳姆轮虽然炫酷，但实际项目里坑很多。

五、运动学模型在控制器中的实现

好，理论讲完了，咱们看看代码怎么写。以差速驱动为例：

// 差速驱动运动学逆解
void DiffDrive_InverseKinematics(float v, float omega, float L, 
                                 float *v_left, float *v_right) {
    *v_left = v - omega * L / 2.0f;
    *v_right = v + omega * L / 2.0f;
    
    // 限幅处理
    float max_speed = 1.0f;  // 最大线速度 m/s
    if (*v_left > max_speed) *v_left = max_speed;
    if (*v_left < -max_speed) *v_left = -max_speed;
    if (*v_right > max_speed) *v_right = max_speed;
    if (*v_right < -max_speed) *v_right = -max_speed;
}

这段代码看起来简单，但实际项目里要加的东西很多。比如加速度限制、死区补偿、滤波处理等等。

实战建议： 我建议你在运动学模型外面包一层平滑处理。比如用S曲线规划器，把速度指令平滑一下。这样车走起来不会一抖一抖的，对电机和机械结构都友好。

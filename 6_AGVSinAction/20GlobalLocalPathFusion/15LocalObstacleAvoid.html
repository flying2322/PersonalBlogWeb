15 局部路径避障：VFH算法、动态窗口避障、社会力模型、行人预测与交互

各位，局部避障这个话题，说实话是AGV真正从实验室走向工厂的「最后一公里」。全局路径规划给你画了一条大路，但路上突然冒出个纸箱、叉车、或者一个低头看手机的行人——这时候全局路径就废了。局部避障就是干这个的：在毫秒级时间内，重新算出一条能走的路。

我这些年调试过的AGV，十有八九的「撞墙」事故都出在局部避障参数没调好。今天咱们就把VFH、DWA、社会力模型这几个主流方法掰开揉碎了讲，顺便聊聊行人预测——嗯，这部分我踩过的坑最多。

核心观点：局部避障不是「躲开就完事」，而是在「安全」和「效率」之间找平衡。躲得太远，AGV像个醉汉；躲得太近，容易急刹导致货物倾倒。

15.1 VFH算法：向量场直方图

VFH（Vector Field Histogram）是我个人最早接触的局部避障算法。它的思路很直接：把周围环境用极坐标网格表示，每个扇区统计障碍物密度，然后选一个「最空旷」的方向走。

说白了，就是给机器人装了个「雷达眼」，然后问它：哪个方向障碍物最少？就往那走。

算法核心步骤

  1. 构建极坐标直方图：以机器人当前位置为圆心，将360°划分为n个扇区（通常72个，每5°一个）。
  2. 计算障碍物密度：每个扇区内，根据激光雷达数据计算障碍物占据的「密度值」。
  3. 设定阈值：密度高于阈值的扇区标记为「不可通行」，低于阈值的为「候选方向」。
  4. 选择最优方向：在候选方向中，选一个最接近目标方向的角度。

我的经验：阈值设定很关键。阈值设高了，AGV会贴着障碍物走，容易刮蹭；设低了，AGV会绕大圈。我一般先用仿真跑一遍，观察最窄通道的密度值，然后取那个值的80%作为阈值。

VFH的优点是计算快，适合嵌入式平台。但缺点也很明显——它只考虑「当前时刻」的障碍物分布，没有速度信息。遇到动态障碍物（比如行人），容易「急刹车」或者「来回摆动」。

15.2 动态窗口避障（DWA）

DWA（Dynamic Window Approach）是我现在项目里用得最多的方法。它比VFH聪明的地方在于：它考虑了机器人的运动学约束。

你想想看，AGV不是全向移动的，它有最小转弯半径、最大加速度。VFH告诉你「往左30°走」，但AGV可能根本转不过去。DWA就解决了这个问题——它只在「机器人当前能实现的运动范围」内搜索。

DWA的工作流程

  1. 采样速度空间：在(v, ω)空间内采样，v是线速度，ω是角速度。采样范围受限于最大加速度和最大减速度。
  2. 轨迹预测：对每组(v, ω)模拟一段短时间内的运动轨迹（通常1-2秒）。
  3. 轨迹评价：用三个指标打分——朝向目标的程度、距离障碍物的远近、速度大小。
  4. 选择最优轨迹：加权求和，选得分最高的轨迹执行。
// DWA评价函数伪代码
float evaluateTrajectory(float v, float w) {
    float headingCost = calcHeadingCost(v, w);   // 朝向目标
    float obstacleCost = calcObstacleCost(v, w); // 避障
    float velocityCost = calcVelocityCost(v, w); // 速度奖励
    return alpha * headingCost + beta * obstacleCost + gamma * velocityCost;
}

注意：三个权重的调参是个玄学。alpha太大，AGV会直冲障碍物；beta太大，AGV会原地打转。我习惯先固定gamma=0.1，然后调alpha和beta的比例，让它们在「走廊场景」下能稳定通过。

15.3 社会力模型

社会力模型（Social Force Model）最早是研究行人运动的，后来被引入到机器人领域。它的核心思想是：把人和障碍物都看作「力场源」，机器人受到「吸引力」（目标方向）和「排斥力」（障碍物、行人）的共同作用。

我个人觉得，社会力模型最妙的地方在于它很「自然」。你想想看，人走路的时候不会刻意去算路径，而是凭感觉——离障碍物近了就躲远点，离目标近了就加速。社会力模型模拟的就是这种直觉。

力的构成

力的类型 来源 作用
吸引力 目标点 引导机器人向目标移动
排斥力 静态障碍物 避免碰撞墙壁、货架等
社会力 行人/其他AGV 保持社交距离，避免拥挤
波动力 随机扰动 模拟不确定性，防止死锁

社会力模型的优点是轨迹平滑，看起来像「人」在走路。但缺点也很明显——参数多，调起来费劲。而且它没有显式的「避障保证」，在狭窄通道里容易卡住。

避坑指南：我曾经在一个仓库项目里用社会力模型，结果AGV在门口来回「抖动」就是出不去。后来发现是排斥力衰减太快，导致AGV一靠近门框就被弹回来。解决办法是把排斥力的作用范围从0.5米扩大到1.2米，同时降低峰值力的大小。

15.4 行人预测与交互

这部分是我觉得最有意思的。行人不是静态障碍物，他们会动、会转弯、甚至会停下来看手机。如果你只把行人当作「移动的圆柱体」来处理，那AGV的表现会非常「愣」。

我记得有一次在商场测试，一个小孩突然从货架后面跑出来，AGV急刹停住了，但小孩也吓到了，站在原地不动。AGV等了两秒，发现「障碍物」还在，就开始绕行——结果小孩又往同一个方向跑，AGV又急刹。就这么僵持了十几秒。

后来我意识到：行人预测的核心不是「预测轨迹」，而是「预测意图」。

常用的行人预测方法

  • 恒定速度模型（CVM）：假设行人保持当前速度和方向。简单但有效，适合短时间预测（<1秒）。
  • 社会力模型预测：用社会力模型模拟行人的未来轨迹。计算量大，但更准确。
  • LSTM/RNN：基于历史轨迹预测未来轨迹。需要大量训练数据，适合复杂场景。
  • 交互感知模型：考虑行人与机器人之间的相互影响。比如行人看到AGV过来，可能会主动让路。

我的建议：实际项目中，别一上来就上深度学习。先用恒定速度模型+社会力模型做基础，跑通了再考虑升级。我见过太多团队花三个月训练LSTM，结果部署后发现行人轨迹根本不符合训练集的分布。

人机交互策略

行人预测的最终目的是「交互」。AGV不能只躲着行人走，还要「读懂」行人的意图。比如：

  • 行人朝AGV走来，但视线在看手机——大概率不会让路，AGV应该主动避让。
  • 行人站在通道中间，但身体侧向一边——可能在让路，AGV可以尝试通过。
  • 行人突然加速——可能有急事，AGV应该减速等待。

这些「潜规则」很难用公式表达，我一般用有限状态机来处理：把行人的行为分为「静止、慢走、快走、转向」等状态，每个状态对应不同的避障策略。

15.5 四种方法的对比与选择

方法 计算速度 轨迹平滑度 动态障碍物处理 适用场景
VFH 极快 一般 差 静态环境、低速度AGV
DWA 快 好 中等 动态环境、中高速AGV
社会力模型 中等 极好 好 人机混行、低速场景
行人预测+交互 慢 好 极好 高密度行人、商场/医院

实际项目中，我通常的做法是：DWA做主力，社会力模型做辅助，行人预测做上层决策。DWA负责底层的运动控制，社会力模型用来平滑轨迹，行人预测用来调整DWA的权重参数。

一个小技巧：在DWA的评价函数里，把「行人预测的碰撞概率」作为一个额外的惩罚项。这样AGV在靠近行人时会自动减速，而不是等到距离很近了才急刹。

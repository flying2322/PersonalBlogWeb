2 AGV运动学基础：两轮差速模型、阿克曼模型、运动约束、位姿表示与坐标变换

各位同学，欢迎来到第二章。上一章我们聊了AGV的整体架构，今天咱们把目光聚焦到AGV的“腿脚”上——运动学模型。

说白了，运动学就是研究“怎么走”的问题。你给轮子发指令，车怎么动？转弯半径多大？能不能原地掉头？这些搞不清楚，路径规划就是纸上谈兵。我个人习惯，在开始任何路径规划算法之前，先把运动学模型焊死在脑子里。

核心观点：运动学模型是连接“控制指令”与“实际运动”的桥梁。没有它，规划出来的路径就是“空中楼阁”。

2.1 位姿表示与坐标变换

先解决一个基础问题：AGV在哪儿？怎么描述它的位置和朝向？

我们通常用一个三维向量来表示AGV的位姿：[x, y, θ]。其中 x 和 y 是它在全局坐标系下的坐标，θ 是它的朝向角（通常以逆时针为正）。

嗯，这里要注意：坐标系的选择很关键。我见过不少新手把全局坐标系和机器人坐标系搞混，结果控制量算出来全是反的。

  • 全局坐标系（世界坐标系）：固定在地面上的参考系，通常用 XWOWYW 表示。
  • 机器人坐标系（局部坐标系）：固定在AGV车体上的参考系，通常用 XRORYR 表示，原点在AGV的几何中心，X轴指向车头方向。

坐标变换说白了就是“换位思考”。你站在AGV上看世界，和站在上帝视角看AGV，看到的东西是不一样的。变换公式其实很简单，就是一个旋转加平移：

// 从机器人坐标系到全局坐标系的变换
x_w = x_r * cos(θ) - y_r * sin(θ) + x_agv
y_w = x_r * sin(θ) + y_r * cos(θ) + y_agv

我在项目中遇到过一个问题：激光雷达装在AGV前方偏左的位置，如果不做坐标变换，直接把雷达检测到的障碍物坐标当成全局坐标，那AGV肯定会撞墙。所以，每次做感知融合之前，我都会先检查一遍坐标变换链路。

避坑指南：我曾经因为忘记更新θ值，导致坐标变换一直用上一帧的角度，结果AGV在转弯时定位漂移了半米多。后来我养成了一个习惯：每次做坐标变换前，先打印一下当前的位姿，确认数据是最新的。

2.2 两轮差速模型

这是最常用的模型，没有之一。你想想看，扫地机器人、仓储AGV，大部分都是这种结构。两个驱动轮独立控制，再加一个或两个万向轮做支撑。

两轮差速的核心思想：通过控制左右轮的速度差来实现转向。

  • 直线运动：左右轮速度相等。
  • 原地旋转：左右轮速度大小相等、方向相反。
  • 弧线运动：左右轮速度不等。

它的运动学方程是这样的：

// 两轮差速模型运动学
v = (v_right + v_left) / 2          // 线速度
ω = (v_right - v_left) / L          // 角速度，L为轮距

// 位姿更新（离散时间）
x' = x + v * cos(θ) * dt
y' = y + v * sin(θ) * dt
θ' = θ + ω * dt

这里 L 是左右轮的轮距，这个参数很关键。我记得有一次调试，AGV转弯总是转不到位，查了半天发现是轮距参数写错了，差了2厘米。你想想看，轮距误差2厘米，在高速转弯时累积的位姿误差会有多大？

优点：结构简单、控制方便、能原地旋转。

缺点：对地面平整度敏感，轮子容易打滑。

2.3 阿克曼模型

阿克曼模型就是汽车模型。前轮转向，后轮驱动。你平时开的车，就是阿克曼模型。

它的核心约束是：所有车轮的转向中心必须交于一点。这样才能保证车轮在转弯时纯滚动，没有滑动。

阿克曼模型的运动学方程稍微复杂一点：

// 阿克曼模型运动学
// 输入：车速 v，前轮转向角 δ
// 输出：转弯半径 R，角速度 ω

R = L / tan(δ)          // L为轴距
ω = v / R

// 位姿更新
x' = x + v * cos(θ) * dt
y' = y + v * sin(θ) * dt
θ' = θ + ω * dt

这里有个关键点：阿克曼模型不能原地旋转。它的最小转弯半径由轴距和最大转向角决定。我在做室外AGV项目时，就吃过这个亏。室内用惯了差速模型，觉得原地掉头很正常。结果室外AGV用的是阿克曼模型，规划路径时没考虑转弯半径，结果车在窄巷子里调不了头，尴尬得很。

警告：阿克曼模型有非完整性约束。简单说就是：它不能横向移动，也不能原地旋转。路径规划时必须考虑这一点，否则规划出来的路径可能无法执行。

2.4 运动约束

运动约束，说白了就是AGV的“物理极限”。你规划得再好，车跑不动也是白搭。

常见的运动约束包括：

  • 最大速度约束：v ≤ vmax
  • 最大加速度约束：a ≤ amax（加减速能力）
  • 最大角速度约束：ω ≤ ωmax
  • 最大转向角约束（阿克曼）：δ ≤ δmax

我个人习惯，在做路径规划之前，先把这些约束整理成一个参数表。这样在规划时可以直接查表，不用每次都重新计算。

参数 符号 典型值（差速） 典型值（阿克曼）
最大线速度 vmax 1.5 m/s 3.0 m/s
最大加速度 amax 0.5 m/s² 0.3 m/s²
最大角速度 ωmax 1.0 rad/s 0.5 rad/s
最小转弯半径 Rmin 0（可原地转） 2.0 m

嗯，这里要特别说一下加速度约束。很多新手只考虑最大速度，不考虑加速度。结果规划出来的路径，AGV根本跑不出那个速度，因为加速距离不够。我曾经在一个项目中，把加速度约束设得太保守，结果AGV跑起来像老太太散步。后来调大了加速度，效率提升了不少，但也要注意别调太大，否则货物会倒。

2.6 小结

好了，这一章的内容就这些。总结一下：

  • 位姿表示是基础，[x, y, θ] 三个量要记牢。
  • 坐标变换是桥梁，全局和局部坐标系要分清楚。
  • 两轮差速模型适合室内、需要灵活转向的场景。
  • 阿克曼模型适合室外、高速行驶的场景，但要注意转弯半径。
  • 运动约束是硬限制，规划时必须考虑。

下一章我们会把这些运动学模型用到路径规划中，看看怎么让AGV按照我们期望的轨迹运动。嗯，到时候会用到今天讲的所有内容，所以这一章一定要消化透。

个人建议：学完这一章，你可以找个开源的两轮差速小车（比如TurtleBot），跑一下它的运动学代码。亲手改改参数，看看位姿怎么变化，比光看书效果好得多。

9 全局路径后处理：路径剪枝、B样条曲线平滑、贝塞尔曲线、路径点插值

各位同学，欢迎来到第九章。前面几章我们聊了怎么规划出一条从A到B的路径，但说实话，规划出来的原始路径，直接拿给机器人去跑，往往会出问题。为什么？因为路径点太密、太锯齿、或者不符合运动学约束。

我最早做AGV项目时，就吃过这个亏。规划器输出了一堆点，我直接丢给底层控制器，结果机器人原地打转，像喝醉了酒。后来才明白——路径后处理，是连接规划和控制的桥梁，这步省不了。

今天我们就来拆解四个核心操作：路径剪枝、B样条曲线平滑、贝塞尔曲线、路径点插值。它们各有各的用处，也各有各的坑。

核心观点：路径后处理不是为了好看，而是为了让机器人能真正跑起来。剪枝去掉冗余，平滑消除抖动，插值满足精度。

9.1 路径剪枝：去掉那些没用的点

先说说路径剪枝。你想想看，A*或者RRT规划出来的路径，往往包含大量共线的点。比如一条直线段上，可能有几十个点，但真正有用的只有起点和终点。

我习惯用Ramer-Douglas-Peucker（RDP）算法来做剪枝。它的思路很简单：

  1. 找到路径上离首尾连线最远的点
  2. 如果这个距离大于阈值，就保留该点，并递归处理左右两段
  3. 否则，删除中间所有点

代码实现也不复杂：

def rdp_simplify(points, epsilon=0.1):
    if len(points) < 3:
        return points
    
    # 找到最远点
    dmax = 0
    index = 0
    for i in range(1, len(points) - 1):
        d = perpendicular_distance(points[i], points[0], points[-1])
        if d > dmax:
            index = i
            dmax = d
    
    if dmax > epsilon:
        left = rdp_simplify(points[:index+1], epsilon)
        right = rdp_simplify(points[index:], epsilon)
        return left[:-1] + right
    else:
        return [points[0], points[-1]]

经验之谈：epsilon的取值很关键。我一般取0.05~0.2米，具体看AGV的尺寸。太大路径会失真，太小又剪不干净。建议先画个图看看效果。

剪枝之后，路径点数量通常能减少70%~90%。这对后续的平滑和插值来说，负担小了很多。

9.2 B样条曲线平滑：让路径更顺滑

剪枝完的路径，虽然点少了，但转折处还是尖锐的。AGV如果直接沿着这些折线走，每到一个拐角就得停下来转向，效率极低。

这时候就需要B样条曲线了。B样条的好处是：局部可控。你修改一个控制点，只影响附近一小段曲线，不会牵一发动全身。

我记得有一次做仓储AGV，通道很窄，用贝塞尔曲线做平滑，结果曲线跑到墙里去了。换成B样条，调整几个控制点就搞定了。

B样条的数学定义是这样的：

C(u) = Σ Ni,p(u) * Pi

其中Ni,p是基函数，Pi是控制点。p是阶数，一般用3阶（三次B样条）就够了。

实际应用中，我通常把剪枝后的路径点作为控制点，然后采样生成平滑路径：

import numpy as np

def bspline_curve(control_points, num_samples=100):
    n = len(control_points) - 1
    p = 3  # 阶数
    knots = np.linspace(0, 1, n + p + 2)
    
    u_vals = np.linspace(0, 1, num_samples)
    curve = []
    
    for u in u_vals:
        point = np.zeros(2)
        for i in range(n + 1):
            basis = basis_function(i, p, u, knots)
            point += basis * control_points[i]
        curve.append(point)
    
    return np.array(curve)

注意：B样条不保证通过所有控制点。如果你需要路径严格经过某些关键点（比如充电桩位置），得用插值型样条，或者把关键点作为曲线端点。

9.3 贝塞尔曲线：简单但有限制

贝塞尔曲线大家可能更熟悉。它的优点是数学简单、直观。但缺点也很明显：全局性——移动一个控制点，整条曲线都会变。

对于AGV路径平滑，我一般只在局部拐角处用贝塞尔曲线。比如一个90度的转弯，用两段直线加一段贝塞尔曲线过渡，效果就很不错。

二阶贝塞尔曲线的公式：

B(t) = (1-t)²P0 + 2t(1-t)P1 + t²P2,  t∈[0,1]

三阶的：

B(t) = (1-t)³P0 + 3t(1-t)²P1 + 3t²(1-t)P2 + t³P3

我建议你记住一个原则：控制点数量越少越好。对于AGV路径，三阶贝塞尔（4个控制点）基本够用。再多就容易出现不必要的波动。

避坑指南：我曾经在一条长直道上用了高阶贝塞尔，结果曲线中间出现了波浪形抖动。后来查资料才发现，高阶贝塞尔容易产生龙格现象。所以，长路径分段处理，每段用低阶曲线，才是正道。

9.4 路径点插值：补上缺失的细节

最后说说插值。剪枝和平滑之后，路径点可能比较稀疏。但底层控制器需要高频率的位置指令（比如50Hz），这就得靠插值来补点。

常用的插值方法有：

  • 线性插值：简单快速，但加速度不连续
  • 三次样条插值：二阶连续，适合大多数场景
  • 五次多项式插值：可以约束加加速度（jerk），适合高精度场景

我个人偏爱三次样条。它能在保证平滑的同时，计算量也不大。下面是一个简单的实现：

from scipy.interpolate import CubicSpline

def interpolate_path(path_points, num_points=200):
    # path_points: Nx2 的路径点
    t = np.linspace(0, 1, len(path_points))
    t_new = np.linspace(0, 1, num_points)
    
    cs_x = CubicSpline(t, path_points[:, 0])
    cs_y = CubicSpline(t, path_points[:, 1])
    
    x_new = cs_x(t_new)
    y_new = cs_y(t_new)
    
    return np.column_stack((x_new, y_new))

关键点：插值前一定要确保路径点已经剪枝和平滑过了。否则，原始路径中的噪声会被插值放大，反而更糟。

9.5 四种方法的对比与选择

说了这么多，到底什么时候用哪个？我整理了一个表格，方便你对照：

方法 主要用途 优点 缺点 推荐场景
路径剪枝 减少冗余点 大幅压缩数据量 可能丢失细节 所有路径的预处理
B样条曲线 全局平滑 局部可控，灵活 不通过控制点 长路径、复杂环境
贝塞尔曲线 局部过渡 简单直观 全局影响 拐角、转弯处
路径点插值 增加密度 满足控制频率 可能引入振荡 控制指令生成

在实际项目中，我通常的流程是：先剪枝 → 再B样条平滑 → 局部拐角用贝塞尔微调 → 最后插值生成控制点。这个流程我用了好几年，在几十个AGV项目上都验证过，效果稳定。

9.6 本章小结

嗯，今天的内容就到这里。路径后处理看起来是细枝末节，但往往决定了AGV能不能稳定运行。剪枝、平滑、插值，这三板斧用好了，你的路径就从「能走」变成了「走得稳」。

最后提醒一句：不要盲目追求平滑。太光滑的路径可能偏离原始路径太远，导致碰撞。我见过有人把路径平滑成一个完美的圆弧，结果机器人直接撞上了旁边的货架。所以，平滑的代价是牺牲路径的保真度，这个度要把握好。
